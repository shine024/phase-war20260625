## 第一块（P1）：82 张无专属图标卡片的视觉撞脸排查

**问题来源**：`tests/evidence/playability_2026-09-21/task13_asset_audit.json` — 82 张卡（多为 cold_/fut_/enemy 变体）无专属图标无 override，走 manifest 可视链或 ERA_KIND 时代通用兜底图 → **多卡可能显示同一张图**。

### Task 1.1 撞脸分组清单（脚本全量）
- 以玩家实际渲染路径为准：走 `UiAssetLoader.card_icon_path_for` 真实七级解析链（复用 `tests/_archived/_tmp_card_icon_dedicated_audit.gd` 模式——脚本已归档至 `tests/_archived/`，`--script` 直跑仍可用，headless 可复跑），对统一卡表 233 张逐一解析出**最终落盘图标路径**。
- 按最终图标路径分组，输出"同一图标被 ≥2 张卡共用"的分组表：组号 / 共用图标路径 / 卡 id 列表 / 卡显示名列表 / 卡稀有度与时代。
- 明确区分三类：a) manifest 有意映射（设计内复用）；b) ERA_KIND 时代兜底兜出来的（同一时代全家一张脸）；c) 完全意外的撞脸。
- 证据：`task11_icon_collision_groups.json` + 人类可读 `task11_icon_collision_groups.md`。

### Task 1.2 撞脸组目检定性（逐组看图）
- 对每个 b/c 类分组：打开共用图标 + 组内卡的卡面合成截图（in-game 渲染或拼图），目检判定玩家观感严重度：
  - 高：同屏可见的两张常用卡同脸（如商店页/背包页相邻）
  - 中：不同时代/稀有度撞脸，同屏少见
  - 低：仅数据层撞，玩家几乎不可能对照发现
- 证据：每组一张对比图，命名 `task12_group_<n>.png`。

### Task 1.3 处置建议与修复方案
- 对高严重度组逐组给出处置：补专属图（走 game-asset-regeneration 管线，STRICT_PREFIX 侧视提示词规范）/ 调 manifest 映射 / 接受（登记设计内）。
- 补图数量预估与批次划分（每批 ≤20 张，生成后逐张目检 + .import 校验 + 实机开面板复验）。
- **质量红线**：新图必须与同稀有度既有卡面风格一致（线宽/配色/构图密度）；每张生成后用 vision 目检，不合格重掷（单张最多 3 掷，仍不合格升级人工）。

**问题来源**：仅 09-13 设计审查顺带提及，从未图级审计；P2-1 备注挂有 4 张已知缺口（pi_r_free_deploy、pi_umbra_01~03）未核销。

### Task 2.2 图标质量目检（主图 94 张全量，分批目检）
- 目检以 **94 张主图全量**为准（68 张 128px 缩略图是主图衍生，不单独打分，只做"128px 下主体可辨识"专项核查）。分批逐张目检，每张检查：

## 第三块（P3）：开场漫画 + 地图过场图审计（开场链 17 + 地图 32 张）

**问题来源**：零专项审计；开场漫画是玩家第一眼体验，风格断裂/分辨率不足代价最高。量小，全量目检成本可控。
**口径勘误（2026-09-22 核对）**：`assets/intro/comic/` 实为 **15 张**（原计划写 19 系把整个 `assets/intro/` 目录 19 张 PNG 计入）；其中 `wakeup_backpack.png`/`wakeup_wrist.png` 已随 v6.20 退出开场链零引用留档，在用开场链图 = 漫画 15 + 演出图 2 = **17 张**。

### Task 3.1 开场链逐张目检（17 张全量 = 漫画 15 + 在用演出图 2）
- 范围：`assets/intro/comic/` 15 张（叙事主体）+ `wakeup_snowfield.png`（基地雪原背景，truck_base 在用）+ `battle_bg.png`（梦战背景，dream_battle 在用）；`wakeup_backpack.png`/`wakeup_wrist.png` 两张退役图只登记为已知孤儿，不占目检量。
- 逐张检查：
  - 叙事连贯：格与格之间角色造型/配色/画风不跳（AI 生图常见的角色漂移重点查）
  - 文字：漫画内嵌文字若为生图产生，必须是正确中文无乱码；若应无文字则有字即违规
  - 分辨率与裁切：实际像素 ≥ 引用处显示尺寸的 1 倍；主体不被裁
  - 白边/水印/签名
- 演出图 2 张额外查与叠加 UI（跳过键/标题字）的对比度
- 按叙事顺序拼接预览长图一张，整体看节奏断裂点。
- 证据：`task31_intro_scores.csv` + `task31_intro_strip.png`。

### Task 3.2 地图/过场图审计（32 张全量）
- 先脚本：引用完整性（每张有消费方；模板路径如 bg_endless_gate_t{0,1,2} 三档齐）+ 尺寸清单（分辨率差异过大即预警）。
- 再目检：同系列地图风格/色调一致；无水印文字；与 UI 叠字区域（若有固定文字位）对比度够。
- 证据：`task32_map_refs.json` + `task32_map_scores.csv`。

### Task 3.3 修复
- 问题图重生成时**必须带前后帧作参考**（漫画）或同系列已合格图作风格锚（地图），避免修一张断一格。
