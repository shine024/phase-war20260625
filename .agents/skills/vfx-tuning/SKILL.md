# VFX 调优技能（v17 踩坑复盘沉淀）

## 触发条件

以下任务**必须先走完五步铁律再动手**：
- 改粒子参数（寿命/锥角/速度/尺寸/数量）
- 换特效贴图或生成新贴图
- 调弹道视觉（拖尾/拖光线/弹体）
- 改审计工具的采样逻辑

## 五步铁律（强制流程，按序执行）

### 第 1 步：先读历史报告

历史评分报告里有现成的参数级正确值，**先抄再调**——不要从零盲试。

| 报告 | 内容 |
|------|------|
| `docs/vfx_realism_report_v12final.md` | v12 轮 31 特效逐项点评 + 高优先级参数级建议（火花尺寸/速度/寿命/颜色梯度全有） |
| `docs/vfx_realism_report_v17.md` | 当前基线（4.2/10）+ 12 武器族分族均分 + 每格一句话总评 |
| `docs/VFX武器族视觉规格.md` | 12 族验收规格 + "不合格特征"反例列 |

v17 实锤：v12 报告建议里写着"火花 1-3px、初速 800-1500px/s、寿命 0.1-0.25s"——和 v17c 三轮试错摸出来的值一致。**先读报告能省三轮。**

### 第 2 步：量贴图实寸（动 scale 前必跑）

```python
from PIL import Image
im = Image.open("assets/effects/particle_textures/xxx.png")
print(im.size, im.getbbox())  # 画布尺寸 + 非透明内容包围盒
```

**禁止按代码注释里的尺寸假设标定 scale。**

v17 实锤：历代注释写"32/64px 贴图"，实测全是 128px（energy 枪口是 1024px 大图内容 974×597）。错误假设潜伏 v9.2→v16.1 三个版本，全系统粒子渲染尺寸超设计 2-4 倍——这是"拖尾像云/火花像发光虫"的单一根因。

本轮实测表（后续新增贴图必须补录）：

| 贴图 | 画布 | 内容实寸 |
|------|------|---------|
| muzzle_light / muzzle_heavy | 128×128 | 74×84 / 125×123 |
| weapon_artillery_muzzle（energy） | 1024×1024 | 974×597 |
| muzzle_jet_sym | 100×46 | 全幅 |
| spark_streak | 128×24 | 118×17 |
| flame_star | 160×160 | 全幅 |

### 第 3 步：改特效前先校准测量

**测量仪器和被测系统联动检查**——特效寿命变了，审计工具的采样帧可能拍不到峰值，基于坏测量继续调特效只会越调越错。

- 审计矩阵采样帧 `[0.05, 0.12, 0.30]`：特效寿命砍到 <0.2s 时，确认 0.05s 帧能拍到峰值（寿命 0.14s 的枪口火在 0.12s 已是尾巴）。
- 改完特效先跑像素核验（特效区非空 + 色相签名匹配族预期），**确认工具没坏再信 AI 分数**。

v17 实锤：枪口火砍短后 0.12s 采样帧拍到全是残烟 → AI 复测全部格读成"烟雾云"（3.5↓）→ 基于这个假反馈去调特效浪费一轮。修采样帧后真因（烟层反客为主）才暴露。

### 第 4 步：单轮单变量 + AI 三次取中位

- **一轮只改一个变量**（参数或贴图或工具采样，绝不同时）——多变量改动出问题无法归因。
- **AI 评分单次噪声 ±0.3-0.5**：对比必须三次取中位（v12 管线 `median/3` 先例）。单次 4.0 vs 3.7 的差异在噪声区内，追这个差异=浪费时间。

v17 实锤：参数+贴图+选帧逻辑同轮混改，复测反降后花了两轮才定位到是选帧问题不是特效问题。

### 第 5 步：感知验收优先于物理正确

"真实感"以**用户读图感受**为准，物理仿真级正确可能更差。

- 动手前拿同类专业 2D 游戏参照（Metal Slug / Broforces 的枪口火都是 2-4 帧手绘贴图 + 短光晕，没有纯粒子模拟的）问用户要什么感觉。
- 不要自作主张做物理仿真。

v17 实锤：按弹道学程序化生成棱角金属破片（多边形+撕裂边+明暗面），用户一句"金属碎片更不好了"直接否决，回退软圆块。游戏 VFX 的真实是**艺术化真实**——读起来像即可。

## 弯路黑名单（每条一句话教训）

| # | 黑名单 | 本轮实锤 |
|---|--------|---------|
| 1 | 按代码注释尺寸假设标 scale | 注释"32/64px"实为 128px，潜伏三版本 |
| 2 | 测量工具与特效寿命不联动 | 拍到残烟当反馈，越调越错一轮 |

## 工具链速查

```bash
# 1. 截 48 格矩阵（~1 分钟，勿用 --headless——dummy renderer 截不出内容）
"$GODOT" --path . res://scenes/tools/vfx_audit_matrix.tscn

# 2. AI 评分（~15 分钟 48 格；--limit 3 试跑；--only f08 只评某族）
python tools/review_vfx_audit_matrix.py

# 3. 回归锁（headless 秒级，38 项断言）
"$GODOT" --headless --rendering-driver opengl3 --path . --script tests/weapon_visual_profiles_smoke.gd

# 4. 锐利贴图生成器（muzzle_jet_sym / flame_star / spark_streak）
python tools/generate_sharp_vfx_textures.py

# 5. 新贴图必须先 import 才能被 preload（否则 "no resource loaders" 编译错误）
"$GODOT" --path . --import
```

- 浏览器审查页：`tools/vfx_audit_review.html`（截图矩阵 + 族规格 + 名字解析审计表 + AI 分数徽章）
- 截图目录：`docs/vfx_audit_shots/`（48 格 + manifest.json）
- 特效消费点速查：`scripts/battle/vfx_impact_factory.gd`（命中/枪口/冲击波）、`scenes/units/bullet.gd`（弹道/拖尾/拖光线）、`scripts/weapon_projectile_vfx.gd`（命中贴图分派/power_tier）
- 视觉身份解析：`data/weapon_visual_profiles.gd`（12 族 + 武器名优先解析器，改武器视觉身份先看这里）
