# 第1关背景图生成说明

## 文件信息

- **生成文件**: `v18.png`
- **保存路径**: `assets/backgrounds/reviews/level_1/v18.png`
- **尺寸**: 1024x1024 (API默认) → 裁剪缩放到 1280x720 (16:9)
- **风格**: 卡通/动画风格，冷色调，线条简洁
- **构图**: 三层横向布局（天空/中景/地面）

## 画面内容

- **前景**: 笔直的道路，两侧沙袋防御工事+铁丝网围栏
- **中景**: 枯树和铁丝网围栏的延伸
- **背景**: 连绵山脉+薄雾+白云蓝天
- **色调**: 蓝色和灰色冷色调为主，略带忧郁感
- **无人物**: 完全空的战场场景

## 与原提示词的关键差异

| 项目 | 原提示词 | 实际生成(v18) |
|------|---------|--------------|
| 地面/道路比例 | 底部15%~22% | 约30-40%（偏少） |
| 构图方式 | 固定三层(65%/20%/15%) | 实际三层结构正确 |
| 道路形态 | 笔直水平车道 | 笔直但偏窄 |
| 视角 | 近侧视(side-view) | 有轻微纵深透视 |
| 氛围 | 雨后湿润感 | 晴朗干燥 |
| 科幻元素 | 青色电光雾 | 未体现 |
| 战场元素 | 弹药箱/战壕/木桩 | 有沙袋+铁丝网+枯树 |
| 风格描述 | 明亮干净 polished 2D | 偏冷色调 |

## 注意事项

1. **AI默认正方形**: Agnes API总是返回1024x1024，需裁剪缩放到1280x720
2. **比例控制弱**: 提示词中"bottom 15%"等比例描述AI不遵守，实际生成比例不可控
3. **透视问题**: AI天生画纵深透视，难以做到纯扁平侧视
4. **人物难排除**: 即使strong negative prompt，AI偶尔仍会画人物
5. **科幻元素缺失**: 提示词中的cyan sci-fi glow未被AI理解
6. **风格偏差**: "bright clean polished"被AI理解为冷色调而非明亮
7. **战场元素简化**: 弹药箱/战壕/通信壕等细节未完整呈现

## 改进方向

- 地面/道路比例需增大到约45%
- 强调"horizontal across entire frame"而非百分比
- 用更多重复关键词强化"no depth, flat side view"
- 考虑用reference image引导风格一致性
