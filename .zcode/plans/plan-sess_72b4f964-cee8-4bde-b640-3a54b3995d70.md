# 改造面板 v1.5 落地实施计划

## 目标与范围

把 v1.5 设计稿落地到 Godot 代码，**仅限改造面板**（`scenes/ui/modification_panel.gd`/`.tscn`），外加**兵种色 bug 收敛**和**键盘导航**两项。卸载按钮不补 API，文案改"替换"。右栏三档折叠含收起态 hover 浮卡。

## 关键事实（探索阶段已确认）

- **代码已超前设计稿**：档位不足已是 `DT.COLOR_AMBER`（L607）、mod-ico 已有稀有度色兜底（L548）。这些不动。
- **5 档阈值硬编码 3 处**（L857 vals / L994-998 if 链），应收敛到 `PowerTiers.POWER_THRESHOLDS`。
- **改造库选中态不改边框色**（L515-516 只改 bg，左边框仍是稀有度色）。
- **无任何键盘输入处理**（grep `_gui_input`/`_input`/`InputEventKey` 零结果）。
- **兵种色 bug 坐实**：枚举只返回 `轻装/装甲/支援/空中/堡垒`，但 `_get_kind_color`/`_get_unit_icon` 匹配 `步兵/装甲/炮兵/防空/空军/...`——只有装甲(1)命中，其余全灰。

**根因**：`modification_panel.gd` 的 `_get_kind_color`(L1591) / `_get_unit_icon`(L1579) 键名错位。backpack_card_item.gd:813 已有规范 int 索引版 `_V9_KIND_COLORS`/`_V9_KIND_GLYPHS`，作为统一基础。

| 文件 | 改动 |
|------|------|
| `resources/design_tokens.gd` | 新增 `const KIND_COLORS := {0:红#e5484d,1:蓝#4d7fe5,2:橙#e59820,3:青#4dcce5,4:灰#9f9f9f}` + `const KIND_GLYPHS := {0:"轻",1:"甲",2:"援",3:"空",4:"堡"}` + `static func get_kind_color(int)`/`get_kind_glyph(int)`（带 fallback）。数值照搬 backpack `_V9_KIND_COLORS` |

| `scenes/ui/backpack_card_item.gd` | `_V9_KIND_COLORS`/`_V9_KIND_GLYPHS` 加注释指向 DT 单一源（不删，避免破坏现有引用） |

**验证**：选 kind=0 步兵 / 2 炮兵 / 3 空军 单位，缩略图边框应显示对应红/橙/青（之前全灰）。

## 阶段 E：键盘导航（modification_panel.gd）

新增 `_gui_input(event)`：

| 键 | 行为 |
|----|------|
| `↑/↓` | 改造库行间移动 `selected_mod_id`（遍历 `%ModListContainer` 子节点） |
| `TAB` | 焦点三栏循环（左名册→改造库→右栏） |
| `SPACE/ENTER` | 焦点在改造库→触发 `_install_modification`；在名册→选中单位 |
| `ESC` | 有选中模块→`_show_deck_empty`；抽屉开→先关；否则→`_on_close` |

- 名册/改造库 btn 设 `focus_mode = FOCUS_ALL`，选中时 `grab_focus()`
- 焦点视觉：`theme_override_styles/focus` 加 2px cyan outline
- **嵌入模式降级**：ESC 不关闭面板（避免连带关闭宿主 card_info_panel），仅取消选中

---

## 阶段 F：替换按钮（已装改造列表）

当前 L1062 仅对武器类改造有"启用/禁用"切换。**保留该切换不变**，对所有已装项追加"替换"按钮：
- 调 `_show_deck_empty()` 引导玩家从改造库选新模块；新模块若同冲突组会触发 `BlueprintManager.replace_modification`(已存在，L1074)
- tooltip 注明"替换为同槽位新模块，原消耗不返还（卸载 API 未实装）"
- 不动 `blueprint_manager.gd`，零平衡风险

## 实施顺序

A（兵种色常量）→ B（状态/选中态）→ C（折叠+浮卡）→ D（抽屉）→ E（键盘）→ F（替换按钮）。每阶段独立可验证。

## 风险与降级

- **C2 浮卡定位**：嵌入模式宿主坐标差异 → 降级用 `tooltip_text` 富文本
- **E 键盘与宿主冲突**：嵌入模式 ESC → 仅取消选中不关面板
- 项目 `--check-only` 因体量可能 5 分钟超时（既有现象），改用静态 Grep 核对 + 单文件 `--check-only`
