## 背包战斗卡卡图不可见问题修复计划

### 问题概述
背包面板中的战斗卡看不到卡面图片。经过完整代码链路追踪，定位到两个根因：

### 根因 A：CompactArtClip 塌缩导致 clip_contents 裁剪

`_ensure_compact_slot_structure()`（backpack_card_item.gd:599-661）创建的 `CompactArtClip` 是 `Control` 类型，放在 `VBoxContainer` 中。Godot 4.x 的 `VBoxContainer` 对 `Control` 子节点（非 Container）的布局策略是 `SIZE_SHRINK_CENTER`，当 `custom_minimum_size` 不够大或父容器尺寸受限（ScrollContainer + GridContainer 布局）时，CompactArtClip 的实际渲染尺寸可能被压缩到 0，导致 `clip_contents = true` 把内部 Icon 完全裁剪掉。

**修复**：给 CompactArtClip 设置足够的 `size_flags_vertical = SIZE_EXPAND_FILL`（已设置但需验证 GridContainer 单元格的实际尺寸是否足够），或在 `_layout_compact_art_clip()` 中确保 icon 不会被 clip 到 0 尺寸。

### 根因 B：图标路径解析失败导致 visible = false

`_apply_card_icon_to_clip()`（backpack_card_item.gd:683-696）在 `tex == null` 时设置 `icon_rect.visible = false`（L690）。如果 `card_icon_path_for()` 对玩家战斗卡返回空字符串（PLAYER_ICON_OVERRIDE 映射不完整、EnemyUnitManifest 合并失败等），所有战斗卡的 Icon 都会被设为不可见。

**修复**：在 `_apply_card_icon_to_clip()` 中增加调试日志输出路径解析结果，定位具体哪些卡的路径解析失败。

### 实施步骤

1. **添加调试日志**（临时）：在 `_apply_card_icon_to_clip()` 中打印 `tex_path` 和 `tex`，确认路径是否解析成功
2. **验证 CompactArtClip 尺寸**：在 `_layout_compact_art_clip()` 中打印 art_clip 的实际 size，确认是否塌缩为 0
3. **修复路径解析**（如果确认为 A2）：检查 `PLAYER_ICON_OVERRIDE` 是否覆盖所有战斗卡，或 `EnemyUnitManifest` 是否正确映射
4. **修复 Clip 裁剪**（如果确认为 A1）：给 CompactArtClip 添加 `size_flags_vertical = SIZE_EXPAND_FILL`（已设置，需验证 GridContainer 单元格是否给了足够空间）

### 预期结果
修复后背包战斗卡应正常显示卡面图片，稀有度边框、兵种标记、星级装饰等叠加层正常工作。
