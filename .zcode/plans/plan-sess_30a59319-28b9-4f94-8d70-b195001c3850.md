## 目标
情报面板全面显示战斗卡的**特殊功能**（改造机制 + 光环），并把过时的固定模板描述换成基于单位实际机制的**动态描述**。敌我都覆盖。

## 三块改动

### 改动 1：扩展 `_build_affix_summary_lines`（16 类改造特殊功能）
**位置**：`card_info_panel.gd` L956-990（现有 10 条 → 扩到 26 条）

在现有 mutations 判断**之前**，补齐 16 类 live 特殊机制字段（全部读 `stats`，`.get` 守卫兼容缺省）。复用现有 `" · ".join(parts)` 模式。文案反映实际机制（不是设计意图）：

```
attack_fort_bonus>0      → "对堡垒特攻 +N%"
splash_radius_bonus>0    → "溅射范围 +N%"
single_target_penalty<0  → "单目标伤害 N%"（负值显示"分散伤害"语义）
armor_break_per_hit>0    → "破甲叠加（每击-N防，N层）"
mark_chance>0            → "标记目标 N%"（+mark_vuln 时追加"标记易伤 +N%"）
siege_bonus_pct>0        → "攻城加成 +N%"
urban_defense_bonus>0    → "巷战防御 +N%"
has_counter_battery      → "反炮兵（受击标记攻击者）"
revive_on_death          → "濒死复活（N%生命）"
reflect_damage_pct>0     → "爆反反伤 N%"
intercept_chance>0       → "拦截 N%"（+charges 追加次数）
death_heal_allies_pct>0  → "亡语治疗友军 N%生命"
slow_aura_pct>0          → "减速光环 N%"
command_aura_bonus>0     → "指挥光环 +N%"
phase_shield_pool>0      → "相位护盾 N"
laser_mark_on_hit        → "激光标记（命中必标记）"
combo_max>0              → "连击系统（N层+N%伤害）"
rage_max>0               → "狂怒系统（N层+N%伤害）"
```

**效果**：3 个 `_show_*_unit` 函数（构装 L1407 / 我方 L1487 / 敌方 L1749）都调此函数，敌我同时生效。空值不显示（默认 0/false 不触发），零侵入。

### 改动 2：敌方普通单位补光环显示
**位置**：`_show_generic_enemy_unit` L1752-1756

当前把 nurture section 显式清空隐藏。改为：先调 `_build_enemy_aura_text(unit)`，非空时填充 nurture section（敌方 platform_type 驱动的医疗/雷达/侦查/指挥光环），空时才隐藏（行为不变）。

```gdscript
# 改前：
if nurture_label: nurture_label.text = ""
_set_section_visible_by_content(_nurture_section, "")

# 改后：
var enemy_aura_text := _build_enemy_aura_text(unit)
if nurture_label: nurture_label.text = enemy_aura_text
_set_section_visible_by_content(_nurture_section, enemy_aura_text)
```

### 改动 3：动态描述（替换固定模板）
**新增函数** `_build_unit_description(stats: UnitStats, is_player: bool, base_text: String) -> String`
- 入参：单位 stats（取特殊机制字段）、阵营（决定"推进方向"措辞）、base_text（基础模板兜底）
- 逻辑：扫描 stats 的特殊机制字段，拼接一句**基于实际机制**的定位描述。如：
  - 溅射手（splash_damage>0）→ "范围溅射单位，攻击波及周围敌人"
  - 反导/拦截（intercept_chance>0）→ "拦截型单位，概率格挡来袭攻击"
  - 标记手（mark_chance>0/laser_mark）→ "标记支援，标记目标使其易伤"
  - 反伤坦（reflect_damage_pct>0）→ "爆反装甲，受击反伤近战攻击者"
  - 复活（revive_on_death）→ "带急救系统，濒死时可复活一次"
  - 无特殊机制 → 回退 base_text（保留通用描述）
- 措辞不写版本号、不写设计意图，只描述当前实际机制。

**替换 3 处固定描述**：
- `_show_player_unit` L1505：`"自动向敌侧推进..."` → `_build_unit_description(stats, true, "自动向敌侧推进，在射程内交战。")`
- `_show_enemy_construct_unit` L1405：`"由敌方相位师基地生产..."` → `_build_unit_description(stats, false, "由敌方相位师基地生产，自动推进攻击我方。")`
- `_show_generic_enemy_unit` L1747：`"向左推进的敌方单位..."` → 用 archetype + stats 动态生成（敌方普通单位无 platform 改造但可能有 platform 光环 + 基础属性特征）
