## 背包新增"相位仪"标签页

### 改动范围

**2 个文件**：`backpack_panel.tscn` + `backpack_panel.gd`

### 具体改动

#### 1. `backpack_panel.tscn` — 添加 Tab 页面节点

在 `TabContainer` 下新增 `PhaseInstTab`（Control），内含 `ScrollContainer` + `VBoxContainer`（相位仪列表用垂直排列，不同于其他 tab 的 Grid 布局）：

```
TabContainer/PhaseInstTab/
  └── ScrollContainer/
        └── PhaseInstList (VBoxContainer, separation=8)
```

#### 2. `backpack_panel.gd` — 逻辑层

**a. TabIndex 枚举新增**：
```gdscript
enum TabIndex {
    COMBAT_CARDS = 0,
    RESOURCES = 1,
    INTEL = 2,
    STAT_BOOSTS = 3,
    RUNES = 4,
    PHASE_INSTRUMENTS = 5,   ## v8.0: 相位仪标签
}
```

**b. 标签标题设置**（_ready 中）：
```gdscript
_tab_container.set_tab_title(TabIndex.PHASE_INSTRUMENTS, "相位仪")
```

**c. @onready 引用**：
```gdscript
@onready var _phase_inst_list: VBoxContainer = $VBoxOuter/TabContainer/PhaseInstTab/ScrollContainer/PhaseInstList
```

**d. 标签切换处理**（_on_tab_changed）：
```gdscript
TabIndex.PHASE_INSTRUMENTS:
    refresh_phase_instruments_tab()
```

**e. 核心刷新方法 `refresh_phase_instruments_tab()`**：
- 复用 `phase_instrument_selector.gd` 的 `_create_instrument_item()` 逻辑
- 调用 `PhaseInstrumentManager.get_unlocked_instrument_ids()` 获取已解锁列表
- 调用 `PhaseInstruments.get_by_id()` 获取每个相位仪定义
- 按星级降序排列
- 调用 `PhaseInstrumentManager.get_current_instrument()` 标记当前装备
- 每个相位仪卡片包含：名称+星级、势力/通用标签、槽位配置、属性加成、主动能力
- 已装备的显示"当前装备中"，未装备的显示"装备此相位仪"按钮
- 点击装备按钮调用 `PhaseInstrumentManager.equip_instrument(instrument_id)`
- 装备成功后 emit toast 提示

**f. 空状态处理**：无相位仪时显示"暂无已解锁的相位仪"

### 设计决策
- **复用 phase_instrument_selector 的 UI 构建逻辑**，不新建组件——两个地方的相位仪卡片外观一致，减少维护成本
- **不引入新场景文件**，直接在 backpack_panel.tscn 内嵌节点，保持背包面板自包含
- **装备后不自动切换 tab**——玩家可能在背包里先看相位仪再操作其他东西
