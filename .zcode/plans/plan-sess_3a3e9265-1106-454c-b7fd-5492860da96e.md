## 修复：我方相位师战力面板"相位仪战力"恒为 0

### 根因
`MasterPowerEvaluator._eval_instrument()` L328 守卫 `if player_bonus > 0.0` 错误地拒绝了合法值 0。

当相位场未分配属性点时：
1. `build_player_master_dict()` 计算 `total_bonus_pct = 0` → `_player_inst_bonus_total = 0`
2. evaluator 读到此字段 = 0.0
3. 守卫 `0.0 > 0.0` = false → 走敌方回退路径 → 读不到 `equipment.phase_instrument` → 返回 0

### 修复
**文件**: `scripts/master_power_evaluator.gd` L328

```gdscript
# 改前：
if player_bonus > 0.0:
    return player_bonus

# 改后：
if master.has("_player_inst_bonus_total"):
    return player_bonus
```

### 影响范围
- 向后兼容：不影响已有相位场加成的玩家
- 不影响敌方相位师（无 `_player_inst_bonus_total` 字段，仍走回退路径）
- 修复后相位场 Lv1 未分配时相位仪战力显示 0（正确行为），分配属性点后显示实际加成
