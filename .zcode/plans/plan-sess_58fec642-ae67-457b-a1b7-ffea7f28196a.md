# 战斗界面优化网页设计稿

## 目标
针对当前战斗界面的5大痛点（信息重叠、底部拥挤、单位信息弱、能量球无解释、色彩混乱），输出一张完整的HTML设计稿，展示优化后的战斗HUD布局。

## 优化要点

| 问题 | 现状 | 优化方案 |
|------|------|---------|
| 信息层叠 | 左上面板/关号信息/战场buff多层重叠 | 左上收起为可折叠小卡片，关号居中顶部大字，buff信息下沉为战场漂浮标签 |
| 底部拥挤 | 导航栏12按钮+装备8槽挤在底部 | 底部双层分离：上层装备/卡牌槽（深紫渐变），下层导航栏（深蓝），间距拉大 |
| 单位信息弱 | 血条极小，远程血量不可见 | 我方单位上方悬浮单位卡（头像+血量+护盾），敌方单位显示方式不变但增大 |
| 能量球无说明 | 右侧蓝色冰球无任何信息 | 旁边加小label说明"相位护盾"或"兵力/能量" |
| 色彩混乱 | 蓝/绿/紫/金多色混用 | 统一深蓝（#0b0d1a）底 + 霓虹青（#00e5ff）边框 + 金色(#ffd700)高亮 |

## 最终布局（从上到下）

```
┌─────────────────────────────────────────────────────┐
│            第 49 关          00:58      ⚡1.0K 💎120 │  ← 顶部：关号+计时+核心资源
├──────────┐                                        ┌─┤
│ ☰  buffs │             ▲ 战场区域 80%              │ │
│ [展开]   │        我方单位(头像+血+护盾+buff)       │ 右侧
│          │                                         │ 能量球
│ 我的     │                                          │ (加说明标签)
│ 面板 ▼   │                                          │
└──────────┘                                        └─┘
┌─────────────────────────────────────────────────────┐
│ ◀ 装备/卡牌槽 ×8 ── 相位仪/技能/符文 ──────────▶    │  ← 上层：可操作卡牌
├─────────────────────────────────────────────────────┤
│ 背包 成长 势力 任务 商店 排行 情报 地图 设置 图鉴    │  ← 下层：导航按钮
└─────────────────────────────────────────────────────┘
```

## 颜色方案
- 底色: `#0b0d1a` 深空蓝黑
- 面板背景: `rgba(15, 20, 40, 0.92)` 半透明深蓝
- 主边框: `#00e5ff` 霓虹青（我方） / `#ff4444` 红（敌方）
- 高亮: `#ffd700` 金色（重要按钮/关卡数）
- 文字: `#e8eaed` 亮灰 / `#9aa0a6` 辅助灰
