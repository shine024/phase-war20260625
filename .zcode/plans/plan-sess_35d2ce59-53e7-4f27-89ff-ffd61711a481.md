# 补全敌方特色掉落卡方案

## 根因总结

`enemy_archetypes.json` 中 10 处掉落引用 7 个不存在的卡ID。深入调查发现两个深层问题：

1. **JSON 掉落是死代码**：`apply_capture_drops_to_archetypes()`（manifest:607）对 C段敌人**无条件覆盖** drops，JSON 的 `smg_mk2` 等从未运行时生效
2. **Boss 掉率 bug**：`_tag_tier_from_id` 用 `begins_with("boss_")`，但 boss ID 是 `cold_boss_mig`（boss 在中间），3 个 boss 掉率被误判为 8%（应为 55%）

## 改动方案（5 个改动，3 个文件 + 1 个 JSON）

### 改动 1：修复 Boss/Elite tier 判定（`data/enemy_unit_manifest.gd` ~L678）

```gdscript
# 原：begins_with("boss_") / begins_with("elite_")  → cold_boss_mig 不匹配
# 新：contains("boss") / contains("elite")          → cold_boss_mig 匹配
```
修复后 `cold_boss_mig`/`mod_boss_command`/`fut_boss_nexus` 掉率 8%→55%。

### 改动 2：掉落从「覆盖」改「追加」（`data/enemy_unit_manifest.gd` ~L607）

`apply_capture_drops_to_archetypes()` 不再覆盖 drops，改为在已有 drops 基础上追加 `captured_*`：
```gdscript
# 原：cfg["drops"] = [{"card_id": drop_id, "chance": chance}]  # 覆盖特色卡
# 新：检查已有 drops 是否含 captured_ 前缀项，若无则追加（保留特色卡）
var existing: Array = cfg.get("drops", [])
if not _has_captured_drop(existing):
    existing.append({"card_id": drop_id, "chance": chance})
    cfg["drops"] = existing
```
运行后每个敌人 drops = `[特色卡(若有), captured_*, bp_平台蓝图(自动)]`。

### 改动 3：新增 7 张特色战斗卡（`data/unified_card_table.gd`，`fut_air_regen_frame` 后）

全部 `enemy_only:true`，绑定掉落它们的敌人的时代/兵种，数值参照同时代同类 ELITE/CHAMPION 卡中位值：

| card_id | display_name | era | combat_kind | tier | 绑定敌人 | 核心数值（参照卡） |
|---------|-------------|-----|-------------|------|---------|------------------|
| `drop_smg_mk2` | MP18-II冲锋班 | 0 WW1 | 0 轻装 | ELITE | ww1_inf_storm_e | HP165 atk_l44 pow100（参照 ww1_inf_storm_e） |
| `drop_phase_lance` | 相位刺刀班 | 1 WW2 | 0 轻装 | ELITE | ww2_inf_para_e | HP195 atk_l52 pow155（参照 ww2_inf_para_e） |
| `drop_railgun` | 电磁步枪班 | 2 冷战 | 0 轻装 | ELITE | cold_inf_spetsnaz_e | HP250 atk_l72 pow235 射程3（参照 cold_spetsnaz 狙击特化） |
| `drop_mega_beam_cannon` | 巨型光束炮 | 2 冷战 | 2 支援 | CHAMPION | cold_boss_mig | HP550 atk_a440 pow300 射程99（参照 cold_sup_zsu23） |
| `drop_thunder_field` | 雷霆突击班 | 3 现代 | 0 轻装 | ELITE | mod_inf_delta_e | HP880 atk_l225 pow420（参照 mod_ranger） |
| `drop_overclock_matrix` | 超频矩阵机 | 3 现代 | 3 空中 | ELITE | mod_air_apache_e | HP980 atk_air375 pow980 射程99（参照 mod_ah64） |
| `drop_mega_particle_cannon` | 巨型粒子炮 | 4 近未来 | 1 装甲 | CHAMPION | fut_arm_colossus_e | HP1350 atk_a1000 pow480（参照 fut_arm_hovertank_e） |

每张卡含完整 22 字段（atk_l/a/air + 各自 speed/windup/active + def_l/a/air + w_light/armor/air），攻速模板沿用各兵种标准（轻装 atk_l_speed 1.5 / 装甲 0.67 / 空中 0.83 / 支援 0.5）。

### 改动 4：JSON drops 替换无效 ID（`data/json/enemy_archetypes.json`）

把 10 处无效 card_id 替换为有效 `drop_*` ID，保持 chance 不变：
- `smg_mk2` → `drop_smg_mk2`（ww1_inf_storm_e, chance 0.2）
- `phase_lance` → `drop_phase_lance`（ww2_inf_para_e, 0.25）
- `railgun` → `drop_railgun`（cold_inf_spetsnaz_e, 0.3）
- `mega_beam_cannon` → `drop_mega_beam_cannon`（cold_boss_mig 0.4, mod_boss_command 0.6, fut_inf_spectre_e 0.4）
- `thunder_field` → `drop_thunder_field`（mod_inf_delta_e, 0.3）
- `overclock_matrix` → `drop_overclock_matrix`（mod_air_apache_e, 0.35）
- `mega_particle_cannon` → `drop_mega_particle_cannon`（fut_arm_colossus_e 0.5, fut_boss_nexus 1.0）

### 改动 5：特色卡注册到 DefaultCards 缓存（`data/captured_unit_cards.gd` ~L46）

7 张特色卡是 `enemy_only:true`，`create_all()` 不收录（只取 player_card_entries）。在 `register_into_default_cards_cache()` 末尾追加注册循环：
```gdscript
# 注册 enemy_only 特色掉落卡（enemy_only 不进 create_all，需显式注册）
const SPECIAL_DROP_IDS: Array[String] = [
    "drop_smg_mk2", "drop_phase_lance", "drop_railgun",
    "drop_mega_beam_cannon", "drop_thunder_field",
    "drop_overclock_matrix", "drop_mega_particle_cannon"
]
for sid in SPECIAL_DROP_IDS:
    var sc: CardResource = UnifiedCardTable.build_card_resource(sid)
    if sc != null and DefaultCards.has_method("register_dynamic_card"):
        DefaultCards.register_dynamic_card(sc)
```
时序已验证：`_ensure_manifest_merged()`（L344）在掉落查询前同步调用此注册，`get_card_by_id("drop_smg_mk2")` 返回非 null，`grant_dropped_cards_by_id` 正常发放。

## 不做的事

- 不改 `captured_*` 缴获卡机制（仅 boss 掉率修为 55%，其余不变）
- 不改自动平台蓝图掉落逻辑
- 不改 3 个时代 GD 文件（已正确）
- 不涉及能量卡/法则卡
