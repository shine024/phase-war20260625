## 二、标准检查流程（新资产入库 / 每次大版本前各跑一遍）

### 第 1 步：机器层（全自动，5 分钟）
```
python tools/_tmp_visual_audit.py        # 240 动画+360 卡图：空帧/越界/白底/双主体
python tools/art_auto_inspect.py         # 阴影/摆幅/火光锚点/同套度 → auto_inspect_v2.json
python tools/build_unit_review_page.py   # 重建工单页（旗标自动并入；映射变了先跑 dump）
```
任一旗标 → 资产不入库或进修复单。

### 第 2 步：工单页人工层（15 分钟，只审增量）
`tools/unit_art_review.html`——筛选"机检:"旗标行 + 新增单位行；动画会动、原大图可点；
批注自动保存；导出 JSON/修复单即施工依据。**历史已批注资产由旗标回归盯防，无需重审。**

### 第 3 步：实机层（仅交互/时序类）
进关-开战-结算-面板链路实机过一遍（记录4.txt 9 类的范畴）。

### 第 4 步：入库纪律（防"改了没生效/换机丢失"）
- 改 card_icons 后：`gen_ui_thumbs.py --force --only=cards` + _thumb384 LANCZOS 手动重采样
- 改任何 png 后：`--headless --editor --quit` 重导入
- **png 不进 git**：改前备份 `.godot/art_backup_<主题>_<日期>/`，换机从备份/打包同步
