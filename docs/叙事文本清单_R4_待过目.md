## 二、时代切换仪式（独白 3 句 + 大横幅）

> 触发：进入时代首关的入战揭幕串最前，每会话一次。✅ = 已注入样例。

**L21 二战** ✅　横幅：「二 战」

- 你腕上的相位仪在发烫——更多的同伴，迷失在这场更大的战争里。

- 迷失在这里的同伴，学会了在漫长的静默里守望。

**L61 现代**　横幅：「现 代」
- 战场变成了屏幕上的坐标，可痛还是真的。

**L81 近未来**　横幅：「近 未 来」
- 钢铁学会了思考，光学会了杀人。
- 最后一批同伴就迷失在这里。他们等车队，等得最久。
