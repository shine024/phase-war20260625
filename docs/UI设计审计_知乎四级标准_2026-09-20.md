## 总评表

| 层级（文章优先级） | 结论 | 一句话 |
|---|---|---|
| 1. 便捷性 | **良好（部分）** | 点读机式悬停、Toast 体系、解锁仪式三层齐备，超多数独游水准；败在快捷键零角标、任务无一键领取 |
| 2. 易用性 | **良好（个别硬伤）** | 按钮四态/点击音/禁用原因文字全覆盖；但有 1 个实锤死交互 + 高频面板无开板反馈 |
| 3. 包容性 | **中上（部分）** | 16:10 绝对安全（expand 模式）、自带三档色盲滤镜；败在超宽屏战场偏左 + 低对比文字 |
| 4. 美观性 | **及格线上（部分）** | 字体家族统一（文章最恨的字体混杂没有）；败在颜色/字号/圆角与设计 token 三层各说各话 |

按文章评判标准，本项目整体在独游平均线之上，且最高优先级的**便捷性恰好是做得最好的**——
优先级顺序押对了。

## 一、便捷性 —— 亮点多

### 对齐文章正面教材的做法（已验证存在）

- **点读机式悬停**：全项目 69 文件 475 处 tooltip；连**锁定工位都有说明**
  （`truck_base.gd:719`"🔒 通关第 N 关解锁"）——正是文章说的"显眼位置给出引导"。
  覆盖：战斗装配槽（bottom_instrument_bar.gd:884/1055/1394/1699）、背包卡
  （backpack_card_item.gd:905）、卡牌词条（card_info_panel.gd:2697）、战场单位悬停
  0.3s 轻面板（unit_hover_info.gd:4）、改造浮卡（modification_panel.gd:321）、
  进化材料/配方（evolution_panel.gd:208/537）、商店（store_panel.gd 多处）、
  buff/连携条（combo_status_strip.gd:114 起）、技能树（phase_master_skill_board.gd:695）、
  世界地图（world_map.gd:1081 起）、移动基地（truck_base.gd:400 起）。
- **杀戮尖塔式卡旁词条**：`scripts/affix_display_format.gd:14-38` 每个词条 tag 自带
  悬停详述（含 get_detailed_description）；机制 tag 全表 `data/card_mechanism_desc.gd`
  供三处 tooltip 消费。
- **Toast 体系**：全局 ToastManager（managers/toast_manager.gd）+ 同文案合并 ×N
  （:92-110）+ 上限 5 条淘汰；119 处调用、42 文件。掉落同名合并（drop_manager.gd:126）、
  战后缴获合并单行（mvp_panel.gd:669-674）、挂机一键收取（truck_base.gd:968）。
- **解锁仪式三层**：14 步教程（tutorial_progression_manager.gd:39-54，实操未完成
  toast 拒推进）+ ~20 个一次性弹窗 FeatureUnlockPopup.show_once（user:// 去重）+
  关卡门控表 feature_unlock_schedule.gd，且**同关多项合并为一个弹窗防连弹**
  （level_progress_manager.gd:110-128）。
- **破坏性操作全有确认**：覆盖存档（title_screen.gd:231）/退出（:493）/撤退
  （main.gd:1446）/二周目（mvp_panel.gd:1035）/黑门扣能量块（world_map.gd:1903）/
  重置教学（settings_panel.gd:443）。
- **ESC 收敛**：main.gd:391-399"关最上层面板"，15+ 面板自带防"一次关两层"。
- **轻提示优先纪律**：图纸兑换"二次点击即确认"代替弹窗（modification_panel.gd:1621）；
  结算弹窗串行链防连弹（main.gd:1782-1805）；未发现"该用 toast 却弹 Modal"反例。

### 缺口 Top5

1. **日常任务奖励逐个领取**（`quest_panel.gd:491-503`，daily_task_manager.gd 无
   claim_all）——成就面板已有 ClaimAllButton（achievement_panel.gd:24）可对照，
   每天 7 次重复点击违背"能一次不分两次"。
2. **快捷键零可见角标**——keybinds.gd:15-22 六个动作 + main.gd:417-421 的 1-9 部署键
   只活在 tooltip 文字里（bottom_function_bar.gd:95-102）。文章专门夸了《朝露》
   "图标上标快捷键"，本项目只做了下半句（悬停出名称）。
3. **faction/quest/settings/leaderboard 四面板 0 tooltip**（faction/quest 有内联
   文字部分兜底）。
4. **连携/combo 系统无首次引导**——不在 show_once、不在门控表、不在 14 步教程里，
   玩家首次看到连携条无任何解释来源。
5. **不同文案 toast 不合并**——仅完全相同文本合并 ×N，密集入账时被 5 条上限挤掉。

## 二、易用性 —— 1 个实锤死交互

### 达标项

- **按钮四态**：全局主题 default_theme.tres 完整定义 Button 五态（:392-396）、
  滚动条三态（:411-414——文章原话"连滚动条都要有状态"都满足）、ItemList/Tab 选中态；
  集中工厂 panel_styles.gd:244-293 五态齐全，大量面板消费。
- **点击反馈全局兜底**：audio_manager.gd:143 node_added 钩子让**所有** BaseButton
  自动带点击音（50ms 去重防双响）+ 悬停音（60ms 节流）+ 按压缩放 0.97 回弹
  （panel_anim.gd:139-161）。
- **禁用态可辨识**：一律"灰掉+写明原因"——"⚠ 功勋不足"（store_panel.gd:440）、
  "✗需CHAMPION"（modification_panel.gd:951-969）、制造条件逐条 ✔/✘
  （evolution_panel.gd:1000-1013）、"技能点不足（通电需X点，可用Y点）"
  （phase_master_skill_panel.gd:379）。
- **选中态**：列表金色 3px 选中框（growth_panel.gd:446-459）、背包轻提亮
  （backpack_panel.gd:2570）、地图当前关加粗环+动点（world_map.gd:1063/1100）。
- **背包拖拽 = 文章辨识度标杆**：虚影跟随+稀有度外框、原格半透明、目标槽
  **可放绿框/禁放红框**、拿起/放下/失败音效全套（backpack_card_item_drag.gd:86-373）。
- 面板开合动画+音效：main.gd 17 个 overlay 全走 PanelAnim（main.gd:497）。

### 缺口（按严重度）

1. **✅ P0 死交互（已亲手核实）**：排行榜敌方相位师行**点击永远无反应**——
   `enemy_row.tscn:19` 的 RowButton `mouse_filter = 2`（IGNORE），而
   `enemy_row.gd:28` 连着 pressed → `leaderboard_panel.gd:308→414` 整条详情弹窗链
   不可达，行也无 hover 反馈。修法=删掉 mouse_filter=2 一行。
2. **CardInfoPanel 三连**：✕ 关闭钮 normal/hover/pressed 三态同一个 stylebox
   （card_info_panel.tscn:224-226，与 PanelChrome"hover 转红"标准相悖）；
   打开直接 `visible=true` 无动画无音效（card_info_panel.gd:309-351）——战场点单位
   是高频操作里唯一"静默突现"的弹窗。
3. **world_map 自建按钮只覆 normal**（world_map.gd:288/404/1418），hover 跳回全局
   青色样式观感跳变；关卡圆钮 pressed 复用 normal（:1075）按下无视觉确认。
4. **战场部署选点期鼠标无卡图虚影**（只有引导线，battle_click_overlay.gd:348-365），
   与背包拖拽标准不在一档。
5. 排行榜详情用原生 PopupPanel 无主题接入（leaderboard_panel.gd:419-422）。

## 三、包容性 —— 16:10 安全，超宽屏翻车点在战场

### 达标项

- **✅ 文章里的 16:10 事故（最左边英雄点不到）不会发生**：project.godot:60-63
  1280×720 + `canvas_items` + `expand` 拉伸只增不裁（无黑边无裁切）；
  912 个 Control 深度 1 层锚点全覆盖；背包/全出血面板监听 size_changed 重算
  （main.gd:699-759）；详情面板屏幕内 clamp（card_info_panel.gd:353、
  unit_hover_info.gd:85）；世界地图整图等比缩放适配（world_map.gd:667-697）。
- **✅ 色弱**：红绿对偶均有第二通道（数字/文字/亮度/图形），且自带
  protan/deutan/tritan 三档色盲滤镜（color_grade.gd:77-89）+ 高对比模式
  （design_tokens.gd:64-67）——超过文章要求。血条白字黑描、阵营底板双色、
  稀有度有中文名+首字母+边框宽度递进。
- **✅ 不默认用户懂图标/ESC**：菜单按钮文字+"菜单"提示 ESC（bottom_instrument_bar.gd:500）、
  帮助面板明示 ESC 与绿槽含义（help_panel.gd:130/206）、出击插页写"点击/ESC 跳过"
  （sortie_interstitial.gd:194）；世界地图有**带文字的色环图例**（实拍确认）。
- 大字号模式 content_scale_factor=1.25 + 底栏 40px 护栏 + 顶栏右锚防掉屏。

### 缺口（按危险度）

1. **⚠ 21:9/32:9 战场裸屏**：阵型带硬编码 `BATTLE_X0=40/BATTLE_X1=1240`
   （card_grid_battle_layout.gd:17-18）+ 背景图 1280 宽锚 x=0 不拉伸
   （battlefield.gd:41/605）→ 超宽屏下全军偏左、右侧 1/4 屏无背景。
   对放置观战游戏这是核心画面。
2. **⚠ 满血单位 HP 数字淡到 45% alpha**（unit_hp_bar.gd:83/397）——开局全场满血
   是常态，而 HP 白字恰是敌我识别兜底通道。
3. **⚠ COLOR_TEXT_FAINT ≈2.1:1 对比度承载功能信息 22 处**（design_tokens.gd:204）：
   商店售罄名（store_panel.gd:530）、情报未拥有项（intelligence_hub_panel.gd:298）、
   卡牌次要字段（card_info_panel.gd:760）——深底深字，"体检测视力"。
4. **⚠ 6px/9px 战斗字号**：状态层数 6px（unit_hp_bar.gd:552）、战力/档位 9px 且用
   FAINT 色（geo_shapes.gd:189-198）；draw_string 路径不受大字号模式影响。
5. **⚠ 血条"黄 vs 红"档位**色盲滤镜开启前色相趋同（unit_hp_bar.gd:58-67），
   有底板+白字兜底故列末位。
6. 分辨率选项仅 16:9 四档（settings_panel.gd:23）；实拍确认 1366×768 不破版。

## 四、美观性 —— 骨架好，执行漂了

### 达标项

- **✅ 字体**：Rajdhani(拉丁/数字) + 思源黑体(中文) 双家族配对，全无衬线，
  无行书草书混用（文章最痛恨的反例没有）；中文兜底链 design_tokens.gd:317-349。
- **✅ 主题架构**：全局唯一 Theme（default_theme.tres，33 个 StyleBoxFlat 覆 14 类
  控件），73 个场景 0 个私有 theme。
- **✅ 主色调低饱和**：面板底色全部深海军蓝系（V<0.17，拾色器安全区）。
- 面板底色/正文白字对比达标；MOTION 三档动效 token 存在。

### 缺口（数字化）

1. **❌ 670+ 种颜色值**：金色 ≥5 套（DT.COLOR_GOLD / (0.85,0.75,0.35) /
   (0.9,0.7,0.3) / (0.941,0.706,0.161) / #FFD700）；血条绿 4 套
   （unit_hp_bar.tscn:20 (0.2,0.75,0.35) vs card_info_panel.tscn:32 (0.247,0.902,0.427)
   vs DT.COLOR_HEALTH (0.2,0.9,0.4) vs GREEN_BRIGHT (0.3,0.92,0.5)）；
   危险红 ≥5 套。
2. **❌ #FFD700 违禁色仍在用**：master_power_evaluator.gd:39-44 段位六色全纯饱和
   （含项目测试 ui_batch2_validation.gd:189 明令禁止的 #FFD700；faction_row.gd:21
   注释自己都写了"纯金大面积文字刺眼→已换 DT.COLOR_GOLD"）。
3. **❌ 字号 17 种 vs token 7 档**（design_tokens.gd:26-32 声明 10/12/14/16/20/32/48，
   其中 32/48 零使用；实际极差 10→88px；奇数 11/15 违规 4 处，10/11px 在
   card_ui_preview.gd:519/558）。
4. **❌ 圆角 9 种 / 边框 3 种 / 阴影 7 种**；token 规定(圆角6/边框2)与全局主题
   (圆角8/边框1)自相矛盾，234 个场景手写 StyleBoxFlat 圆角众数却是 4/5——三层各说各话。
5. **⚠ 弹窗三套骨架**：PanelChrome 统一框架（16 家接入）vs 四大养成面板+card_info
   手写（theme_override 密度 Top4：215/124/116/91 行）vs leaderboard 第三套
   skill_panel_style.tres（圆角4/边框2）——同一游戏三种弹窗观感。
6. 高饱和残留：afk_panel.tscn:18 实心红按钮、card_info_panel.tscn:32 亮绿实心条、
   主题进度条填充全饱和青 (0,0.94,1) 大面积使用。
7. 清理项：assets/fonts 两个死字体文件（data_font.ttf / title_font.ttf，无引用）。
