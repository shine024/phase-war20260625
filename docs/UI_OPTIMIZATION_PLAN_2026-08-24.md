## 0. 依据与前提

**理论依据**（知乎《独立游戏不重视UI设计的后果有多灾难？》，PDF 存 docs/，要点已沉淀进 ui-review skill）：

- 四要素优先级：**便捷性 > 易用性 > 包容性 > 美观性**，冲突时砍低保高
- 提示分层选型：**能 Toast 不用 Tips，能 Tips 不用 Modal**
- 两个提前预见：多物品同时获得的聚合提示、新功能首解锁的一句话 Modal
- 终极验收法：**拿给不玩游戏的人看，他看懂了才算成功**

**执行铁律**（沿用批次二流程，每批必走）：

1. 改前查 ui-review 技能"接入点地图"，能复用不新造；
2. 颜色/字号走 `DesignTokens`，样式走 `PanelStyles` 工厂，禁止新增字面量；
3. 每批跑 `tests/ui_p1_validation.gd` / `ui_batch2_validation.gd`（新文件加进 CHANGED_SCRIPTS）
   + `tests/ui_unified_check.gd`，全绿才收批；
4. 肉眼验收五问：悬停有说明？点击有反馈？失败给原因？ESC 逐层退？换分辨率不破版？
5. CHANGELOG 记批次 + 本计划勾选。

## 2. 批次规划（严格按四要素优先级排序）

      对照 AGENTS.md 停用清单逐条核销 `help_panel.gd` 全文。
      这是"界面内手册说谎"级 bug，优先级最高。
- [x] **B2 tooltip 攻坚**（M，拆 5 小批，每批一个面板）✅ 2026-08-24：五面板 18 → 63 处（growth 12 / store 11 / evolution 13 / modification 15 / card_info 12）：
      growth（1 处起步最惨）→ store → evolution → modification → card_info。
      规则：每个图标、词条标签、数值行悬停即解释；词条文本复用
      `AffixDisplayFormat.fmt_player_affix_tags`，战场 buff 复用 `UnitStatusCollector`
      数据源，不新造数据链。
- [x] **B3 失败反馈具体化**（M）✅ 2026-08-24：五路径普查，实际缺口仅商店符文/情报购买（原仅红闪）——补三处带原因 toast；新增 _show_buy_error/_show_buy_warning 助手：全量排查装备/购买/进化/改造/部署的失败路径，
      toast 必须带**具体原因**（"相位仪槽位已满"而非"操作失败"）+ `error` 音效。
      参考批次二"装备失败反馈"先例。
- [x] **B4 首解锁弹窗扩面**（S-M）✅ 2026-08-24：3 → 8 key（+runeword/faction_level_up/intel_hub/skill_tree/multi_instance）：候选 key——战场回收（v6.15 击杀修复新机制）、
      情报中心、势力声望、挂机结算、军衔晋升。一律 `FeatureUnlockPopup.show_once`，
      一句话说明，能 Tips 不 Modal。
- [x] **B5 高频路径步数审计**（M，先调研后动手）✅ 2026-08-25 调研完成，结论：链路健康，
      无"能一次不分两次"违规；唯一摩擦=空槽批量装配，列为 B5b 建议案（见下）。
      - **买卡**：T/底栏开商店(1) → 势力tab(0-1) → 购买(1) = 2-3 操作。一步到位：无确认弹窗，
        买完即入背包（InstanceRegistry 实例化）+ toast，✓。
      - **装备**：B开背包(1) → 点卡(1) → 装备按钮(1) = 3 操作/卡；装备自动入首个空绿槽 +
        自动关弹窗 ✓；或拖拽到指定槽 1 手势/卡。Esc 一键关面板（键盘零点击）。
      - **部署**：战中数字键1-9直选第N个有卡绿槽(P2-14 已做，免底栏寻路)(1) → 点战场位置(1)
        = 2 操作，RTS 标准下限，不可再合并 ✓。Enter/Space 一键开战 ✓。
      - **批量出售**：**不适用**——出售/拆解已随蓝图体系移除（2026-08-22），重复卡=独立养成
        实例（InstanceRegistry 铁律），非垃圾资产，背包无清理需求。
      - **批量装配（B5b 建议案，未实施）**：9 空绿槽逐张填 = 9×3 操作/9 拖拽，是全链路唯一
        重复劳动。建议背包工具栏加「一键填槽」：按战力降序取未装备战斗卡实例填空绿槽
        （复用 `_try_equip_card` 首选空槽逻辑），满槽/无卡走 toast。涉及 backpack_panel
        （并行会话热点文件），待用户拍板后单独成批实施。
