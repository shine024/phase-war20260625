## 候选一：`assets/map/black_sun.png`（793×790 RGBA）

**资产评估**：黑日主题圆形构图，与 MAP_SCHEME 11「黑日战线」主题强相关（质检报告评分档：质量好）。

**接入点位**：`scenes/world_map.gd` 黑门入口热区（约 L528-538，`gate_entry` Control 创建处，v27 黑门巨环）。
当前黑门只有程序绘制巨环 + tooltip 文案，无专属图腾——此图可作黑门入口的图标纹理：
- 挂法：`gate_entry` 下加 TextureRect 子节点（`texture = load("res://assets/map/black_sun.png")`），
  尺寸标定约 56~72px（对齐既有节点盘径 v28 口径 34px 的 1.7~2 倍），居中锚定巨环圆心 `EndlessBlackgateRef` 巨环位置（`_gate_pos()`）。
- 观感纪律：alpha 底图直挂（图自带透明通道），勿加 modulate 染色；解锁态/未解锁态用 modulate.a 区分（0.9/0.45）。

**改动面**：`scenes/world_map.gd` 单文件单处（gate_entry 构建块 + 1 个 const preload）；零数据/零存档。
**预估工时**：0.5~1 小时（含实机截图验收 + v6.19.3 UI 体检探针复跑）。
**风险**：低。失败回退=删一处子节点构建代码。

## 候选二：`assets/map/mountain_bunker_marker.png`（866×1052 RGBA）

**资产评估**：山体基地侧视图立牌，竖构图带透明底，作"移动基地驻停点"图标语义清晰
（当前基地标记=v26.20 起 22px「移动光点」金点白芯，见 world_map.gd L1612 注记）。

**接入点位**：`scenes/world_map.gd` 移动基地标记绘制处（L1612 附近 `_process`/绘制链，停靠态分支）。
- 挂法：停靠态（非行驶）时在停靠关节点旁上方挂 Sprite2D/TextureRect，缩放标定到 **高 44px** 左右
  （原图 1052 高，缩放系数 ≈0.042；底部锚点对齐节点盘上缘，避免遮关卡数字）；
  行驶态维持现有金点脉冲（两态切换 = 拖曳感 + 到站感）。
- 观感纪律：`UnitOutline` 不适用（非战场单位）；用 modulate.a 呼吸或常亮，禁发光叠加（地图层无 HDR）。

**改动面**：`scenes/world_map.gd` 单文件（标记状态机分支 + 纹理 const + 一次标定常量）；零数据/零存档。
**预估工时**：1~2 小时（含锚点/缩放标定的实机迭代——此项是大头）。
**风险**：中低。主要风险是遮挡停靠关节点数字/桥线，需实机调锚点；失败回退=删分支恢复金点常显。
