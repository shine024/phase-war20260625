当前问题 → 优化方案
❌ 当前问题
  • 金色雕花边框与深色科技 UI 风格冲突
  • 稀有度颜色超过 6 种且无图例说明
  • 荧光绿选中态过于刺眼，视觉攻击性强
  • 青色滥用导致重点不突出
  • 红黄蓝绿四色底部按钮像视频播放器
  • 不同页面同一颜色含义不一致
✓ 优化方案
  • 统一为简洁科技线条边框 + 稀有度渐变光晕
  • 稀有度精简为 4 级，附图例和说明
  • 选中态使用主强调色青色 + 柔和外发光
  • 青色仅用于关键数据和选中态，控制使用频率
  • 底部控制统一为单色图标按钮
  • 每种颜色有明确语义，全局一致
使用规则 Usage Rules
1
主强调色 (#00D4FF) — 仅用于：选中态、CTA按钮、关键数值、进度条。全站最多出现 20% 的面积。
2
次强调色 (#A855F7) — 仅用于：符文系统、传说稀有度、特殊标记。不与主强调色同时大面积出现。
3
金色 (#F59E0B) — 仅用于：资源数字、等级标识、神话稀有度。不作为交互元素主色。
4
绿色 (#22C55E) — 仅用于：正面数值变化、可安装/可操作状态、普通稀有度。不用于已装备项的高亮。
5
红色 (#EF4444) — 仅用于：伤害数字、敌方单位、删除/关闭操作、负面效果。不用于装饰。
