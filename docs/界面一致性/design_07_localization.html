副标题样式规则
  • 中文标题使用 H2 字号 (24px)
  • 英文副标题使用 H3 字号的 60% (约 11px)
  • 英文副标题全大写 + letter-spacing: 1.5px
  • 中英文之间用居中点 · 分隔（非破折号或斜杠）
  • 英文副标题颜色为 dim (#5A6478)，不抢主标题视觉

数值格式化规范 Number Formatting

🔢 百分比

  • 增益：+30%
  • 减益：-15%
  • 固定值：+200
  • 禁止使用小数：× 0.3 → ✓ 30%

📊 大数字

  • 资源数量：9,722
  • 战力值：547
  • 超过 10000 使用缩写：1.2W
  • 禁止科学计数法：× 1.2e4

📏 等级与星级

  • 等级：等级 16（已满）
  • 星级：★★★★★★★
  • 阶段：M0/9（仅技术标识）
  • 禁止：Lv.16 MAX

⏱️ 时间与冷却

  • 倒计时：00:45
  • 冷却时间：3 秒
  • 持续时长：15 秒
  • 禁止：CD: 3s

❌ 当前问题
  • 代码变量名直接显示在界面上
  • 标题中英混排格式不统一
  • "rare" 等英文单词出现在中文界面
  • "Lv." 和 "等级" 混用
  • 拼写错误：regan → regen
  • 口语化表达："回血"、"攻速"
  • 无统一的术语对照表
✓ 优化方案
  • 所有变量映射为中文化描述
  • 标题格式统一为 "中文 · ENGLISH SUBTITLE"
  • 建立术语对照表，全局强制执行
  • 统一使用"等级 N（已满）"格式
  • 修复所有拼写错误
  • 使用正式游戏术语替代口语
  • 新增文案时必须在术语表中查找
