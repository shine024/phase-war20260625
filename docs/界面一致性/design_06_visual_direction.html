视觉方向 Visual Direction

Phase War 统一美术风格定位 · v1.0

三种风格方向对比
方向 A：奇幻 RPG
金色雕花边框、魔法光效、中世纪字体。适合传统卡牌游戏，但与 Phase War 的军事科幻主题不符。
方向 B：军事科幻 ✓ 推荐
简洁科技线条、霓虹光晕、冷色调。与现有 UI 深色背景一致，符合战场/机甲主题。
方向 C：写实军事
迷彩色、金属质感、硬朗几何。适合模拟战争，但缺乏科幻感和卡牌游戏的视觉吸引力。
✓ 推荐方向：军事科幻 + 简洁科技线条
核心理念：保留现有深色科技 UI 的基础，废弃所有奇幻元素（金色雕花边框、魔法光效），统一为简洁的科技线条风格。
视觉关键词：霓虹光晕 · 渐变边框 · 半透明面板 · 几何切割 · 冷色调
应用场景：卡牌边框、弹窗装饰、按钮高光、选中态发光、稀有度标识

视觉规范细则 Visual Guidelines

🎨 边框规范

  • 所有边框使用 2px 实线或渐变描边
  • 圆角统一为 8-12px
  • 禁用雕花、卷草、魔法阵等装饰元素
  • 选中态使用外发光而非加粗边框

✨ 光效规范

  • 光晕颜色与稀有度/语义颜色对应
  • 外发光强度：选中态 > 稀有度 > 普通
  • 禁止使用彩虹渐变光效
  • 光效过渡时间：200-300ms

🖼️ 背景规范

  • 主背景使用纯色或极淡渐变
  • 战场背景可保留但需降低饱和度
  • 弹窗背景使用半透明深色 (#1A2236 @80%)
  • 禁止使用高饱和度插画作为 UI 背景

🔷 图标规范

  • 导航图标：线性风格，2px 描边
  • 单位图标：统一比例，居中显示
  • 状态图标：使用语义颜色（绿/红/黄）
  • 禁止混用写实/卡通/像素三种风格
