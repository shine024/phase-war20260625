PHASE WAR · v7.x · 改造站 · 默认态原型

◆ 默认态（未选模块）设计要点

  • 核心思路：右栏在玩家未选中改造模块时，承载当前单位的完整概览——进来就能看到"这单位多强、装了啥、还能装啥"，不浪费空间。
  • 单位头部：48px 缩略图 + 名字 + 实例号 + 三标签（时代/兵种/档位），一眼锚定当前编辑对象。
  • 战力评分块：大字 1248 + OVERLORD 档位标识 + 下方 5 档进度条（已过档淡色、当前档 cyan 高亮+脉冲点），战力位置一目了然。
  • 基础属性 6 格：HP / 三维攻击 / 装甲防御 / 移动速度，HP 用绿色强调。比中栏单位条更详细，作为"查看"层。
  • 已装改造列表：2 行已装模块，每行带Hover 显卸载按钮（默认半透明，悬停变红）。这就是原设计"图1"对应的状态——右栏展示已装列表。
  • 空槽位引导：虚线框 + 脉冲 + 号 + "还有 7 个空槽位"，可视化剩余容量。
  • 底部 CTA：cyan 渐变引导块 + 箭头指向左方改造库，明确告诉玩家下一步操作。
  • 中栏调整：因右栏承接单位信息，中栏原"单位基础面板"改为极简一行单位条（缩略图+名+档位+战力），避免重复；腾出空间给改造库列表显示更多行。
▸ 状态切换演示：点击右栏顶部的「单位概览 / 模块详情」tab 可对比两个状态。实际游戏中切换由"Hover/选中中栏模块"自动触发，此处 tab 仅作 mockup 演示。
