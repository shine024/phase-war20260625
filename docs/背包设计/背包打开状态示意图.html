为什么保留相位仪栏
  • 装配主链路：背包卡 → 拖到底部绿槽，栏藏了链路就断了
  • 松手前判定沿用红绿语义：绿框可放置 / 红框禁止（与批次二一致）
  • 符文同理：符文页拖入紫色符文槽，无需再开其它面板
示意说明：布局与配色取真实值——视口 1280×720（project.godot）、面板 1180×560（backpack_panel.tscn）、底栏高 64 悬浮卡片样式（BU-1）、钢铁壁垒 8绿+4符 槽位、色板取自 design_tokens.gd。卡面引用 assets/card_icons/player/ 真实游戏图（无专属图的卡按游戏同款规则回落到兵种代表图）。费用 / Lv / 战力 / 各页数量为示意数据，仅用于排版演示。
