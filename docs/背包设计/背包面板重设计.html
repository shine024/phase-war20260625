战斗卡 · 设计要点

  • 大卡面 96×138：比原来 80×120 更大，承载更多视觉信息（5星点 + 兵种图标 + Lv + 战力）。
  • 顶部稀有度色条：传奇/神话加粗到 4px，普通 3px，建立视觉层级。
  • 左上角能量 cost：切角小标签（青色），统一能量卡认知。
  • 右上角兵种色块：8 兵种独立配色 + Unicode 兵种符号（◈ 装甲 / ◎ 炮兵 / ↑ 防空 / ✈ 空军 等）。
  • 5 星点 + #序号：星点紧跟养成系统；同名卡用 #1/#2/#3 区分实例。
  • 底部信息条：Lv.X · 改Y/9 · 战力，战力数字加粗白色突出。
  • EQUIP 绿色徽章：已装备到相位仪的卡左上有醒目标记。

改造 · 设计要点

  • 左侧粗稀有度色条（4-5px）：改造的视觉签名，区别于战斗卡的顶部细条；传奇/神话加粗到 5px。

  • 关键效果高亮：青色 monospace 显示效果数值（+30%/×1.18），让玩家快速扫读。
  • 原型名斜体：底部 italic 显示真实武器原型（M829A4 / Chobham），增加沉浸感。

相位仪 · 设计要点

  • 水平条带布局（区别于其他 Tab 的网格）：相位仪数量少（≤30）但信息量大，水平展示承载更多属性细节。
  • 三列网格：左列星级+名字（140px）+ 中列槽位可视化+属性（自适应）+ 右列主动能力+操作（200px）。
  • 槽位格子可视化：用 12×14 像素小格表示槽位，绿色=战斗卡槽、紫色=符文槽、虚线=空槽。一眼看清容量。
  • 当前装备高亮：金色边框 + 左侧金色 3px 色条 + 金色辉光，让当前装备的相位仪在列表中突出。
  • 主动能力 chip：7★ 相位仪有主动能力，用金色 chip 显示能力名+效果，无能力的用灰色"无主动能力"chip。
  • 星级点阵：7 颗 12×12 星点（不是 5 颗），符合相位仪 1-7★ 的设定，亮的星点带金色辉光。
  • 势力/通用标签：势力专属用青色高亮势力名，通用/初始用灰色，掉落用"掉落"标识。
