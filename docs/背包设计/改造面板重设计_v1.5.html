◆ v1.5 三大改动方向（可落地性 + 布局优化 + 视觉打磨）

一、可落地性修正（消除 v1.4 与代码的脱节）

  • 单位 ID 穿帮：foe_fut_nexus#4（敌方前缀，不可能在玩家名册）→ fut_arm_nexus#1（玩家实例）。源：data/unified_card_table.gd:1513 "虚空领主" era=4 combat_kind=1 power=1590
  • 5 档进度条门槛错位：GRUNT 标 150 等 → 按真实阈值 [150, 260, 420, 720] 重新标注（GRUNT<150 / VETERAN 150+ / ELITE 260+ / CHAMPION 420+ / OVERLORD 720+）。选中单位 power 1590 → OVERLORD，前4格 passed、第5格 current。源：data/power_tiers.gd:60 POWER_THRESHOLDS + line 26 enum Tier
  • 资源条矛盾：删掉"当前战力档 ELITE·T2"格（与选中 OVERLORD 单位矛盾），该信息由右栏承载。补充"研究点 847"（致命精通 cost_research=400 够用）。
  • 致命精通成本：原"纳米 64"（偏低）→ 纳米 200 + 研究 400 + 等级 3。源：data/modification_modules/enhancement_mods.gd:211 enh_crit_dmg
  • APFSDS 属性错误：原"×1.3 / 冲突组 apfsds" → ×1.6 / conflict_group="ammunition" / 对装甲+30%。源：data/modification_modules/armor_mods.gd:150
  • 烟幕弹冲突组：原"radar" → countermeasure（missile_dodge=0.30 经 v7.x 重映射为闪避+30%）。源：data/modification_modules/anti_air_mods.gd:108 AA_09_SMOKE_LAUNCHER
  • "卸载"按钮 → 改为"替换"：BlueprintManager 无 uninstall API（只有 replace_modification / set_mod_enabled）。v1.5 不补 API（涉及资源返还规则，属独立设计决策），按钮文案对齐 replace_modification 语义，hover tooltip 注明"原消耗不返还"。源：managers/blueprint_manager.gd:1074
  • "查看完整效果模拟 →" 去向：v1.4 悬空 → v1.5 定义为底部台抽屉展开（不弹新面板），显示完整 effect key 列表（走 ModEffectLabels.translate）+ 同类已装对比 + 战力预估。源：scripts/ui/mod_effect_labels.gd:15

二、布局再优化（回收 v1.4 被右栏挤掉的 280px）

  • 右栏三档折叠：顶部 col-head 加折叠按钮，三档切换（点击循环 完整→紧凑→收起→完整）：

  • （可选）收起态 hover 浮卡：右栏收起时，hover 名册行弹 180px 迷你浮卡（战力+5档+已装计数），不损失信息可达性。本稿未画，待确认是否需要

  • 状态体系统一（核心）：5 种状态规范化，档位不足从灰改琥珀色（与冲突红区分）：

  • 选中态强化：改造库行左边框 3→4px + 顶边光带 + 背景 8%→12%；名册选中行用兵种色左边框（装甲蓝/步兵红/空军青/炮兵橙），一眼区分 combat_kind。
  • 统一图标体系：所有 mod-ico 用稀有度首字母（C/U/R/E/L/M）+ 稀有度色边框 + 兵种色淡底。颜色+字母双重编码，色弱友好。已装列表图标同规则缩小。

  • 动效（克制）：选中行 translateX 2px / 右栏折叠 200ms / 安装按钮按下 scale 0.97 / 仅"可安装"绿点呼吸，其余静态。
  • 键盘交互补全：页脚 5 键（CLICK/↑↓/TAB/SPACE/ESC），焦点行 2px cyan outline 区别于选中态左边框。注：↑↓/TAB 需在 modification_panel.gd 实现 _gui_input，当前仅 SPACE/ESC 接近可用
