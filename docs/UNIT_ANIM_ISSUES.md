## 十二、空中单位垂直动态：起飞爬升 + 俯冲投弹（2026-08-30 晚，v25）

用户提议给空中单位加"升空/俯冲投弹"拉开与地面单位的差异，已实现（`card_grid_unit_visuals.gd`）：

1. **起飞爬升**：空中单位首次入场从地面线爬升到巡航高度（0.75s SINE-EASE_OUT），投影从满影渐变到淡影。
2. **俯冲投弹**：开火时俯冲压向地面（0.14s 俯冲 → 0.06s 投弹窗口 → 0.30s 爬回），重武器（曲射/火箭/导弹族）俯冲更深（0.78 vs 0.55 巡航高度）；俯冲中再次开火不重启（连续射击=低空扫射观感）；x 冲撞减半防对角线过冲。
3. **投影联动**：影子跟随真实高度（爬升→缩小变淡、俯冲→变大变浓），`aim_pos_for` 改为跟随目标**实时**高度（弹道瞄俯冲/坠落中的目标当前视觉位）。

**工程要点**：垂直动态全部走 `_air_dy` 高度补偿 meta，由 `advance_idle_motion` 合成 `position.y = base_y + dy - bob`——起飞/俯冲 tween 只写 meta 不碰 position.y，与待机浮动（也写 position.y）零冲突；死亡坠落前杀 `_air_vert_tw` 并清 `_air_dy`。`_apply_idle_motion` 的 base_y 对空中单位改取 `-巡航高度`（此前取当前 y，起飞动画会让基准漂移）。重应用（换形态）已在空中则满高度归位不重放起飞。
