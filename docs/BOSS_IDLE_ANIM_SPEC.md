# BOSS 待机帧动画生成规格(P2)

> 交付目标:`assets/effects/unit_anims/<unit_id>/idle_f0.png ~ idle_f5.png`
> 生成后零代码接入——`BossIdleAnim.attach()` 自动检测并播放,无帧图自动回退程序化待机。

## 帧规格(硬性)

| 项 | 要求 | 原因 |
|---|---|---|
| 分辨率 | **与对应卡图完全一致**(当前卡图 512×512) | 归一化缩放按纹理宽度计算,分辨率不同会跳尺寸 |
| 帧数 | 6 帧(f0~f5) | 6fps 循环 ≈ 1s 一个呼吸周期 |
| 底色 | 透明 PNG | 叠在战场格子上 |
| 构图 | **以现有卡图(vis_enemy_XXX)为基准**,帧间仅细微动作差 | 与稀有度框/军衔条/角标对齐,构图变了整套 UI 错位 |
| 动作设计 | 一个完整循环:f0 静止 → f2 最大位移 → f4 回落 → f5≈f0 | 循环无缝 |
| 位移内容 | 悬浮单位:上下 3~8px;坦克:炮管微抬/回;人形:披风/呼吸起伏;**主体轮廓不动** | 帧间漂移是大体量单位最容易被原谅的,小位移即可 |
| 风格 | 与现有卡图同风格、同色板、同光影方向 | 全项目风格统一 |

## 生成 Prompt 模板(agnes-image)

```
以这张图为基础(附 vis_enemy 对应卡图),生成同一角色的待机动画第 {N} 帧:
- 角色主体、构图、配色、光影与基础图完全一致,只有 {动作描述} 有细微变化
- 透明背景 PNG,512x512
- 第{N}帧的动作幅度:0%,33%,66%,50%,20%,0%(共6帧一个循环)
```

## 验收

帧图放入目录后跑:
```
godot --path . res://scenes/tools/battle_audit.tscn -- level=5
```
boss 关卡截图核对;或直接开一局有相位师的战斗目视确认 6fps 循环无跳变、构图无漂移。
