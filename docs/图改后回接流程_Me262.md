# Me-262 手改图回接流程（外部工具改图后照此跑）

> 场景：用户用外部工具（Photoshop/GIMP 等）手改 Me-262 卡图（v30.6，2026-09-13）。
> 本文档 = 改完之后的全部收尾步骤。做完即闭环，无需再动代码。
> 当前已部署基线：第五轮纯素涂装版（零违禁符号，boot ALL PASS，备份 sha16 `529507c19c60deb6`）。

---

## 〇、先弄清你改的是哪个文件（决定走路径 A 还是 B）

| 你手改的文件 | 走哪条路径 |
|---|---|
| 一张 **白底大图**（1024 左右，还没转透明） | **路径 A**（推荐）：存回源图目录，全管线自动跑 |
| `assets/card_icons/enemy/ww2_air_me262.png`（512×512 透明底成品） | **路径 B**：只补翻转+缩略图 |

两条路径最后都要跑 §三 的"锚点→导入→验证→打包"四步。

---

## 一、路径 A：白底源图 → 全管线

### 1. 存文件

把你改好的白底图（扣干净背景保持**纯白**、主体朝左）覆盖存为：

```
docs/待生成卡图_r5试验机/ww2_air_me262.png
```

> 提示：`ww2_air_me262_v7_sharkmouth.png`（鲨鱼嘴+零十字）和 `ww2_air_me262_v8_tiger.png`
> （虎头+鲨鱼嘴，机翼带一处暗十字印）在同目录留档，可直接拿去当手改底稿。

### 2. 部署（白底转透明 + 512 正方 88% 留白 + 敌我成对 + 缩略图）

```bash
cd "/d/godotplay/godot fair duel/phase-war"
python -u tools/_deploy_r5_jets.py
```

预期输出 `OK ww2_air_me262: enemy+player 512x512 (...) thumbs=['ok','ok','ok','ok']`。

---

## 二、路径 B：直接改了 512 成品

改完 `assets/card_icons/enemy/ww2_air_me262.png` 后，补我方翻转版与缩略图：

```bash
cd "/d/godotplay/godot fair duel/phase-war"
python -u tools/_reflip_edited_card_icon.py ww2_air_me262
```

> 脚本会对非 512×512 正方形打警告——成品体系（卡框/战场脚锚）假定正方形，收到警告请回改。
> 顺手工具：流星或其它任何卡同理，`python tools/_reflip_edited_card_icon.py <card_id>`。

---

## 三、收尾四步（两条路径都要）

### 3. 脚部锚点（轮廓变了才必须跑；不确定就跑，幂等）

```bash
python -u tools/generate_card_foot_anchors.py
```

> 改后用 `git diff data/card_foot_anchors.gd` 看——只有 ww2_air_me262 两行变化即正常。

### 4. 资源导入（必跑！跳过则运行时回退占位图——v30.6 实证坑）

```bash
"/d/Downloads/Godot/Godot_v4.5.1-stable_win64.exe" --headless --rendering-driver opengl3 --path . --import
```

### 5. 运行时验证

```bash
"/d/Downloads/Godot/Godot_v4.5.1-stable_win64.exe" --headless --rendering-driver opengl3 --path . res://tests/_tmp_r5_content_boot.tscn 2>&1 | grep R5Content
```

期望最后一行 `[R5Content] ALL PASS`（含"ww2_air_me262 未解析到专属卡图/卡图未入资源系统/脚部锚点"三项断言）。

### 6. 美术全量基线重打包（铁律）

```bash
python -u tools/pack_art_backup.py
```

输出 zip 路径 + sha16，把 sha16 记到 CHANGELOG/提交说明。本机无 F 盘时自动落
`D:\godotplay\_art_backup\`，发行机侧记得同步到权威目录 `F:\godot fair duet\_art_backup\`。

## 四、验收清单（改图时的硬标准）

- [ ] **无违禁符号**：机尾/机身/机翼零铁十字、十字形印、卐字、国籍徽章、编号（含暗淡的、像污渍的）
- [ ] 敌方图**机头朝左**（我方版是翻转，不用管）
- [ ] 背景纯白（路径 A）/ 透明（路径 B），512×512 正方形
- [ ] 虚构标记（虎头/鲨鱼嘴之类）可选，有则不得带出违禁符号
- [ ] 跑完 §三 后 boot ALL PASS
