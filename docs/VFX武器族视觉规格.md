# VFX 武器族视觉规格（v17 验收标准）

> 本文档是"开火/命中特效像不像真的"的**验收标准**，与 `data/weapon_visual_profiles.gd` 的
> PROFILES.spec 字段同步维护。每次跑完全矩阵审计（见文末工作流）后，对照本文逐格打分；
> 不合格的格子按"所属层"回溯到对应实现文件修，而不是直接调粒子参数补丁。

## 为什么需要这份规格

历史上 VFX 修复是症状驱动的（读图反馈 6/10 → 调参数 → 下次别处又露馅）。根本原因：
1. **没有规格**——"真实"没有定义，检查变成"看哪里不顺眼修哪里"；
2. **分派键有歧义**——weapon_type 双枚举在 1/2/3 撞值，各调用点各自猜域；
3. **检查靠抽查**——155 个武器名 × 5 条渲染路径 × 敌我，人眼看不全。

v17 起的解法：**武器名优先解析器**（`WeaponVisualProfiles.resolve_visual_wt`，名字是唯一
无歧义信号；域名无信号时按敌我域兜底）+ **12 族视觉档案** + **全矩阵截图审计**。本文是
其中"规格"一环。

## 通用真实度原则（全族适用）

1. **比例锚定**：特效尺寸必须相对单位读数合理——轻武器枪口火 ≤ 单位高度的 1/4；
   火炮级爆炸直径 ≈ 单位高度的 1-2 倍。审计截图自带 64px 参考框与 100px 标尺。
2. **时长分层**：火花一闪 0.15-0.4s；爆炸火球 0.45-0.6s；焦痕/弹坑是"证据"，1s 以上或
   持久。所有层次不许"瞬间消失"（撞墙感）也不许"过久糊屏"。
3. **方向性**：枪口火沿射击方向锥形喷射；命中火花从弹着点向外放射；穿透类必须有
   入口/出口的方向证据（谁打谁、从哪打来一眼可辨）。
4. **开火与命中形态一致**：激光枪口是白青喷射流、命中就必须是烧灼光斑+焦痕，不许
   开火像能量弹、命中像炸药（v17 修的 LASER(8) 漏出重型域 bug 即此类）。
5. **敌我辨识靠环色不靠火花**：命中环混攻击方阵营色（我方青蓝/敌方橙红），火花/碎片
   保持武器本色——武器辨识优先，阵营信息不喧宾夺主。

## 名字解析审计（防"新武器漏配"）

- 解析优先级：签名精确表（card_resource._WEAPON_NAME_TRAJECTORY_OVERRIDE 同源）→
  视觉关键词（激光/磁轨/等离子/导弹/火箭/高炮/曲射/霰弹/光束/轻动能捕获）→ 域感知 wt 兜底。
- **wt_fallback 名单 = 视觉身份未确定的新武器**——审计页高亮列出。当前 10 个：
  爆破装药、指挥系统、25mm M242大毒蛇、能量护盾发生器、40mm榴弹、相位刃、
  守护者防空、闪电防空、雷霆防空、终焉防空。
  - "xx防空"（无炮/导弹后缀）与"40mm榴弹"是**真缺口**，建议后续给名字或数据补语义；
  - 指挥系统/护盾发生器等辅助系统名走 wt 兜底是**正确行为**。
- smoke 断言：兜底占比 ≤10%（当前 6%）。新增武器名若含枪/炮/弹语义词自动入族，
  无语义词才进兜底名单。

## 审计工作流（每次改 VFX 后跑）

```bash
# 1. 截图全矩阵（需真实渲染，约 1 分钟，勿用 --headless）
"$GODOT" --path . res://scenes/tools/vfx_audit_matrix.tscn

# 2. 浏览器打开审查页，对照上表逐格检查
#    tools/vfx_audit_review.html   （截图在 docs/vfx_audit_shots/）

# 3. 回归锁（headless 秒级）
"$GODOT" --headless --rendering-driver opengl3 --path . --script tests/weapon_visual_profiles_smoke.gd
```

审查发现问题时按层回溯：

| 症状 | 大概率病根层 | 文件 |
|---|---|---|
| 某武器族整族形态错 | 族解析/分派域 | data/weapon_visual_profiles.gd、vfx_impact_factory.gd 分派域 |
| 同武器不同单位观感不同 | 渲染路径未走统一解析 | bullet.gd / 三个 batch / construct_unit_ai.gd 的消费点 |
| 尺寸/时长不对 | 族配方参数 | vfx_impact_factory.gd 配方表 / weapon_projectile_vfx.gd 缩放 |
| 新武器特效像别的武器 | 名字无信号走了兜底 | 给名字补语义词或加关键词（本文档同步） |
