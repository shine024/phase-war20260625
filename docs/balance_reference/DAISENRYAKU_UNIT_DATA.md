## 2. 数值机制速览（读懂数据的前提）

### 2.1 AD大战略(MD) 伤害公式

```
攻击成功率 Power(%) = [自攻击力 + 自经验值/10 - 敌经验值/20] × [100 - 敌防御力]% × [100 - 敌地形防御]%
实际攻击成功率     = 自军机数 × 攻击回数 × Power(%)
```
- **机数影响输出**：先手攻击方以完整编成数计算，后手方以残存数计算 → 先手优势是机制性的
- **空回数/地回数**：机枪系对地 2 回/次，炮弹系对地 1 回/次，对空一律 1 回/次（≈ 我们 per-target 攻速分层的原型）

### 2.2 大東亜興亡史 字段口径

`耐久`：数值 + 硬(装甲硬)/軟(装甲软) 两系 · `索敵`：地N(隠蔽M)/低N(低空)/高N(高空) · `防御`：低N=抗软攻/高N=抗硬攻 · `移動力`：通常/高速两档 · 武器四元组 `弹数/火力/射程/回数`

### 2.3 大戦略Ⅶ 字段口径

`策敵範囲`/`回避力` 各 6 维（高空/中空/低空/地上/海上/海中）· 兵装命中率按 7 类目标分列（航空機/ヘリ/車両/兵士/艦船/潜水艦/施設，0=不可攻击）· 射程 6 维 · `攻撃条件`（隣接/移動后可否/防御反应等）

## 3. 大战略的"平衡指纹"（跨作稳定规律）

### 3.1 耐久（HP）区间极小，档次靠倍数而非大数值

| 档次 | 大東亜(WWII) | Ⅶ(现代) |
|------|-------------|---------|
| 步兵 | 1（軟） | 1 |
| 伞兵/骑兵 | 1-3（軟） | 1 |
| 轮式/装甲车 | 2（硬） | 2 |
| 坦克 | 2-4（硬） | 3-4 |
| 战斗机 | 2-3 | 2 |
| 舰船 | 5-10（耐久） | 24-25（驱逐~ Zumwalt） |

**步兵:坦克 ≈ 1:3，坦克:战舰 ≈ 1:2.5~8（按耐久档）**——系列传统是 1~4 的小整数耐久 + 命中率百分比做主要平衡杠杆，而不是大 HP 池。

### 3.2 価格（费用）锚点——跨 60 年的稳定比例

| 类别 | 大東亜 WWII | Ⅶ 现代/近未来 | 跨代增幅 |
|------|------------|--------------|---------|
| 步兵 | 40~150（动员兵40 → 近卫骑兵150） | 80~140（侦察80 / 空挺140） | **≈1.0x** |
| 轻坦 | 100~130 | LAV-25 300 | 2.5x |
| 中坦/MBT | チハ170 → チリ400 | T-80 380 → 90式 700 | **1.75x**（同类顶级） |
| 自行火炮 | — | M109A6 350 | — |
| 火箭炮 | 噴進砲车 200 | MLRS 600 | 3x |
| 防空 | — | LAV-AD 350 / 爱国者 500 | — |
| 战斗机 | 隼2600~烈风6600（日军） | F-15J 1800 / F-35 2100 | ~1.0x（同代锚） |
| 近未来机 | — | FB-22 5000 | — |
| 舰船 | 驱逐4000~战舰13000（AD-MD 生产费） | Virginia 9000 / Zumwalt 7000 | ≈持平 |

**关键规律：现代兵器对 WWII 同类只贵 ~1.75-3x，步兵几乎不涨**。战力膨胀主要投放在命中率、射程、弹药、特殊能力（ECM/精确弹）上，而非基础数值。

### 3.3 火力区间

| 武器 | 火力值 |
|------|--------|
| 步枪/机枪 | 1 |
| 坦克炮 37mm→120mm | 3→4（60 年仅 +33%） |
| 反坦克火箭（步兵携行） | 3（弹数 1-2，打完即空） |
| 155mm 火炮 | 3（射程 5 格 + 弹 8-20） |
| MLRS 火箭 | 4（射程 5 格） |
| 空空导弹 | 2 |
| 精确巡航弹(AGM-129/BGM-109) | 6（射程 12-18 格） |
| 鱼雷 Mk.48 | 14（舰用） |

**火力 60 年只有 1→6**，差距体现在**命中%（30~93）与射程（1→18 格）**。

### 3.4 三维克制（对空/对甲/对人/对舰）是硬约束

- 步枪 vs 车辆命中 0%、坦克主炮 vs 空中 0% ——**不可攻击是常态**，交叉克制靠专用武器补位
- 坦克机枪 vs 步兵 48%、 vs 直升机 30% ——副武器决定泛用性
- 现代坦克主炮 vs 车辆 67-71%、vs 步兵 57-61%、vs 舰船 39-43%（同弹递减）

### 3.5 MBT 十国横评（Ⅶ，现代坦克设计公差）

```
価格 330(98式)~700(90式)   均值 450      → 最大/最小 = 2.1x
耐久 3~4                                 → 1.3x
主砲火力 67(98式)~75(90式) 均值 70.2     → 1.12x
対車両命中 41~44 均值 42.6               → 1.07x
回避 46~53                                → 1.15x
移動 5~6/6~7                              → 1.2x
```
**同代同级 MBT 的数值公差带极窄（≤±15%），个性靠 ECM/燃料/副武器/移動タイプ**。最贵的 90式(700) 与最便宜的 98式(330) 价差 2.1x，但火/耐只差 ~12%——贵的钱买的是命中与副武器。

### 5.2 跨时代曲线对比（v2 时代跨度重校准）

> **框架前提**：Phase War 是 5 时代（一战→近未来，~130 年）进度型卡牌游戏，**跨代总增幅是设计需求**；
> 大战略每部作品只覆盖窄时代带（单作 10~60 年），无跨代进度概念。因此总增幅不适用大战略"平曲线"标准评判，
> 正确对照维度是**每时代步进**与**曲线形状质量**。

| 维度 | 大战略参考锚 | Phase War 实测（纯战斗口径） | 评 |
|------|-------------|---------------------------|----|

### 5.3 可疑点（v2 重校准后）

1. **[INFO→设计确认] 攻击端增幅重心**：对甲攻总增幅 6.6x 高于 HP 的 5.7x（大战略传统把进步投放命中%/射程/弹数/ECM，火力本身近乎不变）。当前形状单调健康；若未来出现"后期秒杀链"，优先把部分 atk 增量迁往攻速/射程位，而非压总曲线。
2. **[INFO→设计确认 2026-08-25] 兵种比漂移**：步兵:装甲从 1:4.42 收窄到 1:2.23（-50%）。**用户确认：未来时代考虑了动力装甲**——数据指纹吻合：近未来步兵 def_a 78（现代 49 的 1.6x）、重装机兵 1200HP/def_a 104 达冷战 T-55 坦克防御水平、侦察机甲带三武器槽（粒子束步枪+电磁炮+点防御激光）。分段看：近未来跳变 1.59x 是题材引入（合理）；冷战/现代段收窄另有 IFV/APC 混入装甲分类的口径因素（BMD-1 300HP/BTR 320HP 计入"装甲"）。注意：动力装甲是**生存向**改造（def/HP 跳升）而 atk_a 94 反而略低于现代 100——步兵变肉但没变成坦克杀手，克制环仍闭合。
3. **[WARN] 坦克对轻/对甲攻差**：虎式 atk_l 98 / atk_a 438 = 4.5x；大战略坦克炮对人/对甲命中只差 5-10%。三维攻击分离更陡是卡牌定位设计的选择，但"坦克打步兵群"显著低效，需确认符合预期手感。
4. **[WARN] 步兵生存力（同期口径）**：大战略步兵:坦克 = 1:3（单作内恒定）；我方 WW1 1:4.42 → 现代 1:1.97。现代段步兵相对最"肉"已接近对等——与 #2 同源。
5. **[PASS] 曲线单调性**：纯战斗口径下（剔除 boss/守护者/平台），两兵种 HP 五时代全步进 >1.0，无倒退。
6. **[PASS] 射程量级**：2-4 格 + 99 全图（炮兵）↔ 大战略 1-5 格 + 7-18（V-2/巡航弹级）——分布一致。
