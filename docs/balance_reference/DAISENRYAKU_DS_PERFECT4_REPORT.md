## 一、"2018 现代大战略"指代歧义

根据日维基版本年表，2018 年前后有三款相关作品：

| 日文名 | 英文名 | 平台 | 发行日期 | 备注 |
|--------|--------|------|---------|------|
| **現代大戦略 2017** | Modern Daisenryaku 2017 | PS4 | 2017-04-26 | "现代大战略"正统续作，2017 年版 |
| **大戦略パーフェクト4.0** | Daisenryaku Perfect 4.0 | PS4 | 2018-04-26 | 「Perfect 系统」第四作，2018 主发 |
| | | PC | 2018-07 | |
| | | Switch | 2018-09 | |

中文"现代大战略 2018"最可能指 **Perfect 4.0**（2018 年首发）。
也有可能是 **現代大戦略 2017**（标题含"现代"且紧邻 2018）。

## 三、DS 已知单位数据（百度经验，ROM 修改帖）

> 来源：nds大战略修改资料 - 百度经验（https://jingyan.baidu.com/article/3c48dd34c66acae10ae35841.html），作者原创，2018-11-23 更新
> 数据为 **M109A2 自走炮**（序章即可生产）的内存结构解析：

### 3.1 单位内存布局（M109A2，地址 0x02680AE8）

```
原版数据（十进制）           十六进制布局
────────────────────────────────────────────────────
索敌 (Spot)      =  1   →  (01)
弹药 (Ammo)      =  4   →  (04)
射程 (Range)     =  3   →  (03)
火力 (Firepower) = 62   →  62   （注：经验文说62h=98d，即十六进制转十进制）
命中坦（%）       = 69   →  (45)  ← 十六进制0x45 = 69d
命中车（%）       = 61   →  (3d)  ← 十六进制0x3D = 61d
命中步（%）       =  0   →  00   （自走炮不能攻击飞机）
机动（Mobility） = ?    →  不在同一段内存（需另寻）
回避（Evasion）   = 23   →  不在同一段内存
燃料（Fuel）     = 29   →  不在同一段内存
```

### 3.2 单位内存段解读

`01 04 03 62 00 00 00 45 3d 00`

| 字节 | 含义 | 说明 |
|------|------|------|
| 01 | Spot | 索敌值 1 |
| 04 | Ammo | 弹药 4 |
| 03 | Range | 射程 3 格 |
| 62h | Firepower | 火力 98（十六进制 0x62 = 十进制 98） |
| 00 00 00 | Anti-air hit rate | 对空命中 0（自走炮无法攻击航空器） |
| 45h | Hit vs tanks | 命中坦克 69% |
| 3dh | Hit vs vehicles | 命中车辆 61% |
| 00h | Hit vs infantry | 命中步兵 0%（或此段不反映此值） |

### 3.3 其他已知单位（同帖提及）

| 单位 | 内存地址 | 备注 |
|------|---------|------|
| M109A2 自走炮 | 0x02680AE8 | 序章即可生产 |
| 90式歩兵戦車 | 0x0268046C | 有截图对比，数据未文字化 |
| 火力上限 | ~190（0xBE） | 改到此值可"秒大多数怪" |

### 3.4 DS 系统设定（来自 PChome / Baidu Baike）

- **国家**：IQ / JN / KR / UA / RS / GR 共 6 国
- **武器总数**：350+ 种
- **背景**：虚构中东国家 IQ，玩家扮演中立佣兵"Wild Goose（野鹅）"
- **特色**：支持无线联机对战
- **机制类比**：与 VII/PSP 系基本一致（命中率 + 火力 + 射程 + 机动 + 回避 + 索敌 + 燃料 + 弹药 结构）

## 四、从 DS 数据反推的平衡基准（给 Phase War 参考）

M109A2 作为现代自行榴弹炮（武器类型 = 曲射支援）的样本值：

| 属性 | M109A2（DS） | 大戦略Ⅶ 对照（M109A6） | 备注 |
|------|-------------|----------------------|------|
| 火力 | 98 | 3（七级制） | DS 用 0-200 标度；Ⅶ 用 1-6 标度 |
| 射程 | 3 格 | 5 格 | DS 格子可能更小 |
| 命中率（对车） | 69% | 56% | DS 略高 |
| 命中率（对步） | 61% | 66% | DS 略低 |
| 对空 | 0% | 不可攻击 | 一致 |
| 弹药 | 4 | 8 | DS 更少 |
| 回避 | 23 | 16 | DS 更高 |

**注意**：DS 使用完全不同的标度系统（火力 0-200，命中率 0-100%），不宜直接与 VII 对比。Phase War 的参考基线仍是已收集的 VII（现代）和大東亜（WWII）。
