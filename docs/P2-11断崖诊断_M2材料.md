# P2-11 断崖诊断（M2 决策材料补遗）——2026-09-23

> 依据：`tests/evidence/playability_2026-09-22/level_curve.json`（18 轮实机）+
> `tests/evidence/playability_2026-09-22/p211_strength_audit.log`（classic_enemy_strength_audit 镜像审计，2026-09-23 复跑）。
> 本文档只做诊断，不含任何数值改动——调不调、怎么调归 M2 人工拍板。

## 一、两份数据放在一起看

| 数据源 | 口径 | 结果 |
|---|---|---|
| 实机曲线（B1.1c） | 槽2 裸档（一战初始卡、无相位仪养成）打 L43/50/60，各 6 轮 | **0/18 胜**，战败用时 16s→12s→9s（越深越快败） |
| 镜像审计（P2-11 既有工具） | 同时代**中位卡 + 档位镜像强化（Lv7-13）**的敌我战力比，全曲线 13 档 | **0.88–1.55，无尖峰**；L40=1.24 / L45=0.88 / L60=1.10 |

## 二、诊断结论：不是数值断崖，是装备代差墙

1. **敌方数值曲线本身是平的**。镜像养成档下，L41-60 的敌我比与 L1-20（1.23-1.55）完全同量级——不存在"L43 敌人突然变强"。
2. **裸档输在代差**：槽2 存档可上场的是一战初始卡（镜像战力 ~373-435），而 L43 冷战末波 M113 末波战力 ~1400、HP 872+——代差 4-10×，首波接触即团灭（实拍 `pr_curve_L43_battle.png` 等）。
3. **B 组注入无改观的原因**：相位场满级加点只放大现有卡 ~20-30%，救不了 4-10× 的卡面代差——这反证断崖不属于"加点/仪器养成层"。

## 三、对 M2 的判断选项

| 选项 | 含义 | 代价/风险 |
|---|---|---|
| **A 判定"符合预期"（推荐基调）** | 代差墙=推进门槛的自然形态：正常玩家过关 L40 后已解锁冷战制造/商店（制造 L2 开、门 recipe 地板已铺），审计证明同代装备即可战。18 轮全败是**测试裸档跳关**的必然结果，非平衡缺陷 | 零改动；接受"跳关必撞墙"现状 |
| B 软提示（小改动，另立批次） | 行军目标远超已通关进度时（如 >max_unlocked+5），MapActions 加"⚠ 敌方等级远超当前装备"提示；不拦不调数值 | UI 一处 + 文案；需你拍板后排批次 |
| C 数值调平（不推荐） | 压低 L41+ 敌方档位系数 | 与镜像审计矛盾（同代装备已均衡），会伤害正常推进玩家的挑战曲线；v37 刚收口过 WW1 掉落，勿再单变量乱调 |

## 四、给 M2 的最小复核动作（可选）

上手实机验证一次"正常推进"口径即可闭环：从槽 1（真实进度档）走到 L43 打一场——若同代装备下能站住，选 A；若仍秒败，则镜像审计的假设（中位卡/镜像强化代表真实玩家）有偏差，届时再开数值批次。
