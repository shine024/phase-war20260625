# 制造系统 + 基地房间升级 设计文档 v1.0

> 2026-09 定稿。进化系统整体退役，由情报驱动的制造系统接管；同时补上 v22.3 遗留的
> 房间升级态。定案过程中的用户决策：
> ① 制造不消耗缴获卡（纯情报+资源）；② 品质轴复用现有稀有度；③ 缴获卡本身带品质
> （高品质缴获卡分析产出更多情报）；④ 分析仪=档案室升级件；⑤ 房间升级全房间一次做完。
> 关联文档：docs/design_ember_bunker.md（基地本体）、AGENTS.md 停用系统清单。

## 一、定案摘要

| 决策项 | 结论 |
|--------|------|
| 进化系统 | **整体退役**（E1/E2 形态升级 + 低进化/完整进化 + 谱系进化链全部退场） |
| 新卡获取 | 唯一通道 = **制造**：情报解锁配方 → 资源制造 |
| 品质 | 复用现有稀有度轴（实例级）；情报档位决定品质概率池 |
| 制造消耗 | 纯资源（纳米/能量块，高时代加合金/晶体），**不吞缴获卡** |
| 缴获卡 | 保留（可上阵）；品质随获取滚动；用途=上阵或分析仪烧情报 |
| 分析仪 | 档案室 Lv2 解锁；烧缴获卡得情报；档案室 Lv3 提升高品质概率 |
| 制造图纸 | 退役（制造纯情报+资源）；改造图纸不动 |
| 房间升级 | 15 房 Lv1-3 一次做完；补 `level` 递增接口（v22.3 遗留） |

## 二、制造系统

### 2.1 核心循环

```
出战击败敌兵 → 缴获兵种卡（品质滚动） → 分析仪烧卡得情报 → 情报解锁配方+推移品质池
                    ↓（或直接上阵）                    ↓
                    └──────────────→ 制造（纳米+能量块）→ 新卡入库（品质滚动）
```

时代门槛自然转化为情报门槛：高时代敌形打不到 → 没情报 → 造不了。

### 2.2 情报双职责（同一进度轴：IntelManual base_progress）

| 情报 base | 解锁 | 品质概率池（实装值 v26.8，真身 `data/manufacture_pools.gd` POOLS） |
|---|---|---|
| ≥25% | 配方（可制造） | 普通 100% |
| ≥50% | 品质池扩 | 普通70 / 精良25 / 稀有5 |
| ≥75% | 品质池扩 | 普通45 / 精良30 / 稀有15 / 史诗8 / 传说2 |
| 100% | 满池（原 TIER_EVOLUTION 语义平移） | 普通20 / 精良28 / 稀有26 / 史诗15 / 传说8 / 神话3 |

- 品质档位名实装时绑定现有稀有度常量（以代码枚举为准，上表已对齐实装值）。
- **暗保底**：同配方连续 3 次未出 稀有+ → 稀有+ 权重 ×2（PITY_THRESHOLD=3 / PITY_BOOST=2.0，不显示给玩家）。
- 原情报阶梯其余语义（25% 基础属性揭示 / 75% 弱点提示 / 100% 掉率+50%）全部保留。
- 技能树"全时代进化"节点（cw_4）语义平移为**制造时代授权**：高时代配方需解锁该节点
  （沿用原 skill_tree_era 条件位）。

### 2.3 制造消耗（示意锚点，随日均纳米收入 200-400 调）

| 时代 | 消耗 |
|---|---|
| 一 | 纳米×100 + 能量块×20 |
| 二 | 纳米×180 + 能量块×35 |
| 三 | 纳米×260 + 能量块×50 + 合金×30 |
| 四 | 纳米×350 + 能量块×70 + 合金×60 |
| 五 | 纳米×450 + 能量块×90 + 合金×90 + 晶体×40 |

按配方（卡种）固定收费，品质滚动不额外收费；重复制造=再付一次（品质 fishing 的成本）。
工坊 Lv2/Lv3 制造消耗 -10%/-20%。

### 2.4 缴获卡品质

- 缴获卡获取（掉落/购买/势力奖励）时滚动稀有度，与玩家卡同一稀有度轴、同一实例属性乘算。
- 分析仪产出随缴获卡品质递增：普通+8% / 精良+12% / 稀有+16% / 史诗+22% / 传说+30%。
- 取舍：高品质缴获卡要么留战场上阵，要么烧出更多情报——不再有"低进化变身"出口。
- `ACQUIRED_BASE_FLOOR=0.5`（获取缴获卡情报抬底）保留：买到高品质缴获卡同时回填情报。

### 2.5 分析仪（档案室升级件）

| 项 | 设计 |
|---|---|
| 解锁 | 档案室 Lv2 |
| 输入 | 仅限缴获兵种卡（`captured_*`） |
| 流程 | 放入 → 打 2 场战斗后出炉（与修复进度"以场计"同构）→ 卡销毁 + 情报入账 |
| 产出 | 按缴获卡品质（见 2.4），走 `_add_intel(source="analyzer")`，计入 base 峰值 |
| 限制 | 每日上限 3 张；同时在机 1 张 |

### 2.6 制造图纸退役与掉落改道

- `blueprint_evol_` 前缀图纸退役：精英/Boss 掉落表中 20% 进化图纸份额改道为
  缴获卡/资源/改造图纸。**改造图纸（blueprint_）不动**（改造安装仍认蓝图）。
- 技能树进化节点语义平移（见 2.2）。

### 2.7 保留轴 / 退役清单

**保留不动**：card_level（1-30 上阵攒经验）、改造 202 模块、词条、军衔、情报阶梯揭示、
相位师技能树（节点语义平移）。白品质卡=便宜起步版，养满改造照样能打。

**退役**：E1/E2 进化条件判定、EvolutionPathRegistry 消费链（8 兵种 73 节点）、
unit_lineage_config 的进化出口语义（谱系数据转制造目录"来源"展示）、低进化/完整进化、
进化 HP 下限新增来源、inherit_bonus 新增来源、进化图纸。

**改名为制造**：进化面板（战术进化站→制造中心，三栏改为 配方目录/品质池详情/制造）、
help/教程/成长面板紫卡区文案、unit_progression_detail_view"可进化至"→"可制造"。

### 2.8 旧档兼容

- 已进化过的卡就是普通卡实例（card_id 已是目标卡），继续可用；只是"进化"动作消失。
- hp_floor / inherit_bonus 存档字段保留为惰性数值（不再有新增来源），**不迁移不删除**。
- 制造保底计数/配方解锁状态为新字段：配方解锁不落档（实时读情报，天然兼容）；
  暗保底计数落 `bunker_state`（缺 key 兜底）。

## 三、房间升级系统

### 3.1 框架

- room def 加 `upgrades: [{cost, battles, effect}]`；BunkerManager 补
  `upgrade_room()` / `get_room_level()`（补 v22.3 遗留接口）。
- 房间面板加升级按钮+等级角标；升级耗时以"场"计，与修复同构。
- 存档：`bunker_state.rooms[].level`；全部效果走 BunkerManager 查询接口
  （`get_sleep_recovery()` / `get_manufacture_discount()` 等），杜绝零消费方死数据。

### 3.2 十五房升级总表

| 房间 | Lv2 | Lv3 |
|---|---|---|
| 入口大厅 | 布告栏：每日动态任务 +1 | 精神上限 100→110 |
| 宿舍 | 睡觉回精神 20→30 | 40 + Earth 落地窗美术 |
| 食堂 | 每日配给 +50% | +100% |
| 医疗室 | 疗效 40→60 | 费用 50→30 |
| 兵棋室 | 每场精神消耗 10→8 | 沙盘演武：1 张未上阵卡后台吃 50% 经验 |
| 工坊 | 制造消耗 -10% | -20% + 改造安装费折扣 |
| **档案室** | **分析仪上线** | **高品质权重 ×1.5 + 全局情报获取 +10%** |
| 通讯室 | 商店免费刷新 +1 | 势力声望获取 +15% |
| 反应堆 | 生产类效果 +10% | 精神归零掉落惩罚减半（×0.9→×0.95）+ 心跳音 |
| 荣誉室 | 纪念墙铭牌（完整档案+遗言回放） | 出征仪式：日 1 次敬礼，本场掉落 +10% |
| 仓库 | 卡墙（拥有过卡种点亮） | 战利品打印：日 1 张随机缴获卡（喂分析仪，不开第二卡源） |
| 气象站 | 天气预报：出击前可锁 1 个环境加成 | 地表探索：日 1 次派遣带回资源/缴获卡 |

| 风险 | 对策 |

## 七、改造图纸制造通道（v26.10 补，2026-09-02）

改造模块消耗品化（安装一条改造 = 消耗 1 张图纸 + 纳米费）后，制造站新增图纸补给通道。
静态表真身 `data/mod_manufacture.gd`，执行在 `managers/manufacture_manager.gd`，
UI 在 evolution_panel 双模式（"兵种卡 / 改造图纸"标题行切换）。

### 门槛规则（单一心智模型）

**得到过就可造**：定向目录与随机箱池都取自 IntelItemBag「见过集合」（`_seen`，
add_item 自动记录，消耗光仍在；旧档回填=库存∪已装改造）。分工：**掉落负责发现
（第一次），制造负责补给（第 N 次）**——制造不提供未见过的图纸，不蚕食掉落的
发现乐趣；随机箱池同样取自图鉴，保持单规则。

### 形态（混合：低定向高随机）

| 区 | 稀有度 | 形态 | 价目（锚=日均纳米 200-400，×工坊折扣） |
|---|---|---|---|
| 定向兑换 | common / uncommon / rare | 选中即换 | 纳米 80 / 150 / 280 + 能量块 10/20/40 +（rare）合金 20 |
| 随机箱 | epic / legendary / mythic | 开箱 roll | 纳米 420 + 能量块 60 + 合金 30 |

随机箱：池内按 mod 所在稀有度加权（epic 78 / legendary 19 / mythic 3）roll 一张；
暗保底=连续 3 次未出传说+ → 传说+权重 ×2（对齐卡牌制造 PITY 模式，计数存档
`manufacture_state.mod_box_pity`）。

### 平衡留观（首版单变量）

掉率与安装纳米费首版均未动；需求锚=主力 15-20 卡满改一生 ~150-200 次安装。
实机体感后按 `tools/balance_audit` 口径调：DIRECT_COSTS / RANDOM_BOX_WEIGHTS /
PITY_THRESHOLD 三个单变量。重复卡"各付纳米税+各耗一张图纸"对多实例玩法的抑制
留观，必要时加同卡种安装折扣。

### 测试锁

`tests/unit/economy/test_mod_consumable.gd`（14 用例）：安装消耗/双拒绝路径不扣错侧/
开关回退/见过集合四性/定向扣费入包/分区与未见拒绝/随机箱确定性+pity 往返/出率归一。
