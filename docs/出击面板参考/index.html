出击面板的右下/底部编队区参考：一眼看清出战配置，点卡可下钻检查单卡装备。

RoyalCDKeys

B · 战前部署型——「怎么摆」

本项目战斗是固定格子槽位部署（v26.2 布局），战前不做自由布阵；这组主要借「一眼清点」和「敌我对比」的表达。
《全面战争：罗马2》开战前部署阶段
Gamesplanet
左下单位卡矩阵（全军一屏清点）+ 战场部署区高亮 + 顶部敌我兵力对比条。借鉴：①单位卡矩阵的「清点感」可用于出战卡摘要（按兵种 5 类排卡）；②敌我兵力对比条放进敌情栏顶部——双色横条比数字更直觉（数据源 = 敌我战力预估，敌方按档位乘区口径）。
Phase War 对应：编队卡按 CombatKind 5 类分组；对比条 = 我方上阵总战力 vs 本关敌方总战力（比例条，不露具体数值防剧透）。

  • 三档皮肤联动（与机枢大厅换肤叙事同构，是本面板的记忆点）：T1 白板=纸质作战命令+手写标注钉在沙盘上；T2 显示器=磷光绿终端（rd01 材质）；T3 投影=全息作战地图（jb03 形态）+ 沙盘扫描线动画。信息结构三档完全一致，只换容器材质与沙盘表现——一次布局，三套皮。
