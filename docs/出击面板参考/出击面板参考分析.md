## 推荐布局（1280×720，纯 UI 汇编层，零新数据/存档）

```
顶栏：作战简报 · 第N关「名」 · 时代II · 第N天 HH:MM          [返回基地]
左栏：任务目标（守N波/主题一句话）→ 环境四维 → 顺路目标（任务关联）
中区：全息沙盘（时代战线一段 + 我方箭头 + 本关红标 + 波次来向）
右栏：敌情预告（兵种计数/档位/威胁雷达）→ 兵力对比条 → 首通奖励
底栏：相位仪4槽 · 符文行 · 出战卡摘要 ▸        [更换装备]  ▶ 出 击 ◀
```

- **≤2 击铁律**：大厅点沙盘台(1) → 本面板出击(2) ✓；顶栏常显「出击」直达。
- **三档皮肤联动**（记忆点）：T1=纸质作战命令手写风 / T2=磷光绿CRT（rd01）/ T3=AC7 式
  全息沙盘。信息结构三档一致，只换容器材质与沙盘表现——与大厅换肤演出同构，
  T3 投影首亮时「作战地图第一次投出来」就是自带的高光时刻。
- **分期**：P1 静态简报+编队+出击按钮；P2 敌情预告+威胁雷达+兵力对比条；
  P3 全息沙盘动效（随 T3 落地，观星台叙事可并入投影沙盘）。
