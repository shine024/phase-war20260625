# 格陵兰底图 · 最新提示词与生成流程（2026-08-28 定稿轮）

> **本文档 = 大底图（方案11 主地图）当前生成方式的唯一依据。**
> 结论先行：agnes API（agnes-image-2.0-flash）**没有图生图**（/images/edits 500；generations 带
> image 字段被静默忽略，usage.image_tokens=0，URL 前缀恒为 t2i）→ 直接让 AI 画"整张地图"
> 无法满足"轮廓=真实格陵兰"的硬约束 → **改为"AI 画无缝材质贴图 + 程序铺装进真实轮廓"管线**。

---

## 1. 管线总览

```
① 真实海岸线数据  GRL.geo.json（132 点，johan/world.geo.json）
        ↓ 程序栅格化（旋转90°横放：宽端朝西、南尖角朝东=黑门）
② AI 无缝材质贴图 ×5（提示词见 §2，tools/generate_map_textures.py）
        ↓ 镜像三角波采样（无缝）+ UV 噪声扰动（防重复）
③ 程序合成（tools/compose_greenland_map.py）
   地带权重（噪声抖动边界）→ 气候染色 → 山体阴影 → 海面/陆架/碎浪
   → 冰穹放射流纹 → 等高线微影 → 冰川舌+河流 → 湖泊 → 废墟 → 黑门 → 颗粒/对比
        ↓
2560×1440 原生直出（greenland_tex2_main/alt.png），黑门 = 东尖角 (2040, 760)
```

重新生成命令：
```bash
python tools/generate_map_textures.py      # ② 5 张贴图（已生成过，重跑覆盖）
python tools/compose_greenland_map.py      # ③ 合成 2 个种子变体 + 总览图
```

## 2. 材质贴图提示词（当前生效，5 张）

公共头部（每张都拼在最前）：
```
seamless tileable texture, hand-painted watercolor game asset, top-down flat view,
even soft lighting, uniform repeating pattern filling the whole square,
no objects, no border, no vignette, no text, no watermark
```

| 贴图 | 主题描述（拼在头部后） |
|------|------------------------|
| tex_grass | `arctic tundra grassland and moss, muted sage green with dry grass brush strokes and small patches of bare earth` |
| tex_snow | `fresh snow field, pale blue-white, faint wind ripples, sparse ice crystal sparkle, soft drifts` |
| tex_rock | `rugged grey-brown mountain rock and scree slope, painterly cracks, gravel and lichen speckles` |
| tex_sea | `calm deep ocean water seen from directly above, dark blue, subtle current brush strokes and faint wave shimmer` |
| tex_forest | `dense dark pine forest canopy seen from high above, muted blue-green, painterly clumping tree crowns with tiny snow gaps` |

调用参数：model `agnes-image-2.0-flash`，size `1024x1024`，n=1，输出
`docs/地图重设计/generated/greenland/textures/tex_*.png`。

> 经验：**"seamless tileable" 措辞下模型仍会画 4×4 平铺暗示纹**，但合成端用镜像三角波
> 采样（`tri()`）后接缝不可见，无需追求完美无缝。

## 3. 合成端"视觉提示词"（等价于提示词的可调参数，compose_greenland_map.py）

| 参数 | 当前值 | 作用 |
|------|--------|------|
| 地带半径 | 绿 px(40) / 岩 px(64)±36 / 雪 px(96)+ | 沿岸绿→苔原岩→内陆雪，噪声抖动 ±26px |
| 纹理 span | 草300/岩260/雪420/林280/海650 | 减半=细节加倍（上一版 560 被判"少细节"） |
| 地形场 | 冰穹 dist/150 + 棱脊山（ridged, 幅 0.85/0.95 rim） | 山脉起伏来源；河谷由河流下切反蚀 |
| 山体阴影 | 0.85 + 1.5·(gx,gy)·西北光，clip 0.62..1.32 | 幅度 <1 看不出地形（上一版 0.55 被判"无地形"） |
| 冰面流纹 | sin(rad/14px + nrad·9)，雪带内 ±12% | 冰穹放射状流动感 |
| 冰川舌 | 7 条自冰穹重力下测，冰舌 px(9) 宽 + 水线 px(2) | 格陵兰标志地貌 |
| 海面 | tex_sea ×(0.50+0.20(1-x)) + 陆架(22,40,48) | 西深东浅；东边仍偏淡，可再压 |
| 碎浪 | 岸外 5px 带，blur 1.2，α95 | 别超 2px blur（会出白晕） |
| 等高线 | height×14 取小数 <0.07，α40 | 地形图读感 |
| 废墟 | 44 处，r 7~22px，α0.20~0.42，西旧东新 5 档 | 未来档带青光点 (0,210,235) |
| 黑门 | 东尖角黑盘 r20 + 青白双环 | 坐标 (2040,760) → `GATE_POS_S11` |
| 后期 | Contrast 1.12 / Color 1.22 / 颗粒 ±5 | 整体不发灰的最低配置 |
| 种子 | main=11 / alt=97 | 河流/湖泊/废墟布局差异 |

## 4. 废弃提示词存档（勿再使用，附否决原因）

| 轮次 | 提示词要点 | 否决原因 |
|------|-----------|---------|
| v1 "world map"（base_v3_candidates） | `High-altitude hand-painted world map ... five terrain belts ...` | 画出来全是**地球大陆分布** |
| v2 反地球（base_v3b） | `ONE SINGLE INVENTED fantasy continent ... NOT planet Earth ...` | 仍有地球轮廓影子；且看得见农田房子（尺度穿帮） |
| v3b 发明形状（base_v3c，未跑完） | 长刃/哑铃/掌形等具体剪影 + 战壕疤 | "一战战壕疤"大陆视角不可见（米级）；整轮方向被用户否决 |
| v3c 格陵兰直绘（base_v3d/e） | `silhouette clearly shaped like GREENLAND rotated 90° ...` | 模型凭记忆画不准格陵兰 → "整体轮廓太不自然、废墟太刻意太大、没有完全按现实" |
| 程序色块版（greenland_A/B/C/D_hd） | 无提示词，纯噪声色块合成 | 被判"简笔画"——无手绘质感 |
| 贴图铺装 v1（greenland_tex_*） | 同 §2 但 span 加倍、无地形场 | 被判"少细节，与地形"→ 升级为 v4（tex2） |
