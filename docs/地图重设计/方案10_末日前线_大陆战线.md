# 方案 10「末日前线 · 大陆战线」完整设计方案（纯设计稿）

> **本文档只含设计方案**（世界/布局/叙事/美术/系统咬合），不含代码实现与部署流程。
> 与方案 11「晨昏大陆·黑日战线」互为姊妹篇：10 是"战争编年史"基调，11 是"光照奇观"基调。
> 参考示意图：`docs/地图重设计/示意图/scheme_10.png`（十方案对照表 `overview.png`）。

## 1. 设计总览

**一句话**：一张手绘战争大陆全图，100 关 = 一条自西向东横贯大陆的战线，每过一关战线东移一格；
大陆尽头的海平线上撕开一道黑色裂缝——入侵的源头，也是终局要推平的门。

**世界设定**：
- 舞台 = 一片大陆（近未来背景下的最终战场，画风与《这是我的战争》同源），西端群山，东端海岸。
- 入侵从东方海平线的"裂缝"涌出，裂缝沿途在大陆上撕开相位泡入口——泡内是从各时代
  时间线拖来的战场切片（一战堑壕、二战废墟……），**天然解释敌人为何跨越五个时代**。
- 玩家的反攻 = 把战线从家门口一路推回海平线：100 关字面意义上就是 100 道防线。

**核心卖点**：
1. **战争编年史质感**——战线推进、收复失地，与势力占领系统天然咬合（每块地是谁的、易主、收复，地图上肉眼可读）；
2. **零理解成本**——横向推进的大陆图是最经典的战棋/SLG 地图语言，任何玩家第一眼就懂；
3. **美术成本最低**——只需一张手绘大陆图，基地/节点/门全部可复用或已存在。

**与方案 7 / 11 的差异**（为什么它是"原味大陆"）：
| | 方案 10 | 方案 7 / 11 |
|---|---------|-------------|
| 天色 | 统一昼光，无光照渐变 | 潮汐锁定行星，天色=进度条 |
| 门的形态 | 海平线**地上的裂缝** | 天上的**黑日** |
| 氛围 | 战争史、收复失地 | 科幻远征、走向黑暗 |
| 追加美术 | 大陆图 1 张 + 裂缝三态 | 大陆图 + 黑日 + 天光 |

## 2. 地图布局设计

### 2.1 画布与结构
- 横向长卷大陆图（约 21:9 或 16:9 放大平移），五时代战区自西向东一字排开。
- 开局视口 = 西端：家门口 + 第一条战线 + 东方海平线那道细缝（第一幕就能看到终点）。

### 2.2 五条时代战区（自西向东）

| 战区 | 时代 | 关卡 | 地貌与地物 |
|------|------|------|-----------|
| 西线堑壕平原 | 一战 | 1–20 | 之字堑壕、铁丝网、弹坑、残破木栈道、照明弹残光 |
| 闪击森林 | 二战 | 21–40 | 焦黑林带、断树、烧毁坦克、轰炸弹道疤痕 |
| 冷战雪原 | 冷战 | 41–60 | 雷达站、混凝土导弹井、铁丝网围栏、雪地脚印 |
| 现代都市群 | 现代 | 61–80 | 半毁街区、破玻璃塔、无人机剪影、断桥 |
| 近未来焚化区 | 近未来 | 81–100 | 焦土、结晶残骸、半透明化物质、余烬裂缝 |

- 战线走向：每区 20 关蛇形推进（奇偶行反向），区与区之间以长战线连接，视觉上"一条线从头打到尾"。

### 2.3 家（基地）
- 西端**山脉地下掩体**——余烬要塞原样嵌入地图（基地重设计批次的建筑件直接复用，零新美术）。
- 家的叙事地位：背山面敌，是玩家在整张图上唯一的暖色锚点。

### 2.4 门（黑色裂缝，三幕）
- **第一幕（1–49 关）**：东方海平线上一道**细黑缝**，小如远处地平线瑕疵——玩家以为目标是收复大陆，它只是背景；
- **第二幕（50–89 关）**：裂缝明显扩大，边缘泛起**青色裂纹微光**，裂缝上方的天空发暗——玩家意识到入侵源头就是它；
- **第三幕（90–100 关）**：裂缝**占满东方天际**，边缘是翻卷的黑色物质，天空被撕开——终战把战线推回海平线，在门脚下收束。

> 门的悬念原理与方案 11 的黑日一致：**从第 1 关起就以极小形态存在、随进度长大**，把 100 关的目标感物化成一件"正在逼近的东西"。

## 3. 节点与系统设计

| 元素 | 设计 |
|------|------|
| 关卡节点 | 地表**裂缝/相位泡**：泡半嵌地面，泡内是被拖入战场的时代战场切片；首领关用更大的相位师泡 |
| 通关态 | 泡体破碎塌缩（沿用残壳视觉语言：暗玻璃壳、灰色尘漏、熄灭的余火） |
| 占领色标 | 每关节点描边显示占领势力色；收复易主实时变色（势力领地图面板同数据源） |
| 情报弹窗 | 点泡 = 看关卡情报（敌方阵容/掉落/环境/战术简报/驻守相位师），可进入或自动部署 |
| 微光桥 | 时代色虚线串联 1→100，从家门口一路通到海平线裂缝前 |

## 4. 视觉与氛围

- **画风**：与余烬要塞同一套《这是我的战争》手绘粗粝风——低饱和大地色、做旧、灰尘感，整张图就是一块"战争大陆的皮肤"；
- **配色**：五战区各带时代色倾向（锈金/军绿/冷蓝/青灰/相位青），与现有时代配色语汇一致，分区一眼可辨；
- **天气**：大陆统一昼光（方案 10 不引入天色渐变；若想要"推进感"，可只在裂缝上方加一处持续昏暗的云，暗示源头）；
- **动态点缀**：裂缝上方低垂的暗云、战场硝烟、飘动的残骸旗帜（可选，代码粒子）。

## 6. 为什么值得选它 / 什么时候选它

- **选 10 的理由**：想要最稳的战争史诗感、最低的美术成本、与势力占领系统咬合最紧；玩家对"横推大陆"零学习成本。
- **不选它的代价**：没有 7/11 的天文奇观与"天色即进度"的独有记忆点——它更"经典"，更不容易惊艳。
- **与 11 的关系**：11 是 10 的骨架 + 7 的光照 + 黑日奇观；若已决定做 11，10 的大陆骨架方案、裂缝三态资产可以直接为 11 的未来扩展（如第 2 张大陆）储备。

## 7. 一句话设计总结

> 一张手绘战争大陆，五条时代战线自西向东横推，家在西山，门在东方海平线——100 关就是 100 道防线，把入侵者一路推回它来的那道裂缝。
