# 百灯群岛世界地图 · AI 生图需求清单

> 配套设计：世界地图重设计方案 6「百灯群岛」（2026-08-27 定稿方向）——漆黑虚空中 100 个相位泡如群岛浮灯，
> 中央灯塔要塞（余烬要塞的灯塔形态）为家，5 时代 = 5 个星座状泡群，尽头是所有泡缓慢漂向的黑色巨环。
> 本清单 = 世界地图所需的**全部** AI 生成资产：1 张底图 + 3 张巨环 + 1 张灯塔 + 7 张泡 + 1 张残骸表，共 **13 张**。
> 画风与基地同源：`docs/基地重设计/生图需求清单.md` 的纪律与色板全部沿用，两张清单是同一个世界的两半。

## 一、总则（先读）

1. **画风基准**：《这是我的战争》(This War of Mine) 手绘粗粝风。低饱和、做旧、灰尘感；**禁止**高饱和、塑料质感、动漫风、3D 渲染感。地图是"从余烬要塞窗口望出去的那个宇宙"，不许比基地鲜亮。
2. **精灵底色**：件类资产（泡/灯塔/残骸）用**纯白背景**生成，后续脚本负责白底转透明 + 裁边 + 缩放。底图（黑海）与 gate_near 为整幅不透明图，不需要白底。
3. **无文字**：画面内任何文字/编号都不要（关卡编号、时代名由代码贴）。负面词统一带 text/watermark。
4. **发光语义**：泡膜裂光、灯塔暖灯、巨环裂纹都画成"点亮的实物"即可；锁定压暗、可挑战呼吸、通关塌缩等状态切换由代码滤镜做，**不需要**生成多版本（唯一例外：巨环三段渐进是形态变化不是滤镜，出三张）。
5. **尺寸**：生成长边 ≥768（建议 1024），构图按各资产"目标宽高比"预留满幅（可出血），后处理裁切。生成器档位不匹配时选最接近档，勿强行拉比例。
6. **部署路径**：统一落 `assets/map/`；白底转透明 + 缩放复用 `tools/deploy_bunker_v2.py` / `tools/deploy_card_icons_11.py` 的流程；残骸表加 PIL 九宫格切片步骤；全部入引擎后跑 `godot --headless --import` 生成 .import 元数据。
7. **PNG 备份铁律**：`.gitignore` 全局忽略 `*.png`，美术资产不入 git、删=永久丢失。本批 13 张生成并部署后，按项目外 `phase-war-art-backup-YYYY-MM-DD.zip` 惯例重打包并同步异机。

## 六、不用生图的部分（代码解决）

- **微光桥**：Line2D + glow shader（宽发光渐变线），随解锁点亮/呼吸，比贴图灵活
- **泡的三态**：锁定 = 时代泡整体 modulate 压暗 + 裂纹微光呼吸；可挑战 = 正常亮度 + 缓慢脉动
- **节点编号/时代名/势力占领色标**：代码 Label + 描边，沿用现有 `world_map.gd` 逻辑
- **星座连线**（时代图腾）：代码画虚线弧，不占资产
