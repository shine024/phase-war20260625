## 1. 设计总览

**一句话**：一张横跨晨昏线的大陆战争地图，100 关 = 从永昼往极夜推进的五条时代战线，天色即进度条；东端天空的"黑日"其实是入侵源头，随进度从一粒暗星长成占满天际的巨门。

**世界设定**（叙事自洽）：
- 舞台 = 一颗潮汐锁定行星上最后的自由大陆，东西横跨晨昏线：西端永远朝阳（永昼），东端永远背阴（极夜）。
- 敌人为何来自各时代：入侵从东端"黑日"涌出，黑日在沿途撕开的相位泡即关卡入口（泡内是被拖进战场的各时代战场切片）。
- 天色不是自然现象，是门在吞光——玩家逐步意识到这一点（三幕叙事，见 §3）。

**从竞品方案继承**：
- 骨架来自方案 10（大陆 + 战线 + 势力占领色标 + 余烬要塞直接嵌图）；
- 光照氛围来自方案 7（天色即进度、黑日天文奇观）；
- 门的悬念三幕为 7+10 杂交独有。

**与方案 6/8 的关系**：`MAP_SCHEME` 常量三选一（6=百灯群岛星座 / 8=沙漏双界 / 11=晨昏大陆，当前 11）。三套布局代码共存，美术资产跨方案复用，切回只改一个常量。

## 2. 地图布局规范（单一事实源 = `world_map.gd` 常量）

### 2.1 画布
- `MAP_CANVAS_SIZE = (2560, 1440)`，ScrollContainer 平移 + 左键拖拽 + 滚轮。
- 底图 `assets/map/dawn_dusk_continent.png`（2560×1440，LANCZOS 放大自 1376×768 生成件）。

### 2.2 五条时代战线（`_layout_scheme11`，静态缓存 `_s_level_points`）
```
第 era 行（era=0..4）:
    y  = 300 + era * 230            → 300, 530, 760, 990, 1220
    jj = j 若 era 为偶，否则 19-j    → 蛇形：奇偶行反向，避免行间长回拉线
    t  = jj / 19.0                  → 行内 0..1
    x  = 340 + t * 1880             → 340..2220
    wave = sin(t*PI) * 46           → 横向波浪（正弦拱），每行同形
    关卡 = era*20 + j + 1           → 第 1..100 关
```
- 最小相邻间距：行内约 99px、行间 230px、对角 ≥110px（泡径 74px，无重叠）。
- 时代映射 + 天光档（`SKY_BAND_NAMES`）：

| era | 时代 | 关卡 | 天光档 | 布局 Y |
|-----|------|------|--------|--------|
| 0 | 一战 | 1–20 | 永昼（金黄） | 300 |
| 1 | 二战 | 21–40 | 黄昏 | 530 |
| 2 | 冷战 | 41–60 | 薄暮 | 760 |
| 3 | 现代 | 61–80 | 夜 | 990 |
| 4 | 近未来 | 81–100 | 极夜 | 1220 |

### 2.3 关键坐标常量（写死 + 实测值）

| 常量 | 值 | 说明 |
|------|-----|------|
| `HOME_POS_S11` | (230, 390) | 家 = 山脉掩体（余烬要塞），西端山地，桥接第 1 关 |
| `GATE_POS_S11` | (2287, 139) | 黑日中心 = **底图暗星实测位置**（PIL 青色峰定位，见 §3.3） |
| 定场镜头中心 | (880, 460) | 新档（≤3 关）首屏：家 + 首条战线 + 远处暗星 |
| `LIGHTHOUSE_DISPLAY_H` | 420 | 家贴图显示高度（方案 11 实为掩体图） |

### 2.4 节点三形态（`_make_level_node`，TextureButton）
1. **通关**（`_is_level_cleared`，星级>0）→ `bubble_cleared.png` 残壳；
2. **相位师驻守关**（`PhaseMasterGarrison.is_garrison_level`）→ `bubble_boss.png`，数字金色描边，
   有占领势力时 `modulate` 混白染膜；
3. **其余** → 对应时代泡 `bubble_era_{ww1,ww2,cold,modern,future}.png`。
- 尺寸：普通 74px、boss 100px；中央数字 Label（boss 金 + outline）。
- 占领信息 + boss 信息进 tooltip（沿用 v6.10/v7.x 逻辑）。

### 2.5 overlay 层（`_draw_map_overlay`，draw 信号驱动）
- **微光桥**：时代色虚线（dash 10 gap 6，宽 1.5，alpha 0.32）；链 = 家→L1→…→L100→黑日。
- **占领色环**：`_s_occ_colors`（100 关按 `CompanyDefs.get_faction_color` 实时刷新），半径 46。
- **当前关光圈**：青色双环（52/58）。
- **天光小标签**：永昼/黄昏/薄暮/夜/极夜，画布 y=128，alpha 0.4。

### 2.6 残骸装饰（`_scatter_debris`）
- 12 个随机散布（固定种子 20260827），方案 11 用陆战 `wreck_1..8.png`（连通域拆件），
  方案 6/8 用太空 `debris_1..8.png`；alpha 0.35–0.6、旋转 ±0.45rad、缩放 0.45–1.0。

## 3. 三幕黑日逻辑

### 3.1 档位判定（`_gate_state_for_level`）
```
current_level < 50  → "far"    第一幕：暗星
current_level < 90  → "mid"    第二幕：黑日
current_level >= 90 → "near"   第三幕：巨日压东天
```

### 3.2 三态呈现（`_apply_gate_state`，方案 11 分支）
| 档位 | 贴图 | 尺寸 | 行为 |
|------|------|------|------|
| far | 无（隐藏 gate 节点） | — | **底图自带的暗星即第一幕**，不叠加贴图 |
| mid | `black_sun.png` | 240px | 以 GATE_POS_S11 为中心 |
| near | `black_sun.png` | 420px | 同上，压东天（部分出画） |

- 黑日贴图缺失时：gate 隐藏 + overlay 代码画兜底（黑盘+青环+裂纹，`WM_GATE_STATE` 可强制档位）。
- `gate_near.png`（整幅压迫构图）**保留给终局近接演出**，不直接摆画布。

### 3.3 暗星对齐实测记录
用 PIL 在 `dawn_dusk_continent.jpeg`（1376×768）右上区扫青色特征（`(g+b)-2r` 峰值）：
```
峰值位置 (1229, 74) → 画布 2560×1440 换算 = (2287, 139) → 写入 GATE_POS_S11
```

### 4.3 `black_sun` v2 重生成（唯一挂起项）
**v1 失败原因**：盘心平均色 (23,28,29) 为灰绿盘非纯黑；青裂纹像素仅 0.16%，240/420px 显示时完全消失（实测渲染区 0 青色像素）。

**v2 提示词**（已存 `生图需求清单.md` 末尾，复制即用）：
```
[P_SPR]
A single sun disc floating in empty sky, hand-painted,
a perfect circle of PURE MATTE BLACK (near absolute black, no grey),
crossed by THREE OR FOUR THICK bold glowing cyan #00e5ff fracture veins,
each vein clearly visible like bright electric cracks,
a soft pale cyan corona halo rim hugging tightly around the disc, bright enough to be seen,
ominous, quiet, wrong — a star that emits no light,
pure solid white background, no other objects
```
**验收**：盘体平均亮度 <25；青色裂纹 ≥3% 且线宽 ≥4px（保证 240px 仍可辨）；外晕可见不溢出；白底。
**部署**：放 `docs/地图重设计/generated/black_sun.jpeg` → 重跑部署脚本（走圆形蒙版）→ `--import`。

## 5. 代码结构（`scenes/world_map.gd`，~1250 行）

### 5.1 关键函数职责
| 函数 | 职责 |
|------|------|
| `_build_level_map` | 构建画布：底图→残骸→天光标签→gate→家→overlay→节点；静态模板缓存/复用 |
| `_layout_scheme11/8/6` | 布局数据（`_s_level_points` + `_s_bridges`，静态缓存，跨实例一致） |
| `_ensure_layout` | 布局分发（match MAP_SCHEME），只算一次 |
| `_refresh_static_state` | 每次构建刷新占领色环集合 + 巨环档位（含 WM_GATE_STATE 钩子） |
| `_apply_gate_state` | 三方案巨环/黑日三态贴图+尺寸+透明度 |
| `_make_level_node` | 相位泡节点（TextureButton + 数字 + 三形态 + tooltip） |
| `_draw_map_overlay` | 微光桥/占领环/当前光圈/相位缝（方案8）/代码兜底黑日（方案11） |
| `_center_on_current_level` | 视口居中当前关 / 新档定场镜头（≤3 关） |
| `_reconnect_level_buttons` | 静态模板跨场景复用时重连 BaseButton 信号（v7.5 补丁） |
| `_rebind_overlay` | 复用模板时重绑 overlay draw 信号到当前实例 |
| `_scatter_debris` | 残骸散布（按方案选 wreck/debris 前缀） |
| `_on_map_gui_input` | 左键拖拽平移 |
| `_show_level_info_popup` 等 | 关卡情报弹窗/进入/自动部署（原样保留，与布局无关） |

### 5.2 静态缓存机制（跨场景复用性能关键）
- `_s_level_points` / `_s_bridges` / `_s_occ_colors` / `_s_gate_state` / `_s_tex_cache`：静态，
  布局跨实例一致；动态状态（占领/档位）每次 `refresh_levels` 重建时刷新。
- `_cached_level_map_template`：构建完的画布模板，换场景后 duplicate 复用 + 重连信号 + 重绑 overlay。

### 5.3 测试钩子（环境变量，仅截图/调试用）
| 变量 | 效果 |
|------|------|
| `WM_VIEW_LEVEL=N` | 视口居中到第 N 关（跳过定场镜头）；`N=0` 居中到黑日/门位置 |
| `WM_GATE_STATE=far\|mid\|near` | 强制巨环档位（验三幕视觉） |

## 6. 换机部署流程（生成新图后）

```bash
# 1) 生成图放 docs/地图重设计/generated/（黑日 v2 命名 black_sun.jpeg）
python tools/deploy_world_map_assets.py          # → assets/map/
# 2) 导入（GODOT 按 AGENTS.md 自动探测路径）
godot --headless --rendering-driver opengl3 --path . --import
# 3) 全场景运行验证
godot --headless --rendering-driver opengl3 --path . --quit-after 120 res://scenes/world_map.tscn
# 4) 截图验收（可选，Windows 下需去 headless 跑 write-movie）
WM_GATE_STATE=mid WM_VIEW_LEVEL=0 godot --path . --resolution 1600x900 \
  --write-movie .godot/agent_tools/s.png --quit-after 30 res://scenes/world_map.tscn
# 5) 备份：python 打包 assets/map + generated 原图 → 项目外 zip
```
