## 1. 设计总览

**一句话**：一座横贯东西的格陵兰形手绘大陆，100 关以"内容锚定"方式压在图内醒目要素上
（西部石造废墟 → 中部冰穹/环形大城 → 东部黑城与晶体巨构），大致从左到右推进，
终点是东端尖角的**黑色传送门**。单屏显示，无滚动。

- 主题：格陵兰岛轮廓横放（宽端朝西、尖角朝东），废弃"晨昏线/天光档"设定。
- 画布：**2560×1440**（标准 16:9），单屏等比缩放适配可视区（无滚动/拖拽/缩放）。
- **不叠任何贴图**：黑门用原图画的；家是小号程序标记；节点纯程序绘制圆环。底图即全部。

## 2. 布局（单一事实源 = `data/world_map_layout_s11.gd`）

- 100 关坐标由 `tools/prototype_level_layout.py` 生成：
  14 个内容锚点（人工判读自定稿图，见脚本 `ANCHORS` 表）→ 锚点权重分配关数 →
  群内有机散布 → 全对重叠消除（≥45px）→ 空档>240px 从拥挤簇搬迁补位。
- 编号按 **x 排序**（大致从左到右）；时代 = 关卡号 ÷ 20（一战/二战/冷战/现代/近未来），
  只影响节点颜色，玩法数据（敌配/掉落）仍按关卡号取，与旧规则完全一致。
- 家（余烬要塞）= (577, 891) 西南绿低地（避冰雪）；黑门 = (2272, 774) 东端尖角（自动实测）。
- 布点审计（2026-08-29）：全对重叠 0；链间距 min 46 / 中位 ~110；>240px 空档为跨海段（连线作桥）。

## 3. 渲染与交互（world_map.gd）

- **单屏适配**：`_fit_canvas_to_viewport` 把画布等比缩放进 ScrollContainer 可视区并居中
  （scale clamp 0.30~0.55）。⚠️ 方案 11 画布 `custom_minimum_size` 必须为 0——
  DISABLED 滚动模式会把子节点最小尺寸算进容器，导致撑爆窗口。
- **v23.1 浮层化**：上下横条撤除，标题/势力领地图按钮/返回键改为**浮在地图上的角标**
  （顶中/右上/右下），面板放大 1264×688（main.tscn WorldMapPanel）——地图铺满全屏。
- **圈中加点节点**（`_make_level_node`，纯 StyleBoxFlat，零贴图）：
  - **白底圆盘 + 时代色环 + 深色数字**（对比度优先）；未解锁 = 半透明白盘灰字；
    首领关（10/20/…/100，PhaseMasterGarrison）= 金环加大；当前关 = 粗环 + 上方跳动点。
  - 布点最小间距 55px（v23.2 提升以容纳大圈），全对重叠 0。
- **overlay**：时代色虚线桥（家→L1…L100→黑门，宽 3/虚 16 空 10）+ 占领色环（r30）+
  当前关双光圈（r36/42）。占领势力仍按 v6.10 逻辑刷新。
- **家标记**：26px 橙色圆角方块 + "余烬要塞"小字，点击回基地（存档→bunker_main）。
- **黑门**：画门即门，**无三态贴图**；`_apply_gate_state` 对方案 11 恒隐藏 GateMarker。
- 标题："— 黑日战线 · 100 关 —"；势力领地图按钮/关卡弹窗/返回逻辑不变。

## 4. 底图规格与再生成

- 源：`generated/大地图2_2560.png`（用户处理定稿版）；部署 = 复制为
  `generated/dawn_dusk_continent.png` → `python tools/deploy_world_map_assets.py`
  （BASES 流程 2560×1440 原生直出）→ `godot --headless --import`。
- ⚠️ `deploy_world_map_assets.py` 有 `IGNORE_PREFIXES = ("大地图",)`——用户工作稿不入 assets。
- 需求与验收标准见《主地图图片需求_格陵兰.md》（轮廓/尺度/五代废墟/黑门/禁止清单）。

## 5. 布局调参与再导出流程

```bash
# 1) 改 tools/prototype_level_layout.py 的 ANCHORS / 参数
python tools/prototype_level_layout.py
#    → 产出 prototype_level_layout.html（网页原型）+ data/world_map_layout_s11.gd
# 2) 本地预览（8777 端口服务 docs/地图重设计/）
cd docs/地图重设计 && python -m http.server 8777
#    → http://127.0.0.1:8777/prototype_level_layout.html（刷新即最新）
# 3) 重启游戏（或触发 refresh_levels）看游戏内效果
```
