# 主地图图片需求（格陵兰参考版）v1.0

> 2026-08-29 定稿。交付对象：美术 / 生图工具。
> 需求附件（必看）：`generated/greenland/outline_reference.png`（真实格陵兰轮廓标注图）
> 轮廓数据：`generated/greenland/grl.geo.json`（格陵兰真实海岸线，132 点）
> 历史教训：见《格陵兰底图提示词与流程.md》废弃存档——本需求已吸收全部否决原因。

---

## 1. 用途与交付规格

- 用途：战术卡牌游戏《Phase War》主地图（100 关选关界面）底图，关卡气泡、占领色环、
  青色虚线桥由引擎叠加绘制。
- 画布：**2560×1440（16:9）**；若工具上限不足，最低 1312×736 原生交付（禁止再由更小图放大）。
- 格式：单张完整图（JPG/PNG），全画幅满铺，不留白边、不画装饰画框。
- 风格：手绘水彩/油画质感，俯视平面地图，低饱和沉稳色调，笔触细节丰富。

## 2. 构图与轮廓（硬约束）

- **以格陵兰岛真实轮廓为唯一形体参考**（见附件标注图）：旋转 90° 横放，
  **宽端朝西、南端尖角朝东**；海岸峡湾深切、北缘破碎群岛感。
- 陆地横贯画面：从西画幅边缘延伸到东画幅尖端；**海只占上下边缘条带与东侧尖端外**。
- 附件图中三个标注必须成立：
  - 西端宽地 = 家（余烬要塞·起点），地势平缓可读；
  - 东端尖角 = 黑色传送门（终点）；
  - 陆地中部（约东西 1/4 ~ 3/4 段）= 100 关 · 5 条战线铺装区，须为**连贯、开阔、可读**的陆地。

## 3. 地形内容（大陆视角）

**可见**（数十~数百公里级）：
- 沿岸峡湾、离岸小岛（少量）、近岸浅水色变；
- 一圈沿岸山脉脊线（山体有明暗起伏，光源自西北）；
- 内陆高地冰穹（白雪大面块，边缘有冰川舌向外海方向溢出）；
- 河流自内陆入海（细线即可）、苔原湖泊（少量）；
- 低地绿带：西侧宽、向东渐窄渐灰。

**不可见**（尺度穿帮，出现即不合格）：
- 单栋建筑、房屋、农田田块、道路线、城墙、战壕线条、单独树木。

## 4. 五代废墟系统（西旧东新，承接游戏叙事）

废墟是**数十公里级的色斑/痕迹区**，不是单体物件；散布交错、**不得排成横带**：

| 位置 | 年代 | 视觉表现 |
|------|------|----------|
| 西端一带 | 一战 | 白垩色疤痕荒地斑、灰枯林团 |
| 偏东 | 二战 | 中灰炭化焦区、夷平城镇足迹 |
| 中东 | 冷战 | 大片死工业灰区 |
| 更东 | 现代 | 暗灰色废都块群 |
| **黑门周围最密** | 未来 | 巨构残骸场 + **青色微光裂网**（全图唯一允许的青色发光） |

## 5. 黑色传送门（终点视觉锚）

- 位置：**东端尖角**（陆尖上或贴尖角海面），圆盘直径约占画布宽 3%；
- 纯黑圆盘 + 细青白光环 + 微弱外晕；阴森、安静、"不发光的黑洞"感；
- 周围地表应有被灼烧/扭曲的痕迹，越靠近越荒。

## 6. 光照与色彩

- 柔和自然光，无明显时刻感；允许西端略暖、东端略冷压蓝的**大趋势**，但禁止做成
  左右两半的生硬分色或"晨昏线"式渐变带（前一版因此被否）。
- 主色参考：苔原绿、岩灰、雪白、深海蓝；点缀色仅允许黑门系统的青白光。

## 7. 禁止清单

地球其他大陆剪影/星球曲率/太空视角/云层｜横向条带或平行地貌带｜网格、经纬线、
地图框、罗盘、文字水印｜单栋建筑与道路｜大面积纯青色（会压过游戏 UI 的青色标记）｜
高饱和艳色。

## 8. 验收标准（可量化）

1. 轮廓：与 `outline_reference.png` 叠合，主形体偏差目视 <5%；
2. 尺度：全图任意处放大 2 倍检视，无可辨识的单体建筑/田块/线条类人工物；
3. 废墟：西/中/东三段各至少一处可辨的年代斑（颜色/纹理差异），黑门周围密度最高；
4. 黑门：位于东尖角 ±2% 画布范围内，纯黑可辨；
5. 铺装区：中部连线区域内无大面积海、无不可读的高对比噪声；
6. 画布 16:9 满铺、无框、无文字。
