## R15 改动说明

**文件**: `scenes/units/bullet.gd`

1. **速度缩放光束端点**（仅 wt 6/8，即 SNIPER/LASER）:
   - `BEAM_VISUAL_LEN = 80.0`（基础长度，低速弹）
   - `BEAM_TRAIL_SPEED_BASE = 400.0`（速度基准，低于此速不延长）
   - `BEAM_TRAIL_SPEED_MULT = 0.06`（每超1px/s延长0.06px）
   - `BEAM_TRAIL_MAX = 200.0`（封顶防止污染命中格）
   - f06/f08速度约400-600px/s → 延长12-36px，总长92-116px
   - f11速度约800-1000px/s → 延长36-60px，总长116-140px

2. **光束加粗**（wt 6/8）:
   - SNIPER (wt 6): 16px → 24px
   - LASER (wt 8): 20px → 28px

3. **非光束族（f00-f05, f07, f09-f10, f11）** 保持原始静态10px光束，不受影响。
