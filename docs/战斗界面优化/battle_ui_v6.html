2视觉风格：废土科技六色 — GPT §9，颜色即功能

六色功能体系

  • #27e08a 我方 — 描边/血条/选中/可部署
  • #ff3852 敌方 — 描边/血条/禁止/退出
  • #a861ff 技能 — 符文/主动技/能量池
  • #ffc24a 资源 — 金币/费用/关号/Lv
  • #ff8420 危险 — 低血量/BOSS/警报
  • #0e1830 UI 底 — 面板/栏底

设计原则

  • 解决原图"所有元素一个亮度、无视觉重点"
  • 颜色=功能：看到颜色就知含义
  • 亮度对比：关号/费用/选中高亮+光晕，普通元素压暗
  • 战场占 66%，状态 13%，操作 21%（原图战场仅约 45%）

战斗反馈分层

  • -292 普通命中：白色
  • ⚡CRIT -580 暴击：金色放大
  • 🛡-120 护盾吸收：紫色
  • 低血量(<30%)：血条闪橙动画 + ⚠ 警告

部署网格三态

  • 空 灰虚线（无操作）
  • 可放 翠绿实线+发光
  • 禁止 红色（敌区）
  • 已占用：半透明 ✓

3最终目标：3 秒决策清晰度 — GPT 结尾验收

玩家进入战斗 3 秒内应知道

  • ✅ 基地状态 左上基地卡：HP 8500 / 能量 120 / 部署 2/7
  • ✅ 当前波次 顶部居中：第 15/30 波 + 进度 + BOSS 标记
  • ✅ 敌人方向 右侧红色单位群 + 低血量闪烁
  • ✅ 可部署位置 左下绿色网格（拖卡时三态高亮）
  • ✅ 可用卡牌 底部翠绿发光卡 = 能量够+可部署
  • ✅ 下一步操作 右侧紫色脉冲技能 = 可立即释放

核心原则

  • 原图问题不是美术质量，而是 UI 把策略信息隐藏了
  • 优化重点从"漂亮"转向 "战斗决策效率"
  • 主菜单是养成/浏览功能，战斗结束后才显示
  • 战斗中玩家只需"控制战斗"的按钮
