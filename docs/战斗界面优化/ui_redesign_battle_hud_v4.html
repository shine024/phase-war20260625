②阵营色体系（废土科技风）

功能色定义

  • #00ff9d 我方 — 青绿（描边/血条/选中圈）
  • #ff3b4a 敌方 — 红（描边/血条/警告）
  • #b46cff 技能 — 紫（符文/主动技能）
  • #ffd23f 资源 — 金（能量/金币/星级）
  • #ff8c1a 危险 — 橙（低血量/警告）
  • #0a1428 普通UI — 深蓝（面板底色）

色系应用规则

  • 我方单位：青绿描边 + 青绿血条 + 蓝绿选中圈
  • 敌方单位：红描边 + 红血条 + 低血量闪红动画
  • 能量不足卡牌：费用变灰，不可点击
  • 冷却中卡牌：黑色遮罩 + 倒计时数字
  • 可部署卡牌：青绿发光边框（玩家注意力锚点）
  • BOSS波次：波次进度条变红 + 顶部警告

③卡牌栏重构（90px 高度）

卡牌结构（4要素）

  • 左上角 费用圆圈（金色/灰色=不足）
  • 中部 卡图区（56px 高，渐变背景）
  • 底部 卡名（9px，单行省略）
  • 右下角 数量（×N，紫底）

状态反馈

  • 可部署：青绿发光边框，hover 上浮4px
  • 冷却中：黑色遮罩从下往上扫，中间显示秒数
  • 能量不足：费用变灰，卡牌半透明
  • 选中待部署：脉冲青绿光圈
  • 分隔线：区分普通卡 / 符文 / 技能

④战场单位 + 部署网格 + 伤害反馈

单位信息（4层）

  • 顶部：名字 + 5px血条 + 血量数字
  • 本体：64×64 卡图 + 右上等级徽章
  • 选中：青绿地面圈 + 攻击范围虚线圈
  • 低血量：血条闪红动画（<30%触发）

部署网格三态

  • 空位可放：青绿虚线 → 实线
  • 已占用：半透明，不可放
  • 禁止区：红色（敌方领地）
  • 拖拽卡牌时网格自动显示，松开隐藏

伤害数字分层

  • -292 普通伤害：白色
  • ⚡-580 暴击：金色+放大+⚡前缀
  • 🛡-120 护盾吸收：紫色+🛡前缀
  • 所有数字上浮+淡出动画（0.8s）

⑤底部菜单重构：主菜单 → 战斗菜单

原版（12个主菜单按钮）v4（6个战斗按钮）说明
背包 / 成长 / 势力 / 任务 / 商店 / 排行 / 情报 / 地图 / 设置 / 图鉴 / 存档 / 挂机暂停 · 自动 · 技能 · 卡组 · 设置 · 退出 + 1x/2x 倍速主菜单全部移到 非战斗状态（关卡选择界面）

⚠ 核心原则：战斗中玩家只需要"控制战斗"的按钮，所有养成/浏览类功能在战斗结束后回到基地界面再打开。

⑥右侧能量球 → 技能按钮组

原版问题

  • 单个蓝色冰球，无任何信息
  • 玩家不知道：是什么技能 / 能不能用 / 花多少能量
  • 视觉突兀，与UI风格不符

v4 方案

  • 改为 3个技能按钮 竖排（EMP/空袭/护盾）
  • 每个按钮：图标+名称+费用+冷却
  • 可用：紫色脉冲发光动画
  • 冷却中：黑色遮罩+倒计时
  • 能量不足：费用标红
  • hover：显示射程/范围提示箭头
