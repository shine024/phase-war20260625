0. 问题总览 — 新旧对比

❌ 修改前
  • 战斗区域仅占 45%，被 UI 挤压严重
  • 底部常驻 10+ 主菜单按钮（背包/成长/势力…）
  • 信息全部平铺，无层次，玩家无处聚焦
  • 单位颜色灰暗，阵营不分，血条不明显
  • 部署点只是一堆小圆点，无状态区分
  • 右侧技能球看不出是否可用
  • 伤害数字固定红色，无暴击/护盾区分
➜
✅ 修改后
  • 战斗区域扩大到 70%，视觉焦点回归战场
  • 底部常驻改为暂停/自动/技能/卡组（仅 4 个）
  • 三层 HUD 结构：关卡→资源→状态，按需展开
  • 我方青绿描边 / 敌方红色描边，血条 2px 加粗
  • 部署网格三色：灰(空)/绿(可放)/红(禁止)
  • 技能带 CD 遮罩 + 可用发光光圈
  • 普通伤害白字 / 暴击金色大字 / 护盾蓝色吸收

3.3 设计要点

  • 折叠态只展示 最关键的 4 个数字：基地HP / 能量 / 单位数 / Buff条目数
  • 展开/收起使用 200ms 平滑动画，不阻塞游戏
  • BUFF 列表超出 3 项时显示"+X more"，鼠标悬停弹出全部
  • 基地 HP 低于 30% 时进度条变橙色闪烁；低于 10% 变红色快速闪烁

5.3 卡牌状态

状态表现说明
就绪 正常亮度 + 绿色底光 能量足够 + CD 结束

5.4 布局细节

  • 卡牌宽度固定 100px，6 张 + 间隔 = 约 700px，居中放置
  • 超出 6 张时可左右滑动（手势/滚轮），当前页卡片放大显示
  • 已部署的卡牌进入 6s CD，CD 期间不能重复部署同卡
  • 支持拖拽部署：从卡牌栏拖到部署网格上直接放置

10. 开发优先级与工作量评估 规划

第一阶段 — 立竿见影 (P0)

  • 1
    移除底部主菜单 — 砍掉背包/成长/商店等 10 个按钮，替换为 4 个战斗按钮。工作量：小。收益：战斗视野立刻清爽。
  • 2
    重做底部卡牌栏 — 高度 120px→90px，加费用/CD遮罩/就绪条。工作量：中。收益：卡牌从"仓库感"变为"技能栏"。
  • 3
    单位阵营配色 + 血条增强 — 我方绿描边/敌方红描边，血条加粗至 3px。工作量：小。收益：一眼分敌我。
  • 4
    左侧面板折叠/展开 — 默认折叠只显示 4 数字，点击展开详情。工作量：小。收益：减少信息噪音。
  • 5
    HUD 三层重构 — 关卡居中 + 波次进度条 + 资源右上精简。工作量：中。收益：核心信息一目了然。
