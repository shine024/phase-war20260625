4设计规范 取自v3 取自v4

废土科技六色体系

  • #00ff9d 我方 — 青绿（描边/血条/选中）
  • #ff3b4a 敌方 — 红（描边/血条/警告）
  • #b46cff 技能 — 紫（符文/主动技能）
  • #ffd23f 资源 — 金（能量/金币/星级）
  • #ff8c1a 危险 — 橙（低血量/警告）
  • #0a1428 普通UI — 深蓝（面板底色）

布局尺寸（1280×720）

  • 顶部 HUD：108px（15%）— 基地卡/关号/资源
  • 战场区域：504px（70%）— 单位+基地+部署网格
  • 卡牌栏：108px — 左右箭头+8卡槽+分隔符文/技能
  • 战斗菜单：52px — 6按钮+1x/2x 倍速
  • 左侧基地卡宽 200px，右侧资源宽 180px
  • 单位 54×64px，血条 56×5px，网格 44×44px

交互反馈

  • 卡牌 hover 上浮4px + 紫光/青光阴影
  • 可部署卡牌：青绿发光边框（玩家注意力锚点）
  • 冷却中：黑色遮罩从下扫 + 倒计时数字
  • 能量不足卡牌：费用变灰，半透明
  • 技能可用：紫色脉冲动画（1.5s）
  • 低血量单位：血条闪红（<30%）
  • 部署网格：拖卡时三态高亮

信息层级（三层）

  • 第一眼：关号+波次（顶部中央金色）
  • 第二眼：敌我单位位置+血量（战场中央）
  • 第三眼：基地状态+资源+可用卡牌（边缘）
  • 详细属性（攻击/防御/暴击/射程）折叠隐藏
  • 点击单位/基地卡才展开详情
  • 避免战斗界面信息爆炸

5Godot 实现建议 取自v3

① 顶部 HUD：MarginContainer + HBox

锚点 top=0/bottom=108。三个子区域用 HBoxContainer：左基地卡(Control 200px) + 中关号(ContainerCenter) + 右资源(VBoxContainer)。基地卡用 Panel + StyleBoxFlat 左边框 3px 青绿。

② 战场单位：Sprite2D + 浮层 Control

单位本体用 Sprite2D/TextureRect，顶部信息用 Control(anchored top=-44)。血条 ProgressBar(custom=true)，阵营色靠 modulate 或独立 theme。选中圈用 Sprite2D 透明 PNG，攻击范围用虚线圆 texture。

③ 底部卡牌栏：HBoxContainer + 自定义 CardSlot

HBoxContainer 装 8 个 CardSlot(TextureButton 或自定义 Control)。费用圆圈=Label+StyleBoxFlat 圆形。冷却遮罩用 TextureProgress 反向填充或 ColorRect + clip。可部署状态用 Theme 切换边框色。

④ 战斗菜单：HBoxContainer + Spacer

6个 Button + 中间 Spacer(Control h-stretch) + 2个倍速 Button + 设置/退出。主菜单全部从 main.tscn 的 PopupLayer 移除，改为仅在非战斗场景显示（GameManager 状态机控制 visible）。

⑤ 部署网格：GridContainer + 三态

4×2 GridContainer，每个 cell 是 ColorRect/TextureButton。三态用 modulate 切换：绿(available)/半透明(occupied)/红(blocked)。只在 BattleInputState.pending_deploy 非空时 visible=true。

⑥ 伤害数字：Label + Tween 上浮

用 ObjectPoolManager 复用 Label。spawn 时 create_tween，position.y -= 30 + modulate.a 0→1→0（0.8s）。暴击用金色+放大，护盾用紫色+🛡前缀，普通用白色。
