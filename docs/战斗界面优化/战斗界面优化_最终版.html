2视觉风格：废土科技风 — 提示第九节

六色功能体系

  • #00e89c 我方 — 青绿（描边/血条/选中圈）
  • #ff3a4a 敌方 — 红（描边/血条/警告）
  • #b060ff 技能 — 紫（符文/主动技能）
  • #ffcc33 资源 — 金（能量/金币/费用）
  • #ff8a1a 危险 — 橙（低血量/警告）
  • #0c1830 普通 UI — 深蓝（面板底色）

设计原则

  • 解决原版"所有元素接近一个亮度、无视觉重点"问题
  • 颜色 = 功能：看到颜色就知道含义（绿=我方/红=敌方/紫=技能/金=资源）
  • 亮度对比：高亮元素（关号/费用/选中）用金色+光晕，普通元素压暗
  • 统一面板：所有卡片用深蓝半透明 + 阵营色边框

3战场单位与战斗反馈 — 提示第四节（重点）

阵营色区分

  • 我方：青绿描边 + 青绿血条 + 蓝色选中圈
  • 敌方：红描边 + 红血条 + 低血量警告动画（闪红）
  • 原版灰色单位无法区分敌我 → 阵营色一秒识别

单位信息（4层）

  • 顶部：名字 + 5px 血条 + 血量数字
  • 本体：56×66 卡图 + 右上等级徽章
  • 选中：蓝色地面圈 + 攻击范围虚线圈
  • 低血量（<30%）：血条闪红动画

攻击反馈 · 伤害分层

  • -292 普通命中：白色数字
  • ⚡ CRITICAL -580 暴击：金色放大 + ⚡ 前缀
  • 🛡 -120 护盾吸收：紫色 + 🛡 前缀
  • 所有数字上浮 + 淡出（0.8s）

部署网格三态（提示第五节）

  • 空：灰色虚线（无操作时）
  • 可放：青绿实线 + 发光
  • 禁止：红色（敌方领地）
  • 已占用：半透明 ✓

4卡牌栏（90px）与技能按钮 — 提示第六、八节

卡牌结构（费用+冷却）

  • 高度从 120px 降至 90px（悬浮卡牌感）
  • 左上角费用圆圈（金色，能量不足变灰）
  • 中部卡图 + 底部卡名 + 右下数量
  • 可部署卡：青绿发光边框
  • 冷却中：灰色遮罩从下往上扫 + 倒计时秒数

右侧技能按钮（替代能量球）

  • 原版单个蓝色冰球无信息 → 改 3 个技能按钮
  • 每个按钮：图标 + 名称 + 费用 + CD
  • 可释放：紫色脉冲光圈动画
  • 冷却中：黑色遮罩 + 倒计时
  • 能量不足：费用标灰
  • hover：显示范围提示箭头

5底部菜单重构 — 提示第七节

原版（12 个养成主菜单）优化（6 个战斗按钮 + 倍速）
背包 · 成长 · 势力 · 任务 · 商店 · 排行 · 情报 · 地图 · 设置 · 图鉴 · 存档 · 挂机 暂停 · 自动 · 技能 · 卡组 · 1x/2x 倍速 · 设置 · 退出

⚠ 核心原则：主菜单是养成/浏览功能，战斗结束后才显示。战斗中玩家只需要"控制战斗"的按钮。

7最终目标：3 秒决策清晰度 — 提示结尾

玩家进入战斗 3 秒内应该知道：

✅ 我的基地状态左上基地卡：HP 8500 / 能量 120 / 单位 2/7
✅ 当前波次顶部居中：第 15/30 波 + 进度条 + BOSS 标记
✅ 敌人方向右侧红色单位群 + 低血量闪烁警告
✅ 可部署位置左下绿色网格（拖卡时三态高亮）
✅ 可以使用什么卡牌底部青绿发光卡 = 能量够 + 可部署
✅ 下一步操作是什么右侧紫色脉冲技能 = 可立即释放

💡 原图的问题不是美术质量，而是 UI 把策略信息隐藏了。优化重点从"漂亮"转向 "战斗决策效率"。
