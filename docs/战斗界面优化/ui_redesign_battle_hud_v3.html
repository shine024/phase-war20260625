🎨 设计规范

配色体系

  • #0b0d1a 深空蓝黑 — 全局底色
  • rgba(15,20,40,0.92) 半透明深蓝 — 面板背景
  • #00e5ff 霓虹青 — 我方边框/高亮
  • #ff4444 霓虹红 — 敌方边框/血量
  • #ffd700 金色 — 关号/星级/重要提示
  • #00ff88 翠绿 — HP满值/正面buff
  • #e8eaed 亮灰 — 主要文字
  • #5f6368 暗灰 — 次要文字/占位

布局结构

  • 顶部栏: 48px 高 — 关号(中) + 计时(右) + 资源(左)
  • 状态条: 紧贴顶栏下 — 时间/单位数/击杀/伤害横排
  • 左上面板: 180px 宽, 可折叠三段(BUFF/面板/资源)
  • 右侧能量球: 80×80 脉冲动画 + label 标注
  • 战场区: 底部留出 240px 给底部栏, 剩余全给战场
  • 底部装备行: 84px 高 — 左右箭头 + 8个槽 + 分隔线 + 4槽
  • 底部导航栏: 52px 高 — 12按钮均分 + 4个右侧功能键

交互细节

  • 所有卡片 hover 时边框发光 (box-shadow glow)
  • 可折叠面板 header 点击展开/收起, 箭头旋转动画
  • 能量球持续脉冲动画 (3s 周期)
  • 装备槽 hover 边框变青色
  • 导航按钮 hover 半透明蓝底, active 有底部横线
  • 选中敌方单位有金色边框+阴影提示
  • BUFF标签跟随单位浮动显示

响应式策略

  • 固定 1280×720 设计基准
  • CSS transform scale 适配浏览器预览
  • Godot 实际实现用 Container + Anchors
  • 战场区域使用 MarginContainer 四周留白
  • 底部区域用 VBoxContainer 垂直排列装备行+导航行

🔧 Godot 实现建议

① 顶部栏用 MarginContainer

锚点设为 top=0, left=0, right=0, bottom=48。子节点水平 CenterContainer 放关号，Anchor Layout=Right 放计时，Anchor Layout=Left 放资源。

② 左侧面板用 Control + Clip Contents

三个 VBoxContainer 分别对应 BUFF/面板/资源，每个 Header 用 Button + 信号控制下面 Body 的 visible 属性。width=180, 用 Anchors Preset Left-Top 固定。

③ 战场单位用 Sprite2D/TextureRect

我方单位用 TextureRect 放卡图，上方 add_child(HBoxContainer) 做信息浮层。血条用 ProgressBar(vertical=false)，绿色填充。敌方同理但红色填充。

④ 底部装备栏用 HBoxContainer

先放左右箭头(64px)+ 装备槽(64×80, 用自定义控件绘制) + 分隔线 + 符文/技能槽。用 CustomStyle-styles 设置深紫渐变背景。导航栏新建独立 HBoxContainer 在下方。
