# 单位分帧动画生成管线（agnes-video keyframe 图生视频）

> 2026-09-10 批次④动画重生成轮沉淀。生成/替换任何单位分帧动画前必读。
> 权威脚本：`tools/generate_unit_animations.py`（子命令 upload/create/poll/build/batch/check/preview）。

## 一、管线总览

```
白底参考图(_ref/*.jpg) → imgbb 传图 → POST /v1/videos (mode=keyframe, first_frame=URL,
aspect_ratio=16:9, size=720P) → 轮询 GET /agnesapi → 下载 source.mp4
→ ffmpeg fps=8 抽帧 → 白底转透明 v6c(cv2连通域) → 全帧并集bbox → 512画布合成(脚底92%)
→ 雪碧图 sheet_<anim>.png(512/帧) → 【质检门】→ 降采样256(LANCZOS) → 部署 unit_anims
```

- 模型：`agnes-video-2.5-flash`（keyframe 模式=首帧图锁外观）
- API 基址：`https://apihub.agnes-ai.com/v1`（`api.agnes-ai.cn` 的 key 已全部 401 作废，2026-09-10 实测）
- key：`tools/_api_key.txt`，一行一个；**#2 已 401 作废**，活 key=#1/#3
- 限流：免费档实测约 1 次/分钟（429 即退避 30s 重试）；**多 key 可并行各建单**（用户确认），并行驱动模板见 `tools/_tmp_b4_anim_phase2_parallel.py`
- imgbb key 硬编码在脚本内；ffmpeg 路径硬编码 chocolatey bin

## 二、参考图规范（`资料/单位分帧动画/_ref/<unit>_white.jpg`）

1. 512×512 白底 JPG，主体居中留 ~7% 边距（生成脚本见 `_tmp` 系列 build_ref）。
2. **朝向必须朝左**（游戏敌方约定，动画 prompt 全部按"指向画面左侧"写）。批次④卡图（player 版）朝右时**必须水平镜像**——flak 首轮翻车根因即漏镜像。
3. 从哪来：与该单位当前卡图同源。批次④卡图 = `docs/flow重生成_审查/战斗卡_批4/*.png`（白底 1376×768，需裁切）；编制卡 = `assets/card_icons/enemy/<id>.png`（透明底，需垫白）。
4. **参考图与卡图造型必须同步更新**——c96 首轮动画跑成旧绿兵，根因就是 ref 还挂着 08-29 旧版。换卡图必换 ref。
5. 浅色主体（银白/浅灰装甲）在 UNITS 配 `mn_floor`（c96=200），防白底转透明误抠。

## 三、Prompt 要点

- 动作描述 + 固定咒语（镜头锁定/纯白底/首尾帧一致/完整在画面内）按 UNITS 表维护。
- **全身入镜句**（"全身入镜，从头顶到脚底完整可见，绝不半身特写，绝不裁切腿部"）是半身问题的对症药，步兵类必带。
- **抗漂移句**（"大小、位置与构图全程与首帧完全一致，绝不放大缩小平移俯视；画面中只有这一个单位，没有碎片漂浮物"）前置，防取景漂移与穿帮。
- idle 想安静可写"几乎静止，只有胸部极轻微呼吸起伏"——注意副作用见 §五。

## 四、质检门（全过才算完成，缺一不可）

| 检查 | 标准 | 工具 |
|---|---|---|
| 帧数 | idle=8 / attack=12（=anim.json counts） | 验收脚本 `_tmp_b4_anim_verify_v3.py` |
| 重复帧 | 0（回文构造除外，属预期） | md5 逐帧 |
| 贴顶/贴底 | 0 帧（全身不被裁切） | alpha bbox |
| 朝向 | 逐帧列轮廓与 ref 相关性 ≥ 镜像版；**必须朝左** | 同上 |
| 循环接缝 | ≤ ~20（首尾帧 RGB 差,已上线基线 31） | — |
| idle 相邻帧差 | < 15（否则观感摆动过大） | — |
| 目视 | 全帧条带图 + 与卡图同款比对（人眼） | 拼图 Read |

## 五、已知坑与对策（每条都真实踩过）

| 坑 | 对策 |
|---|---|
| 半身裁切（旧版全线腰斩） | 16:9 画幅 + 全身入镜 prompt（满幅方图会诱发模型推近取景） |
| attack 动作模型偏好**朝右**（三掷两翻） | 重roll 碰运气；或反向操作：ref 给朝右版、成片整表镜像（根治） |
| 视频模型对**复杂机械形逐帧融变**（坦克车体每帧微变形=用户所见"变形"） | **载具优先卡图直出程序化合成**（`tools/_tmp_b4_anim_prog_build_v5.py` 范式：卡图抠主体→512 画布→idle 微颤/attack 火光帧叠加），造型与卡图逐像素一致 |
| 视频不回环，接缝 50 | 截短 `source.mp4` 前 60% 重建（收效有限时）→ **回文帧序** `0..N-1..1`（确定性，循环点=相邻帧差） |
| "几乎静止"prompt → 有效变化帧 <8（实测仅 5） | 用有效帧拼 8 格回文（如 0,1,2,1×2），**anim.json counts 不动**，游戏加载器无感 |
| 脏帧：模型画地面阴影/背景光晕/悬浮黑块 | 目检条带图逐帧看，弃脏帧用干净帧重组 |
| step_build 每次从 source.mp4 **重抽帧** | 裁帧长度要裁 mp4（`ffmpeg -t`），裁 raw/ 目录会被覆盖白做 |
| 限流 429 | 退避 30s 重试跨分钟窗口；多 key 并行分摊 |
| 新 png 导入 `--import` 直跑崩(0xC0000005) | 部署路径不变时 `.import` 侧车仍有效，编辑器下次扫描自动重导入；不要手动跑 --import |
| **朝向观感约定**：sheet 按**敌方视图朝左**为真身（游戏对我方 flip_h 镜像成朝右，实机截图已验证），直接看图会觉得"没向前开枪"是错觉 | 审查时以实机截图或"我方视角镜像预览"为准，勿按图面方向下结论 |

## 六、部署规范

1. 512 master → LANCZOS 降采样 256（`2048×256` idle / `3072×256` attack）写入 `assets/effects/unit_anims/<unit>/sheet_<anim>.png`；**anim.json（fps/frame_size/counts）不改**。
2. **描边预烘焙（v6.15，性能项）**：发布期把运行期 alpha 膨胀 shader（`shaders/unit_outline.gdshader`，核显 fillrate 大头）离线画进图，Godot 读 `anim.json` 的 `outline.baked` 跳 shader（`UnitFrameAnim.is_outline_baked`）。两条批处理，均幂等、原图备份 `.godot/art_backup_outline_<date>/`：
   - 横条 sheet：`python tools/deploy_unit_anims.py --bake-existing`（4px@256 基准，逐帧切片防串帧）；
   - **boss 逐帧（idle_f*.png，BossIdleAnim 消费）**：`--bake-boss-frames`（7px@512 基准 = 屏 ~1.6px @ boss scale 0.23；目录 anim.json 为纯 outline 标记）。⚠️ `attack_f0` 姿态帧**刻意不烘**——11/16 因 v24.3 守卫永不显示，其余仅开火瞬间 0.16s 显示，且宿主静态卡图仍走 shader，烘了会二次外扩。
3. 旧部署表先备份 → `docs/flow重生成_审查/动画雪碧图/_deployed_v1_backup/`；512 master 同步审查区 `动画雪碧图/`（旧版进 `_v2备份/`）。
4. 改动卡图后同步重打包美术基线（`F:\godot fair duet\_art_backup\` 按日期惯例）。
5. 无指令不 commit（PNG 本就 gitignore）。

### 验收标准（用户拍板，大幅放宽）

- 游戏是**固定位置弹幕互射**：待机帧只要玩家看得到变化即可；攻击帧"大概有开火动作"即合格。
- **不追求逐帧动作序列精确性**——六格一致性好+有开火光 > 动作幅度大但身份漂移。
- 火光要小甚至没有（开火别喧宾夺主）。

### 两条产出规则

1. **卡图可反向再生**：雪碧图质量好但与原卡图不符 → 不否决雪碧图，用其最佳帧反向生成新卡图（动画=真身，卡图跟随）。
2. **同一单位三套提示词**（attack6 模式 A/B/C 风格）出三版比选：A 直叙帧表 / B 分镜动词 / C 首尾锚定。
3. **雪碧图合格但裁剪废 → 灵活救**（用户拍板 09-29）：原始出图好、只是切格/抠像/注册环节裁坏的，
   优先调切格参数（间隔带阈值/三等分兜底/格序）或手改裁剪框重切，勿直接否决重掷——废的是裁剪不是图。
   实测：C 一致性最好、A 动作性最好、B 易翻车（"压低/反冲"被画碎）。

### 管线参数（踩坑沉淀）

- 格间宽纯白间隔带（≥格宽 1/4）+ 无序号无边框——间隔带自动检测切格才稳。
- 6 帧够用（弹幕互射观感）；attack6 2K 16:9 出 3×2；idle 回文拼 8 帧（counts 不动）。
- register：火光不计宽（防帧间大小漂移）+ 内容钳内（防火光出帧）。
- prompt 三律：主体名词锁死（防举武器→士兵）、视角句（防俯视，对称主体反而要去掉）、负面词禁用（正面意象锁死）。

### 阶段0 锚定帧（身份锁死的关键）

- **锚定帧=真身**：后续攻击表以它为 Image 1 身份锚，卡图只做概念参考与调色基准。锚定帧一旦目验通过即冻结，不再回改。
- prompt 四要素：纯侧面朝左 / 5% 边距 / 纯品红 #FF00FF 平涂 / 中性待机无特效。
- 参数 `size:"1K", ratio:"1:1"`；`--chroma-out` 出棋盘格透明预览供目验。
- 姿态选"悬停待机"而非卡图飞行姿态——卡图是肖像，动画是战场精灵，两链路（repo 方法论原意）。

### 阶段1 攻击表（3:2 方格参数）

- **必须 3:2 + 3×2**：2496×1664 ÷ 3×2 = 832² 正方格，切格零裁损。5×2/16:9 实测被模型无视（画成连环画）。
- 双图驱动：Image 1=锚定帧（身份）、Image 2=**f0 铺格导图**（锚定帧缩样铺 3×2 白底白带，模型照抄版式）。
- 帧序六格：待机→蓄力小光点→开火爆发→火光衰减→后坐余烟→闭合（首尾=待机）。
- prompt 六条硬性（缺一实测翻车）：
  1. 【大小】六格主体同大小如同复制粘贴，不出格不触边
  2. 【站位】主体中心在本格横向右侧 40%（左留火光空间）
  3. 【朝向】全部面朝正左，禁朝右/正脸/俯视/3-4 视角
  4. 【分格】六格独立完整姿态，炮管火光烟不入邻格
  5. 【特效】无弹道无弹丸无光束——只要炮口火光和烟（用户拍板）
  6. 【无地面】悬浮精灵：无地面无影子，火光不在下方产生反光光斑
- 多掷 `--rolls N`：单掷命中率 ~4/6 格，多掷选优+跨版拼格。

### 阶段2 规范化（normalize_sheet，坑全在切除侧）

顺序固定：`键控 → depink → keep_main_bodies → bbox → fit_armor → 全局sc → 右缘底缘锚定`

1. **键控**：背景色=全域量化直方图众数（边框采样会被出图白外框骗）；近背景+近白双候选+边缘连通 BFS（保机身内部白高光）。
2. **depink**：`(r-g>18)&(b>=g-10)&(lum>120)` 映射灰——品红底映衬粉烟根治，橙火（B 低）不误杀。
3. **keep_main_bodies(0.35)**：全分辨率连通域只留 ≥最大域 35% 的域。**勿用降采样孤岛剔除**——/4 采样跳过 1px 细线所在行，白带阴影线/光带残端全逃（fut_nano_drone V5 实测，污染物全 ≤主体 2% 且独立不连通）。
4. **fit_armor（--card-align）**：Reinhard mean/std 迁移**只动装甲色域像素**（掩膜+高斯羽化 2px）。
   实测：色相 208°vs209° 同蓝但亮度差 1.65x——迁移后贴卡图。全帧迁移会把炮口黑环拉暗红、烟拉绿（踩过已修），蓝系掩膜是必须。
5. **全局唯一缩放，宽约束优先**：`sc=(256-24)/最宽帧宽`。横向开火帧宽>高，repo 的"70% 高"规则必爆宽。
6. **右缘+底缘锚定贴回**（偏移各 12px）：机身钉死，火光向左伸缩不晃机身（用户拍板"主体靠右"）。禁止水平居中。

### 阶段2' 原样直出雪碧图（sheet_direct，2026-09-30 用户拍板，**默认主路**）

用户拍板原话："**不可以直接复制原图做雪碧图么，抠背景，反的部分反过来，高低前后直接生成出来的，比你做出的雪碧图保持的好**"——原图 832² 格原位保留，不缩放、不重排、不贴 256。保真度优于 256 重排（256 路实测：贴回爆宽、机身忽高忽低、裁剪切断主体）。

链路固定：`键控 → keep_main_bodies → depink → strip_rail_cols → facing 翻转修正 → fit_armor → 原位拼回`

1. **frame_size=832**：原图 2496×1664（3×2），每格 832²，去底后**原位**放回雪碧图 `<key>_attack_sheet_832.png`（2496×1664 不变）。高低前后、相对大小、构图全保持模型原样。
2. **strip_rail_cols(min_len=100, ratio=1.8)**：残线列清除——某列 alpha 行跨度 >100 且 >邻 3 列中位 ×1.8 → 整列清（战机制服：竖白线粉白色 (234,152,150) 与焰橙可色判区分）。行列双向。BAND 边带清/strip_edge_runs 均败于此坑，唯此法成。
3. **facing 翻转修正（取代"镜像翻格弃用"旧规）**：`facing()` 排橙焰像素（r>140 & r-b>60）后比左右 1/4 窗口列高，R 朝向格整格 mirror 翻正。准确率 22/24，提示性体检——**翻转后必须目验**。
4. **fit_armor**：同 256 路，蓝系掩膜+羽化，原分辨率直接做（无缩放环节）。
5. **产出**：`<key>_attack_sheet_832.png`（**唯一验收物**）+ `_attack_cells.png`（contact 目验用）+ `_attack_anim.gif` / `_attack_anim_pal8.gif`（256 缩预览）。
6. **5 帧回文拼 8**：格序 012343210，runtime counts 适配无痛（six→five 帧 counts 改法见 §六）。
7. **CLI**：`--direct`（默认）/ `--legacy-256` 退旧重排路——256 重排降级为**拼格兜底**（原样直出某格烂到不可翻修时，从其他掷借格走 normalize_sheet 拼）。

### 验收与坏格处置

- 验收物（原样直出主路）：`<key>_attack_sheet_832.png` + `_attack_anim.gif`（8fps 125ms/帧），用户目验 GIF 拍板。
- 自动体检：空格数 / 高离散 σ（干净出图 σ<2）。
- 坏格≤1：跨掷拼格或单格重掷；坏格≥2：整表重掷。裁剪废（键控/切格坏）勿否决出图——调切除参数重切。

### 实测坑速查（2026-09-30 fut_nano_drone 全踩）

| 坑 | 对策 |
|---|---|
| agnes 色号不服从（要 #FF00FF 给玫红 ~(205,34,128)） | 键控永远自适应采样，不硬编码色号 |
| 5×2 网格导图被无视画成连环画 | 只用 3×2 + f0 铺格导图 |
| 16:9 出图带白外框骗过边框采样 | 背景色用全域众数 |
| 模型爱画贴地阴影/地面光斑 | prompt【无地面】硬性条款；锚定帧 tol=85 可连阴影吃掉 |
| 地面火光橙斑与机体连通，孤岛剔除无效 | prompt【无地面】条款根治（V3→V4 根除），勿靠后处理 |
