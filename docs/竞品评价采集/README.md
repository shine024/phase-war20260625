## 二、文件清单与数据字典

| 文件 | 说明 |
|---|---|
| `reviews_all.jsonl` | 合并去重后全量 1680 条 |
| `reviews_positive.jsonl` / `reviews_negative.jsonl` | 按 `voted_up` 划分的正/负面全集 |
| `raw/*.jsonl` | 7 款游戏的原始采集文件（每款一份） |
| `_stats.json` | 机器可读统计（分游戏 + 主题词频） |
| `_quotes_pos.txt` / `_quotes_neg.txt` | 正/负面按赞数 Top12 摘录 |
| `_analyze.ps1` | 一键复跑脚本（合并→划分→统计→摘录） |

每行 JSON 字段：`game, appid, id(recommendationid), lang, voted_up, hours(评论时游戏时长), votes_up, steam_purchase, date(UTC), review(≤500字符单行)`。**不含任何 steamid/昵称等个人信息。**

## 五、高赞摘录的故事线（定性重点）

**负面（赞数最高，见 `_quotes_neg.txt`）：**
1. **Melvor 前 4 条高赞差评全是同一件事**："单机放置游戏强制联网，服务器一挂存档就悬"（216/96/85/34 赞）——单机品类的离线可用性是生命线。
2. **AFK Journey**："p2w is p2w""中氪以下没有内容""无尽菜单"——F2P 商业化越线 = 信任崩塌 + 玩法空心化双重差评。
3. **背包乱斗 376h 老玩家**："怀疑强制 50% 胜率匹配，治疗 build 连续撞 3-4 个克制"——**老玩家对匹配/掉落公平性的疑云**是最毒的差评。
4. **Mechabellum**："随机指挥官彻底毁掉平衡与乐趣——我想玩我的体系，系统不让我玩"——RNG 介入构筑身份感的反例。
5. **Underlords**："2019 年度第一弃养游戏。好游戏，被完全遗忘"——停更判死刑。

**正面（见 `_quotes_pos.txt`）：**
1. Melvor："Runescape in Excel""把犯懒的日子按在电脑桌前"——放置正循环能改变生活。
2. AFK Journey："标题叫 AFK，但我根本 AFK 不了，内容多到停不下来"——放置≠无内容。
3. Mechabellum 14 赞中文长评（**好评里藏着最大警示**）："博弈性很好，但 150 小时才入门，新人不友好，玩家越来越少——现在要做的不是更新和平衡，是把人留住"。
4. Underlords 全部高赞好评都在"求复活"（#SaveDotaUnderlords）——品质能穿越时间，运营能杀死游戏。

## 六、分品类结论

- **放置品类**：差评核心 = 离线可用性/存档安全（技术信任），好评核心 = 正循环改变生活节奏。内容量不是问题（"停不下来"是赞）。
- **自走棋品类**：已验证"停更 = 死"。平衡差评低（玩家接受 meta 轮换），但**运营消失感**是压倒性负面。
- **构筑品类**：好评锚点是"流派成型那一刻"。杀戮尖塔 91.5% 好评率是品类天花板，其差评最少（17 条里平衡/重复命中 0）——**深度本身不产生差评，深度+公平感才产生口碑**。
- **PVP 自动战斗**：RNG 与匹配公平性是差评主源（随机指挥官、疑似 50% 胜率）；门槛劝退是长衰风险（Mechabellum 150h 入门）。

## 八、方法局限（引用数据时须知）

1. Steam appreviews 的 `query_summary` 总数与实际可翻页量严重不符；`filter=all` 实际只暴露**近期窗口**（本次约 2026-05~09）——样本偏向"近期活跃玩家"，历史差评（多随修复消失）代表性受限。
2. Steam 游标在语言池耗尽后循环返回同页（各游戏 78~174 条中文池即触发），中文占比（36%）是池子上限所致，非采样偏好。
3. 好评率 82.5% 是 7 款**成功游戏**的分布，不能当行业基准；反思时应看**差评主题的分布**而非好评率本身。
4. 关键词命中为"评论级"（一条最多计一次），类目间有语义重叠（平衡严/宽口径）；高赞摘录用于定性校准。
5. 复跑方式：`pwsh -File docs\竞品评价采集\_analyze.ps1`（幂等，重读 raw/ 全量重算）。
