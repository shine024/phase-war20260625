## 第 0 步：新图转正（当前唯一前置）

新图在 `docs/待生成卡图_r5试验机/ww2_air_me262_v8_tiger.jpeg`（JPEG）。
部署脚本只认 `ww2_air_me262.png`（PNG 白底）。转换（Python + PIL）：

```bash
cd "/d/godotplay/godot fair duel/phase-war"
python -c "
from PIL import Image
img = Image.open('docs/待生成卡图_r5试验机/ww2_air_me262_v8_tiger.jpeg').convert('RGB')
img.save('docs/待生成卡图_r5试验机/ww2_air_me262.png')
print('converted', img.size)
"
```

- 若新图不是白底（透明底/杂色底）：先在外部工具重存为**纯白底**再回来——部署管线
  靠"亮度≥240→透明"抠图，非白底会抠烂。
- 先目检一眼：机头朝**左**、无违禁符号（铁十字/十字形印/卐字/编号/国籍徽章，
  含暗淡的）、单机无残影。不合格回外部工具改，别往下跑。

## 第 4 步：运行时验证

```bash
"/d/Downloads/Godot/Godot_v4.5.1-stable_win64.exe" --headless --rendering-driver opengl3 --path . res://tests/_tmp_r5_content_boot.tscn 2>&1 | grep R5Content
```

预期最后一行 `[R5Content] ALL PASS`。关键断言：
- `ww2_air_me262 未解析到专属卡图`（PASS=解析到 `res://assets/card_icons/enemy/ww2_air_me262.png`）
- `卡图未入资源系统`（PASS=第 3 步导入生效）
- `脚部锚点缺失/异常`（PASS=锚点在 0.15-0.60 区间）
FAIL 时：看括号里实际值——"placeholder"=第 3 步没跑成；"不存在"=第 1 步没落盘。
