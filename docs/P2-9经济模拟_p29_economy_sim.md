## 模拟假设清单（按"代码真身照抄 → 简化近似"排列）

**直接照抄代码（无近似）**：
1. 波次数 `LevelEras.get_wave_total_for_level`（时代内线性：WW1 3-5 / WW2 4-7 / 冷战 5-8）。
2. 波次出怪 `get_spawn_count_for_wave_card_grid`（base∈[max(2,r0), min(9,max(r0+1,r1+1))] + 每 2 波 +1 上限 +2，钳 2-9）。
3. 波次构成 `LevelSpawnSequences._make_wave_spec`（elite=0.15+0.25×进度，精英波(w%3==0) +0.30，末波 boss=0.40+0.30×进度且 elite 减半；相位师关无末波 boss 倾向）。
4. 掉率乘区 `ERA_DROP_MULTIPLIER`：era0=0.70（v37 收口）/ era1=1.0 / era2=1.15；所有击杀掉率 chance×mult 后钳 ≤1（`roll_blueprint_drops` 同款）。
5. 通用缴获现行档 = `battle_damage_system.gd` v27.18 常量（normal 2% / elite 15% / 每场上限 2，boss 不参与，显式表非空的原型跳过）。

7. 击杀纳米 `roll_nano_materials_on_kill` 默认档（boss 18-38@1.0 / elite 5-12@0.88 / basic 2-7@0.42）。
8. 战后掉落表 `drop_tables.generate_drops`（保底纳米×lvl_mult、随机 1-3/1-4 抽、精材料=tier atk_pct、三星 era_N 卡、era2 保底合金）。

**简化近似（偏差已评估为次要，且两口径同受影响、档位间差值形状不变）**：
a. **胜利=全歼**：击杀数=全部出怪数。实战漏怪会等比压低所有击杀通道（含纳米）。
b. **缴获卡=时代池均匀**：真身按 combat_kind 过滤时代池（`get_random_card_for_era_kind`，空命中回退全池）——近似影响"图鉴偏科"分布，不影响总量。
c. **精英类型均匀混编**：显式表精英按种类占比摊入精英击杀；实际按波次 bias_tags 抽取。
d. **三星概率 0.5**；swarm 单位纳米档（1-2@0.24）、侦察碎片加成（×1.0-1.3）、挂机/黑门/势力/制造收入全部不计。

## 结论建议（由模拟数据生成，供 M4 参考；审美/节奏裁决归用户）

1. **通道本身值得保留（建议不开倒车）**：B1（现行档）相对 A 基线，L60 总卡 281 vs 174（+107 张 / +61%）、
   图鉴新卡 +8.6 种，场均缴获仅 0.59 张——v27.18 保守档的"低频惊喜"定位在数据上成立，
   材料流水零变化（表 2），没有货币通胀副作用。

2. **不建议直升高档（B3）**：通用通道占比升到 32%，副本:新卡比 5.66（现行 4.81）——击杀掉卡的主体验会从
   "图鉴发现"退化为"重复卡洪水"，与 v37"首关掉卡偏多"收口方向相逆。

3. **若 M4 要强化"击杀出真卡"感知**：优先升 B2（中档 5%/25%/场限 3）而非 B3——总卡 +12%、
   图鉴 +3.3 种，量级仍温和；同时考虑把 era0 的 drop_mult=0.70 与通用档解绑（0.70 同时压先例卡与纳米，
   若要保前期惊喜可单抬通用缴获不受 drop_mult 乘）。

4. **图鉴瓶颈不在掉率**：L60 战斗口径完成度天花板 = 67/131（51%）——时代 3/4 卡与势力卡
   本区间不可达；就算 B3 也只到 49%。真卡通道的边际收益在图鉴维度很小，拍板权重应放在"击杀反馈手感"
   而非"收集推进"。
