📋 总结与优先级

本轮已完成（代码改动）：
  • managers/audio_manager.gd SFX_NAMES 新增 5 个槽位：cancel / wave_start / boss_warn / master_appear / base_destroy
  • 新增 12 个事件订阅（仅接有真实 emit 的 SignalBus 信号）：波次/BOSS警告/相位师登场/基地摧毁/部署失败/能量不足/合成成功+失败/符文获得/势力升级/里程碑/相位场升级
  • 修复 _on_enhancement_completed 签名错配 bug（Dictionary→String）+ 延迟连接 CardEnhancementManager.enhancement_completed（原从未 connect，死代码）
  • 修复 cancel 音效被引用但未在 SFX_NAMES 定义（原回落 button）
🎯 补音频文件的优先级建议：
  1. P0 必补（合成音听感差、高频出现）：button / hit / win / lose / explosion / cast
  2. P0 必补（槽位已建但合成器没合成 = 当前静音）：cancel / wave_start / boss_warn / master_appear / base_destroy
  3. P1 推荐（武器辨识度）：12 个 gun_* / laser / rocket / missile / omega / rail 音效
  4. P1 推荐（BGM 基础设施）：新建 MusicPlayer + bgm_title + bgm_battle（至少一战/近未来 2 首）+ bgm_boss
  5. P2 锦上添花：其余养成音效定制、bgm 各时代分曲、bgm_hub
📌 音频规格（来自 assets/sfx/README.md）：格式 OGG（推荐）或 WAV；采样率 44.1kHz；比特率 128-192kbps；单声道即可。 BGM 建议 OGG（循环，立体声）。文件名严格对应 SFX_NAMES，放 res://assets/sfx/<name>.ogg，AudioManager 自动加载并替换合成音（无需改代码）。
