# 暗能与卡牌世界观（v2，2026-09-07 用户口述整理；v2 增 §八/§九，2026-09-17）

> 本文档是暗能/卡牌/迷失/符文体系的**设定真身**。开场叙事（`data/intro_comic_panels.gd`、
> `docs/开场文本.md`）与后续战斗系统（濒死爆发、精神值）从这里取源。

## 一、暗能与精神

1. **暗能入侵**：黑门降世，暗能量涌入世界 → 文明秩序迅速崩溃，人们绝望无助。
2. **暗能入侵精神**：暗能不只侵蚀物质，也侵入人的精神。
3. **精神支配暗能**：不屈的精神可以反过来**部分支配**入侵的暗能。
4. **暗能具现化**：被支配的暗能结合物质，形成实体——这是人类第一批反击力量。
   - 绝望时刻的希望："有人能来挽救"的执念，具现出与异族作战的实体。
   - 早期形态：胜利后暗能实体**正常消散**（用完即散，无法保留）。
   - 强烈精神所化的形状，被人们称作 **"生灵"**（对应开场 b4 格）。

## 二、卡牌的诞生（科技解析）

1. **发现**：结合科技，把"精神对暗能的驾驭方式"解析成式，可以**保留在特制卡牌上**。
2. **意义**：卡牌让力量第一次变得可携带、可复用、可传承。
3. **战斗用法**：相位战斗中，相位师向卡牌**注入精神与暗能**，以卡牌为核心，
   **快速具现能量化实体**（战斗卡实体）。
4. **相位仪**：腕上的相位仪是具现的"锚"（对应开场 b9 格）。
5. **卡牌的本质**：为更容易具现化战斗卡实体而创造的**载体**，不是力量本身——
   力量的源头始终是相位师的精神与暗能。

## 三、迷失

1. **根源**：精神与意志的力量是**有限的**。无限制地引入暗能、让精神与暗能
   无限制交互，**记忆与理智会逐渐消失**——这种状态称为 **"迷失"**。
2. **刚迷失时**：相位师对人类**还没有明显的攻击行为**——意志尚有惯性。
3. **深度迷失**：意志惯性耗尽后，彻底沦为战场上的敌人。
   （对应开场核心设定：**战场上交火的不是异族，是同批回溯、迷失在时代里的相位师同伴**。）
4. **与深航计划的关联**：传送途中暗能量撕碎车队，同伴们在乱流中被暗能浸透而迷失，
   散落在时代各处（对应开场 b10 格）。

## 四、濒死爆发（战斗机制，待实现）

- 战斗中相位师认定自己**必死**时，有人会**主动放开暗能限制**：
  - 提升具现的能量强度，具现出**更强大的战斗卡**，以期望给敌人更多伤害。
  - 代价是加速自身的迷失（精神被暗能反噬）。
- 定位：高风险高爆发的主动机制，与"迷失"体系联动。

## 五、符文

- 相位师的精神、意志与执念，因**长时间与暗能交互**，在相位师**死亡时有一定几率
  凝聚为符文**。
- **符文 = 相位师意志的表现与残留**。
- 与开场 b11 格"战胜迷失同伴、带着他们的力量继续前进"同源：
  被战胜的迷失者留下的力量残留，即是符文的叙事来源。

## 六、精神值系统（v36 部分实装：精神同调战力门）

- 相位师有一个**精神值**；精神值决定**能使用多少战力的卡牌**。
- **v36 补充设定（用户口述 2026-09-16）**：相位师越强大，精神与暗能量的交换就越深，
  在暗能量无限侵扰下**更容易失控和迷失**。因人类尚无法在穿越过程中更好地保护相位师，
  穿越而来的相位师中**中低位居多**。
- **强弱口径**：相位师强弱 = 精神力 × 运用暗能的效率与规模；更直观的表现是
  **能运用更强战力的战斗卡**（卡 power 值上限）。
- **实装载体（v36）**：相位师技能树「精神同调」链（三系各 开窍500/深潜1200/无垠2400，
  基础上限 200）——节点提升可运用战力上限，部署链消费（`PhaseMasterSkillManager.
  get_power_cap`，详见 AGENTS.md v36 节）。数值为占位，试玩数据回来后校准。
- 与基地侧 sanity（入口大厅 Lv3 → 上限 110）的关系待定（统一 or 双轨）。
- 来源：用户 2026-09-07 口述（精神值）+ 2026-09-16 口述（交换深度/迷失风险/中低位居多）。

## 八、迷失后的暗能泄露（空间泡）（用户口述 2026-09-17）

1. **失控即泄露**：迷失 = 精神对暗能的失控（§三）。失控的暗能量不会自行消散，
   而是持续从迷失者身上向外**泄露**——相位师越强，交换的暗能越深（§六），
   泄露的规模也越大。
2. **空间泡**：泄露的暗能量以迷失者为中心聚成**泡**状浸染域——像空间里鼓起的
   一个泡。暗能量被残存的精神惯性约束在泡内（§三.2：刚迷失时意志尚有惯性），
   所以泡有边界、不无限扩散，泡壁即是那层惯性。
3. **影响后的环境**：泡内的环境被暗能量浸染改变。**玩家与敌方卡的战斗、
   与敌方相位师的战斗，全部发生在这样的泡内**——没有"干净的"战场，
   每一关都是被暗能影响过后的环境。
   - 泡内的敌方卡与敌兵，是泡主（迷失者）仍在无意识"驾驶"的具现部队
     （§二.3：向卡牌注入精神与暗能以具现实体——迷失后这份驾驭变成了本能残留）。
   - 战斗环境四维（天气／地形／能量场／时段，v26.2 实装）读作泡内暗能影响的
     四个表现面——环境效果不再只是"关卡装饰"，而是泄露的暗能量作用于泡内
     世界的读数。
4. **泄露的记忆**：暗能量浸泡中，迷失者的记忆碎片从泡内析出、散落在战场上。
   这是外界"读到"迷失者的唯一途径——同伴档案里的事迹与遗言、四维情报的
   逐层揭示，叙事来源都是泡内析出的记忆。
   - 记忆泄露与迷失深度同向：泡越"老"、浸染越深，析出的记忆越接近迷失者
     本人生前最执着的片段（所以读到的是防线、是桥、是那四分钟——
     而不是流水账）。
5. **泡的消散**：战胜驻守的迷失者，泡失去源头而消散，环境恢复；其力量残留
   凝为符文（§五）——"带着他们的力量，继续前进"在物理上的完成时。
6. **玩家在泡内的安全**（钩子，暂不展开机制）：未迷失的相位师精神可控，
   短期在泡内作战无碍；长期滞留的风险与"迷失"同源（§三、§六），
   留作后续玩法潜力（如高渗度挑战、深层泡探索）。
7. **术语口径**：玩家可见文案写**"空间泡"**（三字）与**"泄露的记忆"**（五字，
   "泄露"不作"泄漏"）；设定文档内部"暗能"为"暗能量"简称（宪法三字全称口径
   不变）。空间泡与**黑门无关**——黑门是星冥族的裂隙（宪法「黑门」「裂隙」条），
   空间泡是迷失者的暗能量浸染域，两套概念不得混用。
