# 暗能与卡牌世界观（v1，2026-09-07 用户口述整理）

> 本文档是暗能/卡牌/迷失/符文体系的**设定真身**。开场叙事（`data/intro_comic_panels.gd`、
> `docs/开场文本.md`）与后续战斗系统（濒死爆发、精神值）从这里取源。

## 一、暗能与精神

1. **暗能入侵**：黑门降世，暗能量涌入世界 → 文明秩序迅速崩溃，人们绝望无助。
2. **暗能入侵精神**：暗能不只侵蚀物质，也侵入人的精神。
3. **精神支配暗能**：不屈的精神可以反过来**部分支配**入侵的暗能。
4. **暗能具现化**：被支配的暗能结合物质，形成实体——这是人类第一批反击力量。
   - 绝望时刻的希望："有人能来挽救"的执念，具现出与异族作战的实体。
   - 早期形态：胜利后暗能实体**正常消散**（用完即散，无法保留）。
   - 强烈精神所化的形状，被人们称作 **"生灵"**（对应开场 b4 格）。

## 二、卡牌的诞生（科技解析）

1. **发现**：结合科技，把"精神对暗能的驾驭方式"解析成式，可以**保留在特制卡牌上**。
2. **意义**：卡牌让力量第一次变得可携带、可复用、可传承。
3. **战斗用法**：相位战斗中，相位师向卡牌**注入精神与暗能**，以卡牌为核心，
   **快速具现能量化实体**（战斗卡实体）。
4. **相位仪**：腕上的相位仪是具现的"锚"（对应开场 b9 格）。
5. **卡牌的本质**：为更容易具现化战斗卡实体而创造的**载体**，不是力量本身——
   力量的源头始终是相位师的精神与暗能。

## 三、迷失

1. **根源**：精神与意志的力量是**有限的**。无限制地引入暗能、让精神与暗能
   无限制交互，**记忆与理智会逐渐消失**——这种状态称为 **"迷失"**。
2. **刚迷失时**：相位师对人类**还没有明显的攻击行为**——意志尚有惯性。
3. **深度迷失**：意志惯性耗尽后，彻底沦为战场上的敌人。
   （对应开场核心设定：**战场上交火的不是异族，是同批回溯、迷失在时代里的相位师同伴**。）
4. **与深航计划的关联**：传送途中暗能量撕碎车队，同伴们在乱流中被暗能浸透而迷失，
   散落在时代各处（对应开场 b10 格）。

## 四、濒死爆发（战斗机制，待实现）

- 战斗中相位师认定自己**必死**时，有人会**主动放开暗能限制**：
  - 提升具现的能量强度，具现出**更强大的战斗卡**，以期望给敌人更多伤害。
  - 代价是加速自身的迷失（精神被暗能反噬）。
- 定位：高风险高爆发的主动机制，与"迷失"体系联动。

## 五、符文

- 相位师的精神、意志与执念，因**长时间与暗能交互**，在相位师**死亡时有一定几率
  凝聚为符文**。
- **符文 = 相位师意志的表现与残留**。
- 与开场 b11 格"战胜迷失同伴、带着他们的力量继续前进"同源：
  被战胜的迷失者留下的力量残留，即是符文的叙事来源。
