**结论先行：222 个 sheet 型动画目录中 19 个为真孤儿（解析链五步全 miss，零运行期引用）。
甄别过程零站桩 bug——所有潜在归属卡均已直连命中自己的动画目录。
是否删除待用户裁决；删除前建议整体备份。**

## 判定方法（三轮探针，已入库可复跑）

1. **正向可达集** `tests/_tmp_orphan_dirs_probe.gd`：枚举运行期一切可能的 anim_id——
   **UCT 全卡 id ∪ EnemyUnitManifest.get_entries() 条目 ∪ EnemyCardModMap 全 archetype ∪
   manifest 六张 id 表 ∪ captured_ 变体 ∪ enemy_phase_platforms.json 平台 id**，
   逐个走 `UnitFrameAnim._resolve_key`，收集非空结果。
   两轮踩坑记录：①漏平台 id 会把 `ww1_storm`/`ww1_av7`/`vis_xeno_adept` 误判成孤儿
   （相位师平台直以平台 id 出生，不在 UCT/ECM）；②漏 get_entries 会把星冥 20 套误判。
2. **别名遮蔽甄别** `tests/_tmp_orphan_alias_check.gd`：12 个 ANIM_ALIAS 键实测落点。
   全部在前序步骤（ECM player_card_id / manifest visual_id）就命中别的目录，
   **无一空解析（无站桩），即 ANIM_ALIAS 表当前整体是死代码**，其目标目录成孤儿。
3. **归属解析** `tests/_tmp_orphan_owner_check.gd`：每个孤儿按词根在 UCT 搜潜在归属卡，
   实测归属卡解析落点。**全部命中各自已有目录或空表**——不存在"该接线没接线"的活 bug。
