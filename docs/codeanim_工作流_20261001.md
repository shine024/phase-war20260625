# codeanim 代码驱动动画工作流（2026-10-01 立项，独立路线）

> **边界声明**：本文件为独立路线文档，与 img25 生图重做清单（`docs/img25_重做清单_20260929.md`）
> **互不混写**。共享的只有两件事：阶段0 锚定帧（同一批 staging 产物）、键控/去粉工具函数
> （`import` 复用 `img25_attack_gen.py`，工具文件名带 img25_ 前缀仅因来源，路线归属以本文件为准）。
> img25 清单里的批次进度、执行标准、豁免决定**不约束**本路线；本路线的豁免与批次单独记录在本文件。

## 定位

- 锚定帧仍由生图出（保风格、保真身），**动作帧全部由确定性代码驱动**：
  三层 cutout + 参数时间表 + 逐帧渲染（2026-09-30 PoC 已验证，基线样张 guardian_ww2_blitzkrieg）。
- 对照知乎"代码视频"文的分工：生图模型出"照片"，代码当"动画师"，逐帧只取决于帧号。
- 三大实测卖点：
  1. **垂直注册问题在数学上不存在**——10 帧同源变换，底缘对齐是构造保证；
  2. **身份零漂移**——无生图参与动作帧，agnes 无法改写身份；同命令复跑逐字节一致（md5 已验）；
  3. **facing = 一行参数**（确定性 mirror）。
- 成本：动作帧零生图额度，换单位分钟级。

## 三条铁律（违者出表即废）

1. 渲染**不读真实时钟**——输入只有帧号；
2. 随机**只走固定种子**（SEED 常量，全帧按序消耗）；
3. 渲染**不联网**。

推论：同命令复跑必须逐字节一致——每个单位入批前跑两遍 md5 比对一次。

## v1 基线动画规范（blitzkrieg 实测值，换单位先沿用再调）

- 时间表：f0 怠速 → f1 全焰 → f2 中焰+后坐峰值 → f3 焰熄起烟 → f4–f7 烟飘散 → f8 残烟 → **f9 全清闭环**
- 参数：`RECOIL_BARREL=14` / `RECOIL_TURRET=4` / `HULL_BOB=3`（@1024）· `FLASH_LIFE=3` ·
  `SMOKE_N=6` 错峰寿命 `6.5-i*0.8` · `FPS=12` · `SEED=20260930`
- 层序：**车身→炮管→炮塔**——炮管后坐从炮塔层下方缩进，接缝藏于装甲后
- 坐标铁则：裁剪坐标=画布绝对坐标，合成回贴**不得再叠加切割偏移**（09-30 翻车点，已修）
- 烟闭环设计：错峰寿命保证 f8 基本散尽、f9 全清，循环回 f0 无跳变

## 已知边界（诚实账）

- 切割线是手调常数：换单位需重调 + LAYERS 目检；自动轮廓探测**挂起未做**；
- 烟偏暗偏实：黑底可读但发闷，浅色游戏背景下待复验，参数集中在 `draw_smoke`；
- cutout 机械感：后坐线性回落无弹簧过冲、车身 bob 仅 3px，要生命感需加缓动曲线（挂起）；
- 多形态动作（非开火类）未设计；
- **键控补刀铁则（2026-10-01 首批实测新增）**：封闭玫红区补刀必须在 `depink` **之前**——
  depink 先把亮粉转灰，转灰后按背景色距离就抓不到了（lance 腿间灰块实测）；
  补刀只删近背景色，近白不碰（防误删白色高光，BFS 已兜格间白带）；
- **开火轴向铁则（2026-10-01 用户实检"没抬枪就开火"后立）**：火光锥/烟/后坐必须沿
  **实测炮管轴线**——`flash_angle`（PIL rotate 角，负=上仰）与 `muzzle`（炮口面中心）
  用 `_probe_*.png` 网格量角图实测后入配置，禁止凭感觉填；首修四案：
  omega 炮管俯角 30°、lance 枪刃仰角 29°（muzzle 同时纠偏 50px）、thunder 管束仰角 11°
  （muzzle 原扎进管束 100px）、arm_omega 肩炮 muzzle 纠偏 25px。
  即 img25 §十"没抬枪先抬枪再开火"在本路线的对应口径：**武器姿态来自锚定帧（不动），
  开火方向必须顺武器轴线**；真"举枪预动作"（肢体旋转）仍属生图主路适用域（见适用判定 ❌）；
- 锚定原生粉边残留：fut_nano_drone 炮管下缘过渡带（<2px@256 实机）无法按颜色安全剔除，接受；
- 贴地阴影：lance/howitzer/thunder 锚定自带落地投影（深色端 dist≥100 键控吃不到），全帧同源不闪，
  按"角色阴影"保留——若定稿要求无地面投影，需锚定帧阶段0解决，非本路线工序；
- **锚定自带玫红地面阴影/粉边（10-01 二批确认）**：hummer/ps9/bomber/rpg 等锚定带饱和玫红
  椭圆阴影与描边粉边，键控/去粉后仍存——**img25 主路部署版同款**（同锚定同源），非本路线引入；
  全局去留属美术定稿问题，待用户拍板（代码侧可加"阴影去饱和"一步，未做防两路外观分叉）；
- 投弹弹道方向（10-01 实测纠错）：屏幕系里机身随镜头锁定，弹体相对机体只能**向后飘**
  （阻力滞后）——左向机弹尾向右；前漂=物理穿帮。弹体朝向顺速度向（弹头朝下略偏后）。
  **（10-01 深夜拍板推翻：`bomb_forward:true` 可前漂，mod_air_bomber/ww2_air_bomber 已用）**
