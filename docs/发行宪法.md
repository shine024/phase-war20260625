# 发行宪法（2026-09-19 起，红线条文化）

> **来源**：`docs/竞品反思修订计划_2026-09-19.md` T0.4。依据 1680 条 Steam 竞品评论的教训提炼，
> 是本项目对外的**行为承诺**，也是内部开发的裁决基准。任何与本文冲突的功能设计/文案/运营动作，
> 默认违宪，须先修订本文再执行。
> 引用方式：后续批次 PR / 设计文档直接引条款号（C1~C4）。

## C1 商业化红线

**条款**：付费（若未来引入）只买便利与外观，绝不碰内容可及性；禁止暗箱匹配/掉落调控。

**为什么**：AFK Journey "p2w is p2w""中氪以下没有内容"——F2P 商业化越线 = 信任崩塌 +
玩法空心化双重差评；背包乱斗 376h 老玩家"疑似强制 50% 胜率"——**老玩家对匹配/掉落
公平性的疑云是最毒的差评**（负面词频：商业化 7.1%，且集中于免费游戏）。

**现状**：全项目零 IAP / 零广告 SDK（天然安全）。黑门软门是能量块（游戏内资源）购加次，
不涉真实货币；未来引入任何付费前必须先过本条。

**裁决问题**：这个改动是否让"不付费的玩家玩不到内容"？是否暗中调整了概率？任一为是 → 违宪。

## C2 纯离线承诺

**条款**：核心玩法 100% 离线可玩，存档本地为主；任何联网特性（云存档/统计上报）必须是
增量而非依赖——断网时游戏完整可玩、存档不悬空。

**为什么**：Melvor Idle 前 4 条高赞差评全是同一件事："单机放置游戏强制联网，服务器一挂
存档就悬"（216/96/85/34 赞）——单机品类的离线可用性是生命线，挂了就是差评集群。

**裁决问题**：这个功能断网后表现如何？答案不是"优雅降级"而是"完全不可用" → 违宪或重新设计。

## C3 概率透明承诺

**条款**：一切概率/保底口径玩家可见、可验证（P1 批落地：制造 pity 进度、黑门规则、
相位师遭遇规则三处上 UI）。**文案数值一律从常量/代码读取，禁止在 UI 硬编码**——改常量
文案自动跟随，保证"可见的"与"实际的"永不脱节。

**为什么**：RNG 是竞品负面第一大类（8.8%）；Mechabellum"随机指挥官毁掉构筑身份感"
说明玩家反感的不是随机本身，而是**不可预期的随机**。本作的 pity/驻守制/递增保底
已经是"可预期化"设计，缺的只是让玩家看见。

**裁决问题**：这个随机机制，玩家能不能在受影响之前算出或查到它的规则？不能 → 违宪。

## C4 更新承诺与 tag 纪律

**条款**：
1. 对外沟通的版本路线图任一时刻 ≥3 个版本（内容方向即可，不做日期承诺；草案见
   `docs/roadmap_对外草案.md`）。
2. 版本号 tag 纪律：每个对外发版（试玩包/EA/正式）必须在 main 分支打 `vX.Y.Z` 格式
   annotated tag，与 CHANGELOG 顶条版本号一致；分支开发期间允许无 tag，合并回 main
   发版时必打。
3. 竞品证据：Underlords"2019 年度第一弃养游戏"——品质能穿越时间，**停更 = 死刑**；
   其全部高赞好评都在"求复活"。

**裁决问题**：这次发版打 tag 了吗？当前对外可见的路线图还剩几个版本没兑现？
