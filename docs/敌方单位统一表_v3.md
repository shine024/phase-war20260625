# 敌方单位统一表 v3.0

**日期**: 2026-07-03
**状态**: 草案，待审核命名与数值后进入代码实施
**目标**: 把 A/B/C/D/E 五段（110 单位）合并为一套统一的敌方卡数据，关卡/任务/boss 只做引用；我方卡 = 敌方图水平翻转

---

## 一、命名规则（统一三段式）

```
<era>_<role>_<specific>[_tier]
```

| 字段 | 取值 | 说明 |
|---|---|---|
| **era** | `ww1` / `ww2` / `cold` / `mod` / `fut` | 时代 |
| **role** | `inf` / `arm` / `arty` / `sup` / `air` / `fort` / `boss` | 战斗定位（步兵/装甲/火炮/支援/空军/堡垒/BOSS）|
| **specific** | 型号代号 | 小写下划线，取真实名或音译 |
| **tier**（可选）| `_e` / 无 | 仅用于区分同名：`_e` = elite 精英强化版 |

### 同名区分原则（用户决策：保留两者，区分定位）
- **A 段（平台卡）= 波次常驻基础型**：用真实型号，无后缀。例 `ww2_arm_tiger`（虎式坦克）
- **C 段 enemy_/elite_ = 任务专属**：基础型与 A 段同名时加 `_e`。例 `ww2_arm_panther_e`（黑豹，精英强化）
- **C 段 boss_ = BOSS**：用 `boss` role。例 `ww2_boss_kingtiger`
- **D 段 foe_pool = 补充单位**：用真实名替换 pool_NNN。例 `cold_inf_metis`（原 foe_pool_013）

## 二、三维攻防口径（用户决策：统一为三维）

### 攻击三维展开规则
C 段原数据是单值 `attack_damage`，按 `weapon_type` 分配到三维：

| weapon_type | 武器 | attack_light | attack_armor | attack_air |
|---|---|---|---|---|
| 0 冲锋枪/SMG | 轻火力 | 60% | 25% | 15% |
| 1 步枪/RIFLE | 中口径 | 50% | 35% | 15% |
| 2 机枪/MG | 持续火力 | 45% | 30% | 25% |
| 3 火箭/ROCKET | 爆破 | 30% | 50% | 20% |
| 6 狙狙/SNIPER | 精确 | 55% | 30% | 15% |
| 8 激光/LASER | 能量 | 40% | 40% | 20% |
| 9 导弹/MISSILE | 制导 | 20% | 40% | 40% |
| 10 米加/OMEGA | 终极 | 100/100/100 三维等分 | | |

### 防御三维推算规则
C 段原数据防御=0，按 tags 推算（与 `compute_defense_from_config` 公式同源）：

| 单位类型 | defense_light | defense_armor | defense_air |
|---|---|---|---|
| 步兵 inf | 3-5 | 2-3 | 1-2 |
| 装甲 arm/tank | 10-15 | 14-20 | 8-12 |
| 火炮/阵地 arty/turret | 11-14 | 9-11 | 9-11 |
| 空军 air | 4-6 | 3-5 | 3-5 |
| 精英 elite | +3 全维度 | | |
| boss | +6 全维度 | | |

> 实际数值取 `round(atk*0.45 + hp*0.015)` + tag 修正，clamp [3,40]，与现有公式一致。

// 改前
"equipment": { "platforms": ["steel_fortress_basic", "steel_titan_basic"] }
