## 一、剧情衔接：为什么是"星冥族"

第 100 关的胜利并没有结束战争——它只是证明了相位技术足以正面对抗"彼岸"。玩家在碎片中打赢的每一战，都被彼岸的观察者记录在案。当碎片之潮耗尽、空间重合进入最终阶段，真正的对手浮出水面。

它们来自与地球重合的**彼岸空间**：那个宇宙的恒星早已全部熄灭，只剩暗能量潮汐。文明在永夜里靠**灵能**（精神直接支配能量与物质）和**结晶科技**存活了千万年，视"渡过永夜"为最高使命——自称「**渡者**」。

人类从深空观测影像里发现：它们的所有航路都指向同一个坐标——**大西洋上空那道贯穿天穹的黑色裂口**。裂口后方是一片**星光尽灭的星域**。人类为这道门与门后的文明命名：**黑门 / 星冥族（The Eclipse）**。

**战争伦理钩子**（为后续剧情留口）：星冥族内部分两派——
- 「**渡暮派**」：推动完全重合，人类作为原住物种必须清场（黑门敌军主体）；
- 「**守誓派**」：主张停止重合、寻找两个空间共栖的方法（暗影执刃、拟态者等渗透单位其实是守誓派的侦察/接触尝试——打你，但也在给你递情报）。

## 三、三个新机制（星冥战场识别度）

> 数值均为草案，最终以 balance-check 审查为准。

### 1. 灵能护盾 Shield
- 所有星冥单位拥有独立于 HP 的**护盾层**（约 HP 的 25%~40%）；**5 秒未受击后以 10%/秒快速回复**，HP 不回复。
- 玩家解法：VOID 法则族对护盾伤害 +50%；新增通用改造词条「灵能穿透」（需 bump 改造总数锁 202）。
- 引擎映射：`stats` 新增 `shield / shield_regen` 通道（伤害先扣盾再扣血），复用 DOT/拦截的既有伤害入口。

### 2. 折跃 Warp
- 星冥单位不走"部署虚影等待"，而是**折跃入场**：波次开始前 2 秒在目标格显示**折跃信标**（蓝色撕裂特效），随后单位直接成型。
- 给玩家的反应窗口 = 原部署时间 × 0.5（快，但可预判、可用法则预瞄）。
- 晶工探测器能展开"晶塔信标"作为额外折跃锚点——**优先打晶塔**就能压制出兵节奏（软性战术目标）。

### 3. 共感网络 The Communion
- 星冥单位彼此构成**心灵光环网**（复用 aura 通道）：同网络的相邻星冥单位互 +8% 攻击、互加速护盾回复。
- 击杀"网络节点"单位（晶塔/哨兵浮棱/母舰）会瘫痪局部网络 5 秒——**斩首 > 磨血**的打法差异。

## 五、无限模式「裂隙防线」

### 5.1 入口与战场美术（已定案：黑门 / 星空 / 晶脉浮陆）

**入口节点「黑门」**：
- 解锁条件：通关第 100 关（LevelProgressManager 判定）。
- 大地图第 100 关节点之后浮现**黑门节点**——一座竖立的黑色巨门环（黑曜石门框、门心是缓缓旋转的星空漩涡、门缘嵌青金晶脉光）。点击 → 战前摘要（本场裂隙环境/首波预览）→ 进入战斗。
- 大地图在黑门解锁后，其周边区域配色渐变为深空调。

**星空战场**（背景星空，脚下「晶脉浮陆」）：
- **背景**：深空星野（近黑蓝，基准色 ≈ `#0A0E1C`）+ 低亮度青紫星云 + 远处彼岸舰队剪影与黑门残环，视差两层。
- **脚下（晶脉浮陆）**：被黑门引力撕离地表的一块**战场浮陆**——灰蓝岩体，裂纹中嵌**青金晶髓发光脉络**；部署格线由晶脉勾出（敌我分色沿用现有网格渲染）；浮陆四缘破碎悬空，露出下方星海。
- **可读性红线**：沿用 v26.9 三件套（深色描边 + 全单位投影 + 背景压暗 BG_DIM 兼容）；**单位本体与背景亮度差 ≥ 90**（沙漠融底事故的 30~60 为反面基准）；晶脉高亮只出现在格线与非战斗区，不与单位争抢亮度。
- **交付管线**：1280×720 背景 1 张走 level bg 生成管线（`docs/ART_PIPELINE_LEVEL_BG_GENERATION.md`）；晶脉自发光与格线由 battlefield.gd 现有网格/染色层**运行期叠加**，不烧死在背景图里（保证时代 tint 与 BG_DIM 兼容）。

### 5.2 单场结构

- **无限波次守相位场驱动器**：驱动器被毁 = 本轮结束，即结算。没有"通关"，只有纪录。
- 每 **5 波**出一个精英（B 段），每 **10 波**一个 Boss（D 段三首领轮换 + 渡师强化变体），波间 7 秒（沿用近未来节奏）。
- 敌方同时在场**上限 9 格封顶**（不突破 3×3 敌阵格数——渗度提升的是出兵密度、档位概率与轮换速度，不是格子数）。
- 我方规则与 100 关一致：能量、法则、相位仪全解锁，单位上限照旧。

### 5.3 渗度（Depth）与数值成长

- 每 10 波渗度 +1。四档位（新兵/老兵/精英/传奇）随波次推进逐步上移，51 波后恒传奇。
- 成长公式（草案）：
  ```
  enemy_hp  = base_hp  × tier_mult × (1 + 0.05 × wave)
  enemy_atk = base_atk × tier_mult × (1 + 0.05 × wave)
  boss 波额外 ×1.15；tier_mult 沿用 1.20 / 1.30 / 1.46 / 1.66
  ```
- era 定位：`era = 5`（星域带），基准 = 近未来档 × 1.35。

### 5.4 计分与排行榜

- `score = 波次 × 100 + 击杀数 × 2 + 总伤害 / 1000`（草案）。
- 直接提交现有 **survival_highscore**（挑战类，周重置）与 `survival_best` 玩家统计——排行榜系统零改动。

### 5.5 裂隙环境（复用 battle_environments 四维）

每场随机 1 条：

| 环境 | 效果（敌我对称） |
|---|---|
| 灵能风暴 | 间接伤害 +15% |
| 低重力带 | 直射伤害 +10% |
| 裂隙潮汐 | 回能每 10s 在 ±30% 间摆动 |
| 晶髓矿脉 | 击杀回能 +2 |

## 六、星冥缴获卡：全游戏唯一「只可掉落」系（已定案）

> 现行规则（v26.8/v26.10）：新卡获取唯一通道 = 制造，图纸为库存消耗品。星冥卡是这条规则的**唯一例外**——只能从黑门刷出来，制造中心对它全程关闭。这让"下黑门"成为不可替代的玩法动机。

### 6.1 获取：只可掉落

- 击杀掉落率沿用现表：基础 8% / 精英 22% / 首领 55%。
- **品质滚动复用缴获品质管线**（`ManufacturePools.apply_captured_quality`，4 获取点同链）：普通 55 / 精良 25 / 稀有 12 / 史诗 6 / 传说 2。
- **渗度品质加成**（草案）：渗度每 +1，高品质权重上移、普通递减（线性，渗度 5 封顶）：
  ```
  渗度0: 普通55 / 精良25 / 稀有12 / 史诗6 / 传说2   （= 现行基准）
  渗度5: 普通40 / 精良22 / 稀有17 / 史诗14 / 传说7
  ```
- 神话品质对星冥卡**不可达**（保持"神话 = 制造专属"的现行铁律；星冥卡不能制造，故顶格为传说）。

### 6.2 养成三通道（全部挂现成管线）

| 通道 | 规则 | 复用系统 |
|---|---|---|
| **可升级** | 强化等级与普通卡同链同币（纳米），无特殊化 | CardEnhancementManager |
| **可刷词条** | 星冥卡有**专属词条池**（星冥科技系：护盾协同/折跃稳定/灵能穿透协同等）；单条重随 / 批量重随 / 锁定计费**全部复用现表数值（500~10000 档），仅计费币种由纳米换成星髓** | AffixManager（reroll / batch_reroll / 锁定），v19 兵种分池机制天然支持新池 |
| **重复卡出口** | 重复星冥卡可喂**分析仪**烧情报（按品质 +8~30%，档案室 Lv2 门禁照旧）——drop-only 卡的唯一回收出口 | v26.8 批次3 分析仪链 |

### 6.3 排除规则（防止绕过 drop-only）

- 制造中心配方目录**不收录**星冥卡；仓库每日战利品打印池**排除**星冥卡；气象站地表探索**不出**星冥卡。
- 掉落即唯一入账通道：黑门击杀掉落 → 背包缴获卡，同品质滚动链。

## 七、货币「星髓」（第 5 种资源，已定案）

- 获取：按渗度里程碑发放（10/20/30/50…波），**每周获取封顶**（呼应 `design/gdd/game-pillars.md`「NOT Infinite Grind」——无限模式定位是**评分挑战**，不是无限刷资源）。
- 用途（三件）：
  1. **星冥卡词条洗练**（§6.2 的重随/批量/锁定计费币种）；
