# VFX v18：命中贴图标定 + 轻武器减层 + 审计工具修正

> 2026-08-19 · 三轮单变量迭代（遵循 vfx-tuning 五步铁律）· 基线 v17 = 4.2/10（48 格）

## 病根（像素级实锤，非猜测）

1. **命中贴图层整体超尺寸 8-18 倍**
   `weapon_impact_*.png` 画布实为 **1536×1024**（内容宽 1062-1410px），而代码按
   `REF_TEX_PX = 512` 假设基准再 ×2 显示（0.26-0.51×2）→ 实渲染 550-1300px，
   比 64px 参考单位大 8-18 倍。与 v17"注释 32px 实为 128px"同型病根第三次复发。
2. **按名查表的 hash 贴图全部缺失**
   `weapons_realistic/{hash}_impact.png` 实存仅 1 张（weapon_artillery_impact），
   其余全部回落 FALLBACK(857px 内容) 再乘 0.9-1.0 → ~800px 巨爆。
3. **v10 真实度层压垮轻武器命中**
   flash(115px 贴图×2.4-4.4=276-506px) + 烟团(160-288px) + 破片(64-141px)
   + v17k 第二慢环(r50) 无条件叠加 → 轻武器命中亮核 119px，读成"小火球"。
4. **轻武器枪口糊团**
   26 粒 × 12-26px × 0.14s × 48° 锥相互重叠，单发读成橙色糊团。

## 第 4 轮后剩余病根定位（像素+AI 交叉）

1. **火箭/导弹枪口火读成"径向爆散"**：像素证实方向正确（R% 94/8，锥角 24°），
   病根是 FLAME_STAR 贴图本身是 8 臂放射星形——每颗粒子自带放射形态，
   排在锥里也读成"四散火花"。需换方向性贴图（texture 级改动，需用户确认）。
2. **导弹/火箭弹道"弹体被烟吞没"**：拖尾烟雾膨胀失控，弹体不可见。
3. **爆炸命中缺碎片层**：AI 判决 5 次提"缺碎片/破片层次"——v12 报告早有参数级建议
   （金属碎屑 15-20 个、2-5px、300-600px/s、重力下坠）。
