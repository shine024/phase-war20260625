## 0. 评级口径（先读，后看四方向）

**换血成本评级**（衡量"选此方向后，存量资产要花多少动作才能归队"）：

| 档 | 定义 | 大致动作量 |
|----|------|-----------|
| **S** | 保留为主：≥80% 资产走批量调色/后处理即合规，重生成 ≤20% | 一轮 LUT + 少量补图 |
| **M** | 半换血：全量统一调色 + 30%~50% 重生成 | 调色管线 + 2~4 批生图 |
| **L** | 大换血：>50% 重生成或全量 img2img 风格化重绘 | 全量重跑生图管线（含脚锚/翻转/备份全流程） |

**五维评估**：①卡图适配度 ②场景资产适配度（漫画/雪原/基地/背景）③深航叙事契合 ④与霓虹 UI 的关系 ⑤AI 生图管线可控性。

**全方向共用管线约束**（四方向全部 prompt 串一律遵守，批次④照此执行）：
- 卡图串 backdrop 统一写 `clean pure white background with NO ground`——实测管线是白底生成 + `flood_white_to_alpha` 转透明（`generate_missing_card_icons_11.py` 既有口径），黑底/深底/studio backdrop 字样不进立绘串。
- 负面词栏只写结构性排除：`text / perspective view / frame`（agnes 实测：负面概念词反激活，写"不要 X"反而把 X 画进画面）。
- player/ 侧生成后跑 FLIP_LEFT_RIGHT 镜像翻转——重生图构图必须可翻转：画面内禁止文字、字母、带字旗帜/徽标、单侧不对称符号（翻转即穿帮）；`text` 结构性排除同时服务于此。

## 方向 A：军事写实 · 硬核纪实（参考：《战争游戏红龙》/《Close Combat》卡面风）

### 参考游戏与画面关键词
《Wargame: Red Dragon》单位卡（实物照片混排+冷灰排印）、《Close Combat》兵种卡、《Steel Division》营卡。可直接进 agnes/Flow prompt 的关键词串：

```
military unit identification catalog plate, NATO field-manual reference illustration,
precise scale documentation drawing, historically accurate equipment detail,
clean pure white background with NO ground, museum specimen documentation
```

历史单位补 era 词（`WWI / WWII / Cold War / modern day / near-future`），禁止写 `gritty / dusty / battle-worn`（agnes 实测：风格词自带场景暗示，会把破败垃圾带进画面，见 `tools/_agnes_image_api.md` 第 3 条）。

### 色调方向
- 主色：低饱和军橄榄绿（Munsell 约 10Y 4/2）、灰卡其、冷灰钢色；整体饱和度压到 20%~35%。
- 明度：中低明度主体；现有卡图为透明底抠图精灵、游戏内叠深底呈现（"黑底"只是查看器预览），与本档低明度天然衔接。
- 点缀色：仅允许锈褐（铁锈氧化色）与烟熏黑两种"时间痕迹色"，面积 ≤10%。
- 全图色温偏中性微冷；禁止暖黄主导（现状 ww1 步兵的卡其黄需调色压冷）。

### 光线规则
- 单一均匀顶光/前顶光（图鉴式标本光），无侧逆光、无色光。
- 暗部保留细节（暗部不低于 15% 亮度），无死黑投影；主体受光面/背光面明度差 ≤2 档。
- 脚部保留现有白色椭圆投影锚（`generate_card_foot_anchors.py` 管线产物，规则不变）。
- 禁止：霓虹 rim light、体积光、戏剧伦勃朗光。

### 笔触/媒介
- 细腻写实数字厚涂（detailed realistic digital matte painting），无轮廓描边。
- 允许轻微做旧颗粒（subtle film grain, fine granular metal texture）——现状 `vis_player_001` 坦克的"版画刻线+点状肌理"即此档，可作为本方向的**现有合规样板**。
- 禁止：赛璐璐勾边（现状 ww1 步兵）、卡通粗描边（现状 fut_swarm）。

### 与现有资产适配度
- **卡图（356 张）**：写实厚涂无描边类（坦克/载具/动力甲，抽样约占 55%~65%）→ 统一调色（压饱和+中性冷）即归队；勾边/卡通类（抽样约占 35%~45%，集中于步兵与球形舰/卡通载具）→ 需重生成。粗估：**调色归队 55-65% / 重生成 35-45%**。
- **徽章/阵营标/相位仪**：纹章风与"图鉴档案"气质同族 → **全保留**。
- **序章漫画**：版画排线手绘感与档案风可共存 → **保留**。
- **雪原醒来/卡车基地图**：卡通手绘描边 → **需重生成**（约 6-8 张）。
- **战场背景**：写实摄影感沙漠 → 压暗+去暖调色即可，**保留**。

### 换血成本评级：**M**
理由：卡图主体同族但存在三档质感漂移，需一轮全量统一调色 + 约 35-45% 卡图重生成 + 场景演出图重生；生图管线本身可控性高（写实军事图鉴是 agnes 现有产出舒适区，大量存量即证明），无技术风险，纯粹是量。

## 方向 B：末世工业 · 荒芜史诗（参考：《冰汽时代》UI+插画混融风）

### 参考游戏与画面关键词
《Frostpunk》概念插画（冷灰蓝雪原+暖橙炉火）与铜版蒸汽 UI、《This War of Mine》炭笔渲染、《FTL》宏大叙事插画。可直接进 prompt 的关键词串：

```
vast empty snowfields under a flat overcast sky, monumental lone industrial structure,
single warm ember light source in a cold blue-grey world, oil-stained steel machinery,
thick painterly illustration, film grain texture, one tiny human silhouette
against huge machinery to carry the epic scale
```

（`wasteland / desolate / bleak` 等废墟字面词不进串——agnes 风格词自带场景暗示，会把瓦砾垃圾画进画面；荒芜与史诗感改由空旷构图、人物与机械的比例差、单一暖光源来表达。）

雪原场景锁意象词：`wind-carved snow fields, flat overcast sky, distant colossal black monolith with faint violet halo`（用正面意象锁死"空旷干净"，不写 `no trash`——agnes 负面词反激活）。

卡图立绘串（512 透明底管线；卡图占资产量约 96%，是本方向主战场）：
```
single military unit or vehicle, full body, historically accurate equipment detail,
clean pure white background with NO ground, overcast diffused lighting,
one narrow cool sky-blue rim light along the back edge, thick painterly rendering,
subtle film grain, muted cold palette with one small warm accent
```
（立绘串禁用 `heavy atmospheric haze / volumetric fog`——体积雾会毁掉透明底剪影边缘；氛围雾只出现在上面的场景串。）

### 色调方向
- 主色：深灰蓝（#2B3A4A 一档）与冷灰（对齐 UI 的 `COLOR_BG` 深空黑 #0A121F 色系，卡图背景自然沉入 UI 底色）。
- 对撞点缀：暖橙琥珀（炉火/车灯/油灯，对齐 UI `COLOR_ENERGY` #E69919 / `COLOR_AMBER` #F59E0B）+ 黑门紫晕（对齐 `COLOR_ACCENT_PURPLE` #8C59F5）。
- 饱和度中低（25%~40%），唯暖光源与紫晕允许高饱和小面积。
- 一图一冷暖对撞，暖色总面积 ≤15%（现状序章漫画 b6 已是此结构：暖橙火光 × 冷紫门光）。

### 光线规则
- 基调：阴天漫射顶光（overcast diffused light），无硬直射阴影。
- 每图恰好一个"叙事光源"：炉火/车灯/黑门晕/屏幕辉光，自带体积光雾（volumetric glow around the light source）。
- 大气透视强制：远景沉入灰蓝雾（aerial perspective, distant objects fade into blue-grey haze）。
- 卡图立绘：透明底精灵叠深底呈现（生图走白底管线，见 §0），主体漫射光，允许轮廓处一道极窄冷天光 rim（现有 ww1 步兵的青蓝轮廓光即雏形，可收编为规则）。

### 笔触/媒介
- 厚重数字厚涂（thick painterly digital illustration）+ 全图统一噪点颗粒（film grain overlay）。
- 烟雾用柔边喷枪（soft airbrush smoke），金属用硬边刮擦（hard-edge scuffed steel）——软硬对撞。
- 禁止：干净赛璐璐、卡通粗描边、矢量平涂。
- 注意措辞陷阱：写 `oil-stained steel` 可以，写 `dusty / grimy / gritty` 会被 agnes 激活成垃圾满地。

### 与现有资产适配度
- **序章漫画（11 格）**：已是本方向（版画排线+冷暖对撞+颗粒）→ **零换血保留**。
- **雪原醒来演出**：灰蓝雪原+紫门+橙车灯，结构与色相全对位；但笔触是卡通粗描边，按与 C 相同的判据——描边调色调不出 → **待 img2img 风格化小样验证**（保构图换笔触的低成本路径，成败以小样定）。
- **卡图（356 张）**：写实厚涂类调色归队（压冷+颗粒叠加，可批量 LUT）；勾边/卡通类重生成。粗估：**调色救 55-60% / 重生成 40-45%**。
- **卡车基地三图管线（5 时代 × 3 图）**：现图卡通描边+幽默感 → **需重生成**（管线已就绪，v3 prompt 骨架可直接换风格词）。
- **徽章/UI**：深底青线纹章与"冷灰蓝+暖橙"共存无冲突 → **全保留**。
- **战场背景**：写实沙漠压冷+加雾调色即归队 → **保留**。

### 换血成本评级：**M**
理由：叙事类资产三段式归队（漫画零换血 / 雪原 img2img 小样低成本过渡 / 基地房间三图管线就绪只需换风格词）是最大红利，但卡图仍需全量调色 + 四成重生成，动作量与方向 A 同档。可控性中上：氛围词有 agnes 措辞陷阱，但已有三轮实测经验（`tools/_agnes_image_api.md`）可规避，序章漫画（FLOW 管线）已证明该风格可稳定产出。

## 方向 C：油画历史战争（参考：军事历史油画质感）

### 参考游戏与画面关键词
博物馆战争画（《马里博罗公爵战役》Meissonier 式细节油画、《无畏舰》时代海军油画）、删减版参考：《Total War: Empire》加载屏油画、《CoH》开场 CG 静帧。可直接进 prompt 的关键词串：

```
grand historical war oil painting, museum canvas, visible impasto brushstrokes,
aged varnish amber glaze, dramatic single light source, romantic 19th century
military painting composition, canvas weave texture
```

### 色调方向
- 整体罩"老清漆"暖褐滤镜（aged varnish tone）：深褐 #3E2F23、拿浦黄 #A67B5B、铁锈红 #8C3B2E、铅白高光。
- 明度整体压暗，高光只出现在光源与金属反光处；饱和度低（20%~30%）但色相偏暖。
- 与 UI 的冷底（#0A121F 深空黑+霓虹青）呈**暖冷对撞**——油画卡放进霓虹 UI 如"射灯下的博物馆展柜"，是四方向中与现状 UI 关系最紧张的一个。

### 光线规则
- 伦勃朗式单侧强光（single strong side light from upper left），投影长且深（long deep shadows）。
- 明暗对比强烈（chiaroscuro），暗部面积 ≥40%。
- 天光：暖金色黄昏光或火光，禁止冷白日光与霓虹色光。

### 笔触/媒介
- 可见厚涂笔触（visible impasto, bristle brush marks）+ 画布织纹（canvas weave）。
- 边缘软（soft painterly edges），无数字锐边、无描边。
- **管线风险点**：512 透明底立绘要求干净剪影边缘，油画软毛边与抠图/脚部锚点扫描（`generate_card_foot_anchors.py` 按脚部连通域扫描）直接冲突——透明底管线要为此改造或改走白底+`flood_white_to_alpha`（白底与暖褐油画也冲突）。agnes 对"油画笔触+透明底"的稳定产出是四方向中最低的。

### 与现有资产适配度
- **卡图（356 张）**：现有全部为数字硬边插画，与本方向**不同族**，基本无法调色救（调不出笔触）→ **重生成/全量 img2img 重绘 ≈ 100%**。
- **序章漫画**：版画感尚可共存但色温相反 → **需重生成或整体罩染调色（实验性）**。
- **徽章/UI**：扁平矢量纹章 vs 油画 → 关系割裂，UI 不可能改（DesignTokens 刚收敛），只能接受"卡画是油画、UI 是霓虹"的双层结构 → 徽章保留但**整体违和**。
- **战场背景**：油画天空/沙丘可重生成替换。

### 换血成本评级：**L**
理由：唯一一个卡图接近全量重绘的方向；且透明底管线与油画毛边结构性冲突，需先改造工具链再谈产出；agnes 稳定产出油画+军事细节的废品率风险最高。买得起"博物馆史诗"，但买的是四方向里最贵的一张门票。

## 方向 D：科幻霓虹强化（参考：现有 DT 霓虹 UI 全 compatible，卡图向赛博军事）

### 参考游戏与画面关键词
《EW: Homeworld》舷窗构图、《StarCraft II》人族载具卡、《Cyberpunk 2077》武器插绘（军规侧）。可直接进 prompt 的关键词串：

```
cyber-military hard-surface concept art, clean pure white background with NO ground, cyan rim lighting,
glowing energy lines on armor panels, holographic HUD accents,
sleek angular panel lines, airbrushed glow, crisp digital edges
```

历史时代单位的处理分两轨：装备类可科幻化改型重生；一/二战写实单位**不做内容科幻化**，只做统一"相位辉光"后处理（见下）。

### 色调方向
- 主色：深空黑呈现底（透明底精灵叠 #0A121F UI 底，直接对齐 `COLOR_BG`；生图仍走白底管线，见 §0）+ 中低饱和金属灰主体。
- 发光点缀：霓虹青（#00F0FF，对齐 `COLOR_ACCENT_CYAN`）为恒定主 rim 色；霓虹紫（#8C59F5）专属黑门/相位异常语义。
- 规则：发光只出现在"能量/相位/信息"要素上（能量管线、屏幕、相位仪、特效），装甲本体不发光——保住卡与卡的识别度（全发光=全一样）。

### 光线规则
- 双光源恒定：主光冷白前顶光 + 青色 rim light 勾背光侧轮廓（现状 ww1 步兵/040 电弧步兵已自带此结构）。
- 暗部近黑但不糊（保留 10%~15% 亮度细节）。
- 自发光体带辉光（glow, bloom）——与 UI 的 `GLOW_ENABLED/GLOW_BLUR=8` 同语言。

### 笔触/媒介
- 硬边数字概念图（hard-surface concept art）：锐利面板线、喷枪渐变光、无描边无画布纹。
- 现状科幻系卡（fe/fut/drop 抽样：战列舰、球舰、轨道炮动力甲）**已是此风格**——本方向的现有合规样板。
- 历史单位轨：不重生成的，走批量后处理（LUT 压冷 + 边缘检测加青 rim glow，可写 Python/PIL 或 Godot shader 一轮跑完）。

### 与现有资产适配度
- **徽章/阵营标/UI**：原生同构 → **零换血**。
- **科幻系卡图**（fe 14 + fut 15 + drop 4 + vis_xeno 异形系约 20 ≈ 53 张/阵营，占 30%）：已是本风格 → **原生保留**。
- **写实历史卡图**（ww1/ww2/cold/mod 26 张 + vis 写实系 ≈ 125 ×2 阵营，占 70%；vis 不全属写实——约 20 张 vis_xeno 已归上栏）：后处理轨（压冷+青 rim）可救 **70%~80%**，仅构图/姿态不合格者重生成（估 ≤20%）。
- **序章漫画/雪原/基地图**：暖色手绘叙事画与霓虹冷硬风**不同族** → 若选 D 需重生成叙事图，或接受"叙事=手绘、战斗=霓虹"双层结构（现状拼凑感的残留）。
- **战场背景**：压暗沙漠+青雾调色可半归队 → **调色保留**。

### 换血成本评级：**S~M**（纯后处理路线 S；科幻化重生成路线 M）
数字口径：原生 30% + 后处理救 50%~56% = 免重生成约 80%±2%，恰跨 S 档 80% 门槛——是否站稳 S 取决于 vis_xeno 归档数与后处理小样成功率，故记 S~M 而非 S。
理由：唯一能把主成本压在"程序化后处理"上的方向——调色与 rim glow 均可脚本批量完成（`tools/` 已有批量处理惯例），重生成集中在叙事类资产与少数卡图。选 S 路线的代价是叙事资产违和保留；选 M 路线则要重画全部漫画/演出图。**agnes 可控性四方向最高**（科幻概念图是生成模型舒适区）。

### 推荐：**方向 B（末世工业·荒芜史诗）为主锚，缝合方向 D 的 rim-light 恒定规则**

理由：

1. **叙事低成本对位**。深航计划的三个母题——雪原、黑门、车队孤灯——就是方向 B 的构图公式本身（冷灰蓝世界 + 一点暖光 + 紫晕）。叙事资产三段式归队：序章 11 格漫画零换血、雪原醒来演出走 img2img 小样低成本过渡、基地房间三图管线就绪只需换风格词重跑；后续找回同伴/时代 boss 的演出图有现成风格模板可复制。
2. **与既有 UI 是缝合而非妥协**。B 的"深灰蓝底"沉入 DesignTokens 深空黑，暖橙灯火对齐 AMBER/ENERGY token，黑门紫晕对齐 PURPLE token——UI 不用动一行代码，卡图与 UI 从"两张皮"变成同一色环。同时把 D 的"青色 rim light 恒定规则"收编为 B 的卡图立绘细则：现状卡图本就普遍带青蓝轮廓光，这道 rim 就是内容层与 UI 层之间的缝合线。
3. **成本可控且风险已探明**。M 档成本与 A 相同，但 A 买到的只是"档案库"气质（时代识别度最好、戏剧张力最弱），B 买到的是游戏的第一情绪。agnes 氛围词陷阱（gritty/dusty 反激活）已有三轮实测规避手册，FLOW 管线产出过整套序章漫画——两个管线的可行性都有存量证据。
4. **淘汰理由存档**：C 是气质上最动人的方向，但它与霓虹 UI 暖冷对撞、与透明底管线结构冲突、卡图全量重绘，三个否决点各自都够致命。D 分两路线看：M 科幻化路线会抹平历史系卡（26 单阵营/52 双阵营）的时代识别度——时代差是本游戏卡牌系统的核心信息，不能为统一感牺牲信息量；S 后处理路线保得住时代感，否决点在叙事层——序章漫画/雪原/基地图与霓虹冷硬风不同族，要么全量重画（成本回到 M 档），要么接受"叙事=手绘、战斗=霓虹"的双层割裂，那正是本次手术要治的拼凑感残留。若用户对 B 的"颗粒厚重"不感冒，A 是退守选项（差异主要在情绪与叙事资产换血量，管线动作相同）。
