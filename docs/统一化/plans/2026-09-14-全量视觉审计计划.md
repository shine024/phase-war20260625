## 二、方法（视觉模型分片审查）

1. **编排**：workflow 脚本把 242 张切成 **21 片 × ~12 张**，并行派发给视觉子代理；每片一个代理，逐张 `read_image` 读原图（512/1024px）。
2. **Rubric**（判档六维，浓缩自 STYLE_BIBLE 第二/三/七章 + 分档表 §10 已裁决口径）：
   - **rim**：按判定链核颜色档位（①写实装备→冰天青 ②fe/fut/drop→霓虹青 ③vis_xeno→黑门紫）+ 落位 + 辉光度 → ok / missing / wrong_color / overglow
   - **写实度**：1-5；**≥4 = C 存疑**（照片感禁则）
   - **笔触**：厚涂可见=合规；平滑渲染/照片质感=flag
   - **构图**：单主体/朝向（player 朝右·enemy 朝左）/占比>90%/多主体/裁切
   - **标记**：水印、文字、字符、签名、白底污染、接地阴影残渍
   - **暖源语义**：按 §10 裁决口径——涂装/呢料/木铜/肤色/火光=语义合规；无源暖光泛洪=flag
3. **输出**：每片返回结构化 JSON（id/六维/档位/一句话）；主代理聚合。
4. **复核**：C 存疑 + 档位异常项由**主代理亲自放大重读**（裁角/局部 zoom）二次确认，剔除视觉模型误判。

## 三、边界与风险（如实声明）

- **AI 初筛 ≠ 人工终审**：分档表标注"视觉模型判档"；C 存疑与 A/B 边界件建议人工抽验（检查点呈样张）。
- **分辨率限制**：水印/小字在 512px 原图上可能不可辨 → 标记维度存疑的一律进放大复核队列。
- **本计划 0 改图**：产出=分档与清单；任何处置（重生成/LUT/收紧）另立检查点裁决，不动 pixels。
- 一致性校准：片与片之间判档尺度可能漂移 → 主代理聚合时按 §10/§1 已判样例（me262=A-、patriot=B 等）对齐锚点。
