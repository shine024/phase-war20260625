## 4. 配方级问题(2026-09-10 核查诊断,下一轮重生成前必读)

1. **同 prompt 批量出图=配方趋同**:42/55/58 三张逐字同词、22/38 两张逐字同词。同 prompt 多次生成只差随机噪声,近似同图——与审计「按时代差异化出图解决配方趋同」的目标相悖。**改法**:同时代多关卡给差异化变量(地形/主力构筑物/时刻/天气强度轮换)。
2. **负面词混进正面 prompt**:API payload 无 negative 字段,`text, frame` 以句号拼接在 prompt 尾部——对无独立 negative 通道的模型等于正面描述,可能反而诱导画字/画框。**改法**:接 API 的 negative/extra_body 通道,或从拼装里删掉。
3. **snow 词串叙事污染**:COLD+snow 修饰串绑死 `distant colossal black monolith with faint violet halo`——黑门+紫晕是无尽模式门图专属意象,被带进 42/55/58 普通雪城关卡背景,叙事穿帮。**改法**:普通关雪词串去掉 monolith;monolith 仅保留在 gate 图配方。
4. **重复词稀释权重**:`flat overcast sky` 最多 4 次、`diffuse daylight` 2 次——拼装器无去重。**改法**:拼装后按短语去重。
5. 环境参数来源:`battle_environments.gd` ENV_BY_LEVEL(68 显式)与 `_default_env_for_era`(其余走时代默认)——若关卡设计实际环境与默认不符,重生成前先核 ENV_BY_LEVEL。

单位侧补充诊断:
6. **卡图/徽章负面词同样混正面**:`text, perspective view, frame, ground, ceiling`(卡图)与「text, frame」(徽章)均句号拼进正面 prompt 尾——与背景同病(§4-2)。中文负面「无文字无水印无logo」在锚段内属内嵌语义,问题不大;英文尾拼必改。
7. **过程 prompt 未存档**:garand_para 卡图四轮迭代配方全失,复刻只能 vision 反推——**教训:生成脚本 JOBS 是唯一真源,临时改配方必须回写脚本再跑**。
8. **朝向口径差**:卡图宪法 facing right(player 直出),动画模板全「指向画面左侧」——卡图与动画精灵朝向相反,战斗内同屏混用时注意视觉一致性(待游戏内人审确认是否违和)。
