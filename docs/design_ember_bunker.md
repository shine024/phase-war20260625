# 余烬要塞（EMBER BUNKER）· 设计文档 v1.0

> 2026-08-25 定稿。Phase War 基地/主枢纽系统——融合《这是我的战争》侧视横剖面 + 《幽浮2》避难所建设。
> 决策记录：侧视横剖面视角 / 轻美术（程序化底子+AI贴图后补）/ 抽象光点主角 / 无 NPC。

## 一、定调汇总

| 决策项 | 结论 |
|--------|------|
| 视角 | **侧视横剖面**（娃娃屋式，楼层垂直向下，单屏 1280×720 无滚动） |
| 美术档位 | **轻美术**：P1 全程序化色块跑通 → P1.5 AI 生成 ~20 张贴图逐张替换 |
| 主角呈现 | **抽象光点**（12px 青白圆点+呼吸柔光），无角色精灵 |
| NPC | **无**。羁绊对象 = 牺牲英雄的记忆档案（30 位敌方相位师） |
| 核心情感 | 黑暗基地一间间点亮；纪念墙为 30 位逝者一盏盏亮灯 |

## 三、房间系统（14 房间 × 状态机）

```
[❌废弃] ─付资源+耗时→ [🔧修复中] ─按战斗场次推进→ [✅可用] ─付资源→ [📈升级]（P2+）
```

- 修复耗时以"场"计：每完成一场战斗推进 1/N，不打仗进度停滞 → "出击↔回家"节奏
- **反应堆 = 深层电力开关**：上层房间靠基地备用电池供电可正常修复；深层设施
  （通讯室/荣誉室，`needs_power` 标记）在反应堆未上线时修复进度冻结。
  （P1 实测修正：原"冻结所有房间"会让玩家第一间修复永远卡死——除非先攒够
  反应堆的合金500+能量200，违背"首个大目标"的引导意图）
- 观星台 = 终局（全房间✅ + 通关 100 关 + 集齐 30 英雄碎片，P4）

## 四、光点主角（无精灵）

- 12px 青白圆点 + 呼吸柔光（Tween 循环）
- 精神值联动：<50 光圈缩小；<30 变暗偏紫+掉落-10%；=0 强制回宿舍睡觉
- **发呆机制**：停留 5 秒无操作 → 底部浮现阶段化内心独白（纯文字淡入淡出）

## 五、日循环（回合制）+ 精神值

```
睡觉→新一天（基地调亮）→出击（N场自由，每场精神-10/败-20）
→回基地（修复进度+场次推进）→夜晚（渐暗）：修房/读档案→睡觉→日结算→存档
```

- 日夜仅氛围（全屏 ColorRect modulate Tween），无实时压力
- 天数驱动情感四阶段：1-15 麻木 / 16-40 投入 / 41-70 羁绊 / 71+ 选择

## 六、英雄档案与纪念墙（P3，叙事核心）

- 数据源：`data/enemy_phase_masters*.gd` 30 位 master（姓名/势力/时代现成）
- 击败驻守（20 关 100%）+ 遭遇（15%）相位师 → 掉遗物碎片 → 档案室解锁
  （姓名/势力/时代/生前事迹一句/遗言一句——30 组文案先写 10 位）
- 荣誉室纪念墙 3×10 灯阵，解锁一位亮一盏（青→金渐亮动画）
- 集齐 30 = 观星台解锁条件之一

## 七、入口流程与集成

```
标题屏 ──"进入基地"──→ bunker_main.tscn（新主枢纽）
                           │ 兵棋室"前往战场"（Engine meta: launch_from_bunker）
                           ▼
                       main.tscn（战斗，链路零改动）
                           │ 顶栏"返回"（检测 meta → 回基地并清除）
                           ▼
                       bunker_main.tscn
```

- P1 双入口并存：标题"新游戏/继续"→ main.tscn 原样；main 底部功能栏原样
- `GameManager.go_to_battle` 链路零改动；场景切换由 bunker/title 直接 change_scene
- BunkerManager 挂 ManagerLazyLoader（`ensure_loaded("bunker")`，非 autoload），
  监听 `SignalBus.battle_ended` 全局推进修复进度/扣精神值
- SignalBus +3 信号：`bunker_room_state_changed(room_id, new_state)` /
  `bunker_day_ended(day)` / `hero_archive_unlocked(master_id)`
- 存档（P2）：`bunker_state` 段 {day/sanity/rooms/hero_fragments/narrative_stage}，
  schema v8→v9，全字段默认值兜底
- **验收铁律：基地→开战 ≤2 次点击**

## 十、风险与对策

| 风险 | 对策 |
|------|------|
| 基地"挡路" | 兵棋室一键直达，开战永远 ≤2 点击 |
| 经济冲突 | 修复成本锚定日均纳米收入（~200-400），首期偏低可调 |
| 旧档兼容 | bunker_state 缺失 = 新基地初始态（P2 接存档时） |
| 文案量 | 先 10 位英雄，逐步补齐 |
