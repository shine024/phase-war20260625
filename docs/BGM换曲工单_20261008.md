## 换曲方案（两案，按优先级）

### 案 A：hub 按时代轮换（#7，推荐先做）

大地图/基地进音乐时按 `GameConstants.get_era_for_level(GameManager.current_level)` 选曲，映射：

```
era0 (lv1-20)   → hub_ww1    （新键）
era1 (lv21-40)  → hub_ww2
era2 (lv41-60)  → hub_cold
era3 (lv61-80)  → hub_modern
era4 (lv81-100) → hub_future
```

**曲源建议**：incompetech Kevin MacLeod 库（授权链现成——CC BY 4.0，署名由 credits 页承载），选 5 首"时代氛围但低紧张度"曲（对应战斗曲的同时代 calm 面）。候选方向：
- ww1：悲怆弦乐低张力段（如 Impact Largo 类）
- ww2：军鼓行进慢板（Five Armies 的 calm 面或 Take the Lead 类）
- cold：悬疑电子稀疏版（Crypto 之外的长音垫类）
- modern：Rock Hybrid 低强度层
- future：氛围合成 pad（非 loop 游戏感）

**工序**（全链在 `assets/sfx/CREDITS.md` 文末有流水线文档）：
1. 下载 → `tools/bgm_swap_from_manifest.py`（响度归一 -14 LUFS + 溯源元数据）
2. 登记 CREDITS.md 台账 + `_steam_assets/licenses/incompetech_*` 快照
3. ⚠️ **铁律：ogg 不入 git，动音频前外部备份**（本机 `D:/godotplay/_art_backup/`）
4. `--headless --editor --quit-after 3000` 导入
5. 代码接线：BGM_MAP 加 5 键 + `world_map.gd` / `truck_base.gd` 两处 `play_music("hub")` 调用点改 `AudioManager.music_key_for_current_era()`（新增小函数，音效文件缺失回退 "hub"）

### 案 B：battle_future 换曲（#9）

Space Fighter Loop 与全曲库风格断层。两个方向二选一：
- **换曲**：从 incompetech 选悲怆/紧张管弦（与 ww1-ww4 档同语言），如 Rite of Passage / Clash Defiant 类；
- **保曲换档**：若用户喜欢轻快 futuristic，把它挪到 hub_future（案 A 落地后近未来基地用），战斗 future 档换重曲。

**注意**：dream_battle（开场梦战）硬编码 `play_music("battle_future")`（`scenes/intro/dream_battle.gd:77`）——换曲后需复听开场演出效果。
