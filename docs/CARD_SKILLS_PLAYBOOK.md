## 一、系统机制（必读）

卡片定时技能 = **全队大招**。解锁技能树节点后，只要场上派出对应兵种的战斗卡，每固定秒数自动触发一次，无需手动操作。

```
解锁技能树节点（card_skill）
        ↓
场上存在带对应 source_tag 的友军单位（≥1 个）
        ↓
引擎每 0.5s 扫描计时，达 interval 秒触发
        ↓
大招生效 + 屏幕提示（Toast）
```

- **触发单位是战斗卡，不是基地**。基地节点（phase_field_driver）不参与卡片技能。
- **提示**：终极技（红色大字 + 震屏）；普通技（金色轻量提示）。
- **势力加成**：激活对应势力（nova_arms / aether_dynamics / frontier_union / void_research）后，**所有单位**自动带对应家族 tag，无需特定兵种也能触发。

## 六、注意事项

1. **大招需要先解锁技能树节点**——「概念武器」分支 tier 6-13，需相位场 XP 攒技能点逐级解锁。
2. **同场触发多人共享**——多张同类单位在场，该技能仍按各自 CD 触发，不叠加计数。
3. **激活势力可免兵种限制**——不想凑兵种就激活对应势力，所有单位自动带家族 tag。
4. **普通技提示为金色轻量 Toast**，终极技为红色大字 + 震屏。
