# 基地模式新档开场剧情 · 10 个方案

> 适用范围：基地模式（bunker）新建存档时的开场演出，主角醒来落在地下房间。
> 所有方案共用同一套剧情节拍（见 §0），差别只在**呈现形式**与成本。
> 工程约束：Godot 4.5 / 2D / 1280x720 / gl_compatibility；基地已有 `intro_shown` 存档标记模式可复用（新档播一次，续档跳过）。

---

## 0. 统一剧情节拍表（所有方案共用）

| # | 节拍 | 内容 |
|---|------|------|
| B1 | 失眠 | 主角连续几天头痛失眠，反复做**同一个梦** |
| B2 | 入侵之梦 | 梦中：异空间异族文明入侵，一个又一个文明被毁灭 |
| B3 | 未来的自己 | 某天梦中出现未来的自己："我给你一个**获得保护自己能力**的机会" |
| B4 | 为什么被入侵 | 暗物质扭曲空间；两个空间重合时，**最终只会剩下一个** |
| B5 | 力量的来源 | 地球进入暗能量活跃星域，**精神已经可以支配能量** |
| B6 | 为什么是卡牌 | 对现阶段普通人最合适的形式：**以卡牌保存精神与能量的具现化** |
| B7 | 真相 | 未来主角的意识来自**已毁灭的另一条时间线**；那条时间线保存下了部分空间碎片，引导临近空间的同族来这里提前获得力量 |
| B8 | 醒来 | 主角醒来，身处地下房间 → 无缝进入基地玩法 |

> 任何方案都必须完整覆盖 B1–B8；开场结束的**落点永远是地下房间**，与基地模式第一天的引导衔接。

## 方案 1｜分格漫画动画（Motion Comic）★你点名的形式

**概念**：黑屏上漫画分格逐格"砸"出来（带音效与轻微震动），每格配 Ken-Burns 式缓推缓拉 + 一两行旁白字幕。像动态连环画，而非逐帧动画。

**节拍铺法**：
- B1：1 格——主角在床上辗转，闹钟连闪 3 天日期；
- B2：3 格快切——天空撕裂/虫影/城市崩塌（可用现有战斗场景截图加滤镜改造成"漫画格"）；
- B3：2 格——梦中另一个"自己"伸手，格线故意画歪制造不安；
- B4–B7：3 格"设定格"——把暗物质/空间重叠/卡牌具现画成示意图风格（类似说明书插画，成本极低）；
- B8：最后 1 格被"撕开"→ 实际画面浮现 → 转入地下房间。

- **时长**：60–90 秒
- **成本**：美术 ★★☆（6–10 张分格图，其中设定格可用简笔示意）；程序 ★☆☆（TextureRect + Tween 即可）；音频 ★☆☆
- **优点**：表现力/成本比最高；分格节奏天然适合"噩梦反复"的压迫感；跳过、断点都好做
- **缺点**：分格画风与游戏写实卡面若差异大会违和，需统一滤镜/描线
- **落地**：`scenes/intro/comic_intro.tscn`，一格一个 TextureRect，Tween 控制 scale/position + 音效；结尾切 `bunker_main`

## 方案 2｜文字冒险式（VN 静态插画 + 打字机文本）

**概念**：全屏背景插画（4–5 张）+ 底部文本框打字机式输出旁白，"未来的自己"以半透明立绘/纯声音形式与主角对话。Slay the Spire、传统 galgame 开场路数。

**节拍铺法**：B1–B2 用一张"噩梦"插画垫底；B3–B7 全部在"梦中对话"里完成——这正好是设定信息量最大的部分，VN 形式最不怕台词多；B8 黑屏一行字"……你醒了。"→ 进基地。

- **时长**：2–3 分钟（可点击加速）
- **成本**：美术 ★☆☆（4–5 张背景，可先复用 `assets/backgrounds/` 改色）；程序 ★☆☆（一个对话框组件即可）；音频 ★☆☆
- **优点**：全场最便宜、最快出成品；设定讲解（B4–B7）最从容；文案改动零成本
- **缺点**：演出感最弱，像"读设定集"；对不看文字的玩家不友好
- **落地**：`story_dialog_panel`（补剧情.txt 里本就标注"需新建"），做完还能被全游戏后续剧情复用——**这一项本身就是基础设施投资**

## 方案 3｜预渲染视频 CG

**概念**：开场做成一段真正的视频（AE/Blender/AI 生成分镜再剪辑），游戏内全屏播放，播完进基地。标题画面之后、按键"开始新游戏"之后触发。

**节拍铺法**：按 B1–B8 顺序剪辑；B2 的文明毁灭是全片视觉高潮（大场面正是视频相对实时的优势）；B7 用"时间线碎裂成玻璃碎片"的意象收束。

- **时长**：90–120 秒
- **成本**：美术 ★★★★（外部制作）；程序 ★☆☆（一个 VideoStreamPlayer）
- **优点**：观感天花板；可顺便当商店页/宣传素材一材多用
- **缺点**：本项目中成本最高；改动文案=重新渲染；**Godot 4 原生只支持 Ogg Theora（.ogv）**，mp4/webm 需 ffmpeg 转码；玩家几乎必跳过，性价比低
- **落地**：`assets/video/intro.ogv` + `scenes/intro/video_intro.tscn`；注意 720p 码率与体积控制

## 方案 4｜剪影/皮影风格动画

**概念**：全片只用**黑色剪影 + 单色渐变背景 + 粒子**讲故事：失眠的床是剪影，入侵的虫群是黑色潮水，两个文明的重叠是两团色块互相吞噬。GRIS / 地狱边境式的抽象高级感。

**节拍铺法**：B2 异族入侵与 B4 空间重叠是这个形式的主场——"两个空间只剩一个"画成两团剪影互相吞并，一笔讲清核心设定；B6 卡牌具现化是唯一亮色：黑画面里浮出发光的卡牌轮廓；B8 剪影逐点亮起颜色 → 醒来。

- **时长**：90 秒
- **成本**：美术 ★★☆（剪影比写实画面省 5–10 倍工时）；程序 ★★☆（需要一批 Tween 动画与粒子）；音频 ★★☆（氛围音重要）
- **优点**：美术成本与高级感的最佳平衡；"梦"的非真实感与剪影天然契合；风格不易与卡面冲突（本来就是梦）
- **缺点**：信息传递偏氛围、弱细节，B5–B7 的设定仍需字幕补足；调不好会显得空
- **落地**：纯 Node2D + Polygon2D/Shader，`scenes/intro/silhouette_intro.tscn`

## 方案 5｜档案/新闻蒙太奇（Documentary Dossier）

**概念**：不从主角视角，而以"世界正在发生什么"的档案拼贴开场：电视新闻截图、天文台警报、卫星云图上标出的"暗能量活跃星域"、盖着"机密"红章的政府密档……最后一个镜头切到主角的病历单：**连续失眠 7 天**。Frostpunk/SCP 式冷开场。

**节拍铺法**：B1 主角病历+就医记录；B2 各国"集体噩梦"社会新闻（梦境入侵被处理成都市传说）；B4–B5 泄露的天体物理学家访谈与密档（讲暗物质/空间重叠）；B6 一份实验记录："意识耦合具现化——卡片化方案通过验证"；B7 一页被撕掉一半的档案，落款是未来日期；B8 画面从档案桌拉黑 → 床头闹钟响 → 醒来。

- **时长**：90–120 秒
- **成本**：美术 ★★☆（文档模板+截图拼贴，无角色美术）；程序 ★☆☆；音频 ★☆☆（新闻播报腔配音加分极大）
- **优点**：设定硬信息（B4/B5/B6）讲得最自然——本来就该是"文献"；世界观可信度最高；文案为主，迭代便宜
- **缺点**：情感代入弱（前 80 秒主角只是纸面上的名字）；需要中文文案质量高
- **落地**：一组全屏"纸张"TextureRect + 翻页/盖章音效 + glitch Shader

## 方案 6｜单幅长卷运镜（One-Shot Pan）

**概念**：委托/绘制**一张超宽插画**（约 3840x720 或上下分段），镜头从左到右一次性连续平移，旁白贯穿全程：星空暗能量星云 → 银河悬臂上的地球 → 城市上空撕开的空间裂缝 → 崩塌的街景 → 地面之下的地下房间剖面。一个镜头讲完一个宇宙。

**节拍铺法**：画面顺序即 B5→B4→B2→B1→B8（倒叙式：先给宇宙尺度的原因，再落到主角床头）；B3/B6/B7 由旁白在对应画面处补齐。

- **时长**：60–75 秒
- **成本**：美术 ★★★（一张大图，但只需一张，且可拆成背景复用）；程序 ★☆☆（就是 Tween 一个 x 坐标）；音频 ★☆☆
- **优点**：完成后是全项目最"电影化"的一段；那张长图可裁切复用为标题画面/章节转场背景
- **缺点**：前期全押在一张图上，图不合格则整体返工；静态画面 60 秒对美术细节量要求高
- **落地**：大图按 1280 宽分段加载防内存峰值；`scenes/intro/pan_intro.tscn`

## 方案 7｜卡牌发牌叙事（Card Deal）★最贴游戏主题

**概念**：黑暗中，一只手（未来的自己）隔着桌面给你**发牌**。玩家逐张点击翻牌——每张牌的牌面就是一段记忆或一条设定（插画+短文案，直接用游戏现成的卡牌框架/边框），翻完 7 张，最后一张翻开后整张桌面向下坠去——你从床上坐起。

**节拍铺法**：正好 7 张对应 B1–B7：
1. 【失眠】2.【入侵】3.【邀约·未来的自己】4.【空间重叠】5.【暗能量星域】6.【卡牌具现化】7.【毁灭的时间线】——第 7 张是金色闪卡，翻开的瞬间牌桌崩塌 → B8 醒来。

- **时长**：40–60 秒（玩家自控节奏）
- **成本**：美术 ★★☆（7 张牌面插画，可直接用缩略风格的设定图）；程序 ★★☆（复用现有卡牌 UI 组件，翻牌 Tween）
- **优点**：**开场即教学**——玩家在剧情里学会的第一件事就是"翻卡牌"，与核心玩法同构；B6"卡牌保存精神与能量"的设定由形式本身演示，不用嘴说；自带轻交互，跳过率天然低
- **缺点**：单张牌面信息容量小，B4/B7 的复杂设定只能精炼成一句话；7 张插画的风格统一要求高
- **落地**：复用卡牌渲染组件 + `scenes/intro/card_intro.tscn`；发牌手可用剪影，省一份立绘

## 方案 8｜交互式梦境碎片（Interactive Dream）

**概念**：玩家醒着"漂浮"在一片黑色梦境空间，四周漂浮着若干发光碎片/气泡。点击碎片 → 触发一小段画面+旁白（B2 的入侵、B4 的设定、B7 的真相…），集齐关键碎片后梦境中心亮起"未来的自己"的剪影，说完 B3 的邀约，梦境碎裂，醒来。

**节拍铺法**：自由碎片（可点可不点）：各国灾难幻象、文明毁灭群像；关键碎片（必点，共 4 枚）：B4/B5/B6/B7 四条设定；最终碎片：B3 邀约 → B8。

- **时长**：60–120 秒（取决于玩家）
- **成本**：美术 ★★☆（碎片小图 6–9 张）；程序 ★★☆（点击/收集/解锁逻辑，工作量主要在程序）
- **优点**：开场就有"玩"的感觉，代入感与完成度平衡最好；设定分成小口，不淹人；跳过逻辑内建（点完即走）
- **缺点**：三个形式里程序工作量最大；做不好引导玩家会迷路；碎片小图的美术量容易被低估
- **落地**：`scenes/intro/dream_intro.tscn`，碎片=Area2D + Tween 浮动，收集状态机

## 方案 9｜实机无缝开场（In-Engine Wake-Up）★性价比之王

**概念**：不做独立动画。新档直接从**基地地下房间的实际场景**开始：玩家躺在床/地板上，视角即游戏视角。屏幕上以"闪回"形式断续插入梦境残影（B2 的虫影扫过天花板、B4 的空间重叠一闪而过），未来自己的台词作为画外音随操作出现；玩家按提示起身、环视房间，最后一段旁白点出 B7 真相，引导顺手打开第一张卡——开场结束，游戏已经开始。

**节拍铺法**：B1 用"房间细节"讲（墙上的服药记录、7 天的泡面盒）；B2/B4 短闪回插在起身过程中；B3/B5/B6/B7 全部画外音+字幕；B8 是起点不是终点（反结构：别的方案是"醒来收尾"，这个是"醒来开场"）。

- **时长**：60–90 秒
- **成本**：美术 ★☆☆（全部复用基地现有场景资产）；程序 ★★☆（闪回转场+画外音触发器）
- **优点**：零场景切换、零新资产场景；开场与第一天引导无缝焊死，最不会让人跳过；后续每次加剧情节拍都便宜
- **缺点**：B2 文明毁灭的"大场面"表现力受限于实机画面，史诗感最弱；依赖基地房间场景本身的完成度
- **落地**：`bunker_main` 新增 `intro_state` 分支 + 全屏闪回 ColorRect/Shader 转场；与现有 `intro_shown` 标记同一套机制

## 方案 10｜可玩序章（Playable Prologue）★冲击力之王

**概念**：开场就是一段被剧本完全控制的短玩法。玩家操纵主角**在梦中**经历一次注定失败的战斗：异虫压境、文明崩塌（复用现有战斗系统 + 预置必败配置），绝望之际未来的声音响起，递来第一张卡——用这张卡完成一次爽快的反转击杀（教学战）——画面碎裂，惊醒于地下房间。补剧情.txt 序章"最后的梦境"就是这条路线。

**节拍铺法**：B1 被压缩成开战前 10 秒的画外音；B2 即战斗本体；B3 未来的声音在残血时刻触发；B4–B7 教学战过程中的字幕卡逐条弹出；B8 战胜后白屏 → 醒来。

- **时长**：3–5 分钟
- **成本**：美术 ★☆☆（复用战斗资产）；程序 ★★★（脚本化演出+必败/必胜剧本+异常兜底，全项目最贵的程序活）
- **优点**：第一分钟就在"玩这个游戏"，留存冲击力最强；开场直接完成核心战斗教学；未来自己"给你力量"的 B3 节拍由机制亲自演示，情感落点最实
- **缺点**：新档到"自由行动"间隔最长，急性子玩家最容易在开场流失；剧本演出的边界情况（跳过、崩溃、中途存档）都要兜底
- **落地**：BattleManager 预置"序章剧本"配置（补剧情.txt 已给出此方向）+ `scenes/intro/prologue.tscn` 壳；必须配"跳过序章"选项

## 推荐与组合

**没有规定必须单选**——常见游戏开场本就是"前段动画 + 后段实机"的拼接。推荐三条路线：

1. **稳健路线（推荐首选）**：方案 1（分格漫画讲 B1–B7）→ 无缝接方案 9（实机醒来进基地）。
   漫画管"史诗感"，实机管"落地感"，两段都是低成本高产出，且方案 2 里的对话框组件可以先行做出来垫底。
2. **贴题路线**：方案 7（卡牌发牌）。如果只允许选一个形式，选它——开场形式本身就在教玩家"这个世界的力量以卡牌保存"，B6 设定由形式自证。
