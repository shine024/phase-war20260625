# 背景图 3x3 反推改图工作流说明

把单车道侧滚战斗背景 → **3x3 对 3x3 开阔地面布局**。连续自然开放地面(无网格、无强制中线),底部大块平整放置区供单位站立,天空压小,氛围忠实原图。

## 流水线(两步)

### 第 1 步:反推原图
- **模型**:`agnes-2.5-flash`(多模态,`/v1/chat/completions`)
- **作用**:看原图,生成一段中性英文视觉描述,锁定**时间/天气/色调氛围/天空/地平线/地面材质**
- **关键**:指令显式**跳过前景物件**(箱/沙袋/板/丝/障碍/堆),把前景当空地;禁战争词(过审)
- **缓存**:结果存 `reverseprompt_level_XX.txt`,下次命中缓存跳网络(反推较慢,flash 也偶发超时)

### 第 2 步:img2img 改图
- **模型**:`agnes-image-2.1-flash`(`/v1/images/generations`)
- **输入**:`prompt = 反推描述 + MODIFY 改图指令`;`extra_body.image = [原图 base64]`(img2img 必须放 `extra_body` 内数组,顶层 `image` 会静默退化成 text2img)
- **成功标志**:返回 URL 路径含 `/i2i/`
- **输出**:`bg_3x3_level_XX.png`(1792x1024 请求,实际 ~1312x736,16:9)

## 改图指令(MODIFY)设计要点

| 要点 | 措辞 | 原因 |
|---|---|---|
| 天空小 | `roughly one third / make the sky SMALL` | 模型**不认 % / horizon line 35%** 抽象比例,只认大小词 |
| 地面大平整 | `HUGE wide fairly-level, level smooth so units can stand stable` | 放置区要稳 |
| 地面有细节非空 | `sparse low grass tufts, tiny pebbles, small rocks` | "completely empty / NOTHING" 会让地面死板光秃 |
| 底边不秃 | `Near BOTTOM edge add foreground detail: grass clumps, stones, dry weeds` | 否则底边光秃 |
| 过渡无线无雾 | `same ground texture continues to far distance, ONE continuous surface, same color` | **"line/band/strip" 会画线;"haze/mist/fog/aerial perspective" 会画雾墙** |
| 远景不构线 | `low distant trees same color family as ground, soft small` | 远树同色族,不构成对比剪影线 |
| 无聚光 | `Natural ambient light — no stage spotlight, no artificial beam` | 聚光灯太假 |

## 踩坑记录(prompt 演进)

- **v05**:`Compress the SKY to at most top 35%` → 模型忽略,天空没小
- **v06**:`LOW horizon line at 35% / SKY ONLY thin band` → 还是没小
- **v07**:`SMALL sky / HUGE ground / ground 3x sky` → **天空小成功**(大小词有效)
- **v07 副作用**:`3-by-3 unit grid` → 模型当真**画格子**;`completely empty` → 地面死板;底边光秃
- **v08**:删 grid,加地面装饰 + 前景底边细节 → 地面活了
- **v08/v09 问题**:`thin line at horizon` + `haze/mist/fog` → **中景出现一条线**(线词)+ 天空顶一条线
- **v10**:`thick fog swallows everything, no distant structures` → **雾太刻意**,占空地边缘
- **v11**:`aerial perspective: far ground lighter/cooler/softer` → 模型还是**当雾画**
- **v12(最终)**:删全部 `haze/mist/fog/aerial/dissolves/line/band/strip`;过渡改**同质同色同材质连续地面**;远树同色族柔和小 → ✅ 无雾、无线、自然融合

**核心教训**:对扩散模型,负向词(`no line`)+ 机制词(`aerial perspective`)都不可靠;**正向描述目标形态**(`same texture continuous surface`)才稳。

## 用法

```bash
# 默认跑 2-5 关
python "docs/3x3_vs_3x3/工作流定稿/背景图_3x3反推改图_工作流.py"

# 单关(调试/重跑)
python "docs/3x3_vs_3x3/工作流定稿/背景图_3x3反推改图_工作流.py" 4

# 批量(全部剩余关)
python "docs/3x3_vs_3x3/工作流定稿/背景图_3x3反推改图_工作流.py" 6 7 8 9 10
```

- **输入**:`assets/backgrounds/bg_level_XX.png`
- **输出**:`docs/3x3_vs_3x3/bg_3x3_level_XX.png`
- **反推缓存**:`docs/3x3_vs_3x3/reverseprompt_level_XX.txt`(删它可强制重反推)

## 注意事项

1. **SSL**:apihub 证书过期,脚本已 `check_hostname=False / CERT_NONE` 绕过
2. **网络**:img2img 偶发超时(尤其 SSL EOF),脚本内置 4 次重试;失败单关重跑即可
3. **内容策略**:原图多为战场主题(工事/废墟/沙袋),反推 prompt 禁战争基础词后,模型会用近义词(metal fencing/coils of wire/sandbag barriers 等)。多数关生图不触发 policy;若某关触发 `content_policy_violation`,扩禁词列表
4. **尺寸**:请求 1792x1024,返回 ~1312x736;游戏 1280x720,可直接用或裁切
5. **API 密钥**:见 `docs/生图API.txt`;脚本用主密钥(活跃),备份密钥备用
