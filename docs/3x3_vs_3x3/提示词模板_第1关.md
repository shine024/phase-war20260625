# 第1关 背景生图提示词（v03 定型版）

输出文件：`level_01_v03.png`（1312×736，16:9）
API：`agnes-image-2.1-flash`，size `1792x1024`，去掉 `response_format`

## 设计要点（锁定）

1. **三层比例**：顶 40% 天空 / 中 15% 远景过渡带 / **底 45% 专用放置区**
2. **底部放置区必须全平全空**：无任何物体，供单位站立；所有细节推到中间过渡带
3. **整体一片连续地面**：左右自然连通，不分割、无中央屏障
4. **第1关主题**：20世纪初欧洲乡村河谷黎明（索姆河基调），钢壁防务配色 steel-blue + earthy-brown + khaki
5. **近侧视**（near side-view），干净地平线，无强透视畸变

## 内容政策注意（重要）

**WW1 / 索姆河 / Somme / 战壕 / 铁丝网 / barricade / blood / corpses / MP18 等词会触发 `content_policy_violation`**。
- 描述用合规同义替换：`early 20th century European rural valley`、`old countryside`、`distant old farm cottages`、`low earth mounds`
- 负面提示词里**不要写 gore/blood/corpses/weapons**，只写要排除的构图问题
- 时代味靠"配色+氛围"传递，不靠战争名词
