## R17：轻武器枪口白热闪核

**文件**: `scripts/battle/vfx_impact_factory.gd`（spawn_muzzle_flash 轻分支后追加）

### 根因（弯路黑名单 #1 原样复发）

`muzzle_jet_sym.png` 画布 100×46，但**非透明内容只有 100×24 的细横带**。v18 注释按
"内容实宽 100px"设粒子 scale 0.07-0.15 → 单粒火星实际只有 **7-15px 宽 × 1.7-3.6px 高**
= 三像素高的细丝，轻武器枪口火自 v18 起**完全不可见**（诊断实测：wt0 枪口区亮像素
≈ 纯场景道具，spawn_muzzle_flash 本体贡献 ≈ 0）。

### 诊断过程（scenes/tools/vfx_muzzle_diag.tscn 留档）

1. 首测 45px 闪核仅 +21 亮px → 疑 tween 写法 → 复刻 spawn_impact_sprite 模式仍无效
2. 节点探针：精灵在树/可见/alpha 0.68 但零像素贡献 → 排除 tween/池
3. 裸 Sprite2D 对照同样 ~0 → 怀疑贴图 → PIL 实测内容带仅 24px 高
4. 同贴图 scale 2-4 渲染 11545 亮px → **贴图没问题，是 scale 标定错了基准**

### 修正（单变量：闪核层 scale 按内容带实寸重标定）

双层闪核（复刻 spawn_impact_sprite 双层模式）：
- 白热核心：scale 1.4→2.0（带高 34→48px），近纯白，膨胀 0.05s + 淡出 0.14s
- 暖橙光晕：scale 1.8→2.4，alpha 0.45，膨胀 0.07s + 淡出 0.16s

### 验证

- 像素：8 个轻武器枪口格全部 **+2100~2400 亮像素**（839→约 3000，与重型族 5538 同量级）
- median/3 族均分：f00 4.17→4.67（+0.50）、f05 3.50→3.83（+0.33）、f04 4.33→4.50（+0.17）、f06 3.67→3.67

## R19+R20：曲射弧线可读化（2026-08-20 第二批）

**起点**: f01/f02 trajectory 全 2-3/10，AI 批"完全缺失弹体与曳光/未展示飞行中弹体"。

### 根因 ×2（连环缺陷）

1. **R19 双枚举碰撞**：`_apply_trail_tier` / `_trail_color_for_weapon` 的 `0,1,2,4` 分支
   按旧枚举注释当 "SMG/RIFLE/MG/PISTOL"，但同文件 `_get_indirect_arc_multiplier` 按
   新枚举把 1/2 当 INDIRECT/AERIAL——曲射弹被拖 SMG 级火花（16 粒 0.35-0.65），
   且贴图分发落 else 火花贴图。修复：1/2 归入 `[3,7,9]` 烟迹组
   （贴图/档位/配色三处），档位按弹体 78×13px 标定烟团 23-41px（v18-R6 烟<弹教训）。

2. **R20 local_coords 缺省**：CPUParticles2D 默认 `local_coords=true`——粒子在弹体
   本地空间模拟，弹体飞走时把全部已发射粒子**拖走**，拖尾只是身后 ~22px 的尾巴
   （初速×寿命），路径永远画不出来。修复：`_trail_particles.local_coords = false`
   （粒子留在世界空间沿飞行路径沉积）。全族轨迹格随之出现真实弹道线。

### 验证（R20 全 12 族 × 3 轮 median/3 vs R16 单轮基线）

- **总分 3.93 → 4.16（+0.23）**——全会话最大单轮涨幅
- 轨迹格 9 涨：f01_player 2→4（卡死两轮的弧线格）、f04_enemy 4→6、
  f08_player 4→5、f06/f07/f09/f10×2/f11 各 +1
- 像素证据：f01 弧线中段（y45-260）0→1807 亮px；空间分布为线/弧形非云状
  （f08 峰值行 773px 集中窄带；v17c 烟云教训已规避）
- 族均分：f10 +1.17 / f02 +0.83 / f04 +0.33 / f11 +0.33；f06 -0.27（enemy 侧 -1）
