# 命中表现夸张规则（以《暗黑破坏神 3》为标准）

2026-09-17 · 本文是命中/弹道/枪口特效的唯一美术验收标准。**任何特效改动先对表，参数轮动只许向已批的表收敛。**
参照系：暗黑破坏神 3（D3）——ARPG 打击感的行业基准。前轮参照的《矮人军团》量级结论（白团占比等）作废，其"反馈强度分层"思想保留。

## 一、D3 命中语言五律（总纲）

1. **受击白闪是主反馈通道**——每次命中最先被读到的永远是"目标本身亮了一下"（剪影推白 0.06-0.10s），命中点的粒子是配角。D3 的打击感七成来自这个白闪 + 音效，粒子只占三成。
2. **命中点只放"亮点"，不放"烟量"**——接触点反馈 = 小而亮的火花迸溅（≤0.15s），颜色即语义。D3 的常规命中几乎零烟：**烟是爆炸族和地面持续效果（火墙/毒云）的专属词汇**。
3. **颜色即语义，一色一义**——伤害类型决定命中光色：物理=白金、火=橙、雷/电=青白电弧、虚空/能量=紫、化学=绿。阵营信息只承载在冲击波环和伤害数字上（本项目既有约定，与 D3 阵营无关、类型着色的原则同构）。
4. **强度阶梯按量级跳档，不按伤害数值连续缩放**——轻→tick 级；重→闪+震+碎；大招/核武级→全屏。玩家按档读威胁，不读像素差。
5. **死亡 > 命中**——单击克制、击杀夸张（D3 怪物碎尸+战利品喷发是全游戏最大的演出）。常规命中永远不给击杀级的量。

**横切规则（全体生效）**：
- **弹体尺寸律（v38 用户裁决"炮弹比兵大"）**：飞行中的弹体**恒小于一个兵**（单位基准宽 58.9px / 参考单位 64px）——曲射炮弹基准 ~50px（PROJ_TEX_SCALE[1]=0.45，榴弹 flavor 1.2 加成已取消）。弹体的"分量感"由拖尾与命中爆炸承担，不许靠放大弹体本身；调整任何弹体尺寸前先对照本条与单位基准。
- 受击白闪（unit_outline flash_strength）：0.08s 剪影推白，暴击/HEAVY 档加亮到 1.0 全程；这是唯一全族共用的主反馈。
- 暴击顿帧 0.05s@0.1（450ms 冷却）：保留，与 D3 重击顿帧同律。
- 燃烧 DoT：火焰包下半身 ≈ 单位等宽（已升格）——D3 持续状态视觉显著于单击，同律。
- 点射节奏：步枪 2 发/机枪 3 发，**首波全亮 + 后续波 42% 减淡（曳光回声）**——保留节奏，消灭"多弹头"读感（已实装）。
- 伤害数字：保留阵营双色 + 相对量级金色大字——**有意偏离 D3 的小数字**（Phase War 是卡牌构筑游戏，数字是构筑反馈的一部分，此偏离经用户裁决）。
- 机制弹字（闪避/护盾破碎）：保留——D3 的精英词缀触发也有文字提示，同律。
- **光学层（v6.17 新增）**：泛光（battle_optics.ensure_glow 挂 WorldEnvironment，**只开第 3 级 glow 模糊** + project.godot hdr_2d）+ 曳光/白斑 HDR modulate（rgb>1 过 bloom 阈值）+ PointLight2D 光闪池（枪口/爆炸/大招三挂钩，上限 10）+ 背景压暗降饱和（BG_DIM 0.72 / BG_SAT_KEEP 0.82，era_bg_modulate 唯一口径）。光学层是**既有词汇的亮度放大器，不新增命中词汇**；弱机（GT 620M 级）实测 glow 默认两级 ≈4x 帧率损失、只留一级 ≈ 零回归——**勿加回多级**。开关 GameConfig.vfx_glow_enabled / vfx_dynamic_lights_enabled，环境变量 PW_GLOW_OFF=1 / PW_LIGHTS_OFF=1。参照系《轮回保险公司 R.I.P.》拆解（2026-09-18，13 张官方截图）：其开火/弹道/命中表现力来自光学外衣，命中词汇与 D3 表同构。
- **曳光表微调（v6.17，表 #0"粗曳光"项内收敛）**：宽度全档 ×1.3（MG 3.8 / RIFLE 2.4 / TANK_GUN 4.5 / SMALL_ARMS 2.5 / XENO 2.8 / 兜底 3.0）+ 颜色 rgb×1.5 HDR 化；坦克炮曳光 5.4×口径、0.065s。弹体本体尺寸不动（弹体尺寸律不破），alpha 口径全不动（42% 点射回声不破）。v38.6 回归锁已锁此值，改动须同步断言。
- **焦痕密度（v6.17）**：爆炸族概率 0.5→0.65、半径 8-18→10-20、peak_a 0.42→0.50；MAX_TRACES=48 环缓冲上限不变（防刷屏约束仍在）。
- **伤害数字抖动（v6.17）**：±15/±10 → ±26/-16~+6，防 big_crit 金色大字叠印（数字风格/双色不破）。

## 四、验收流程（防再循环）

1. 本表经用户逐项裁决后**冻结为唯一标准**；
2. 此后特效改动一律"向表收敛"，不再引入表外词汇；新增武器/机制先加表再写码；
3. AI 评分降级为回归参考（只防退化，不做审美裁决）；每轮改完以战斗实录片段交用户过目；
4. 参数冻结后写 CHANGELOG/AGENTS 定稿记录。
