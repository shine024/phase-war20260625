## 核对要点提示

1. **effect重定向**：MOD的accuracy_bonus实际加暴击伤害，vision加暴击率——核对时勿看字面。
2. **我方不乘时代倍率**（v6.8移除），仅敌方/UI消费。
3. **直射衰减v6.2已删**，统一不衰减。
4. **evolution_registry `_unit_type_to_key` bug**：5兵种查进化返空。
5. **敌方Lv双语义**：手填level（设计基准）≠ 展示Lv（战力派生）。
6. **JSON优先**：`data/json/enemy_phase_masters.json` 若存在则覆盖内联数据（schema v1）。
