## 一、编号体系（图源分配）

| 段 | 编号范围 | 内容 | 图源约定 |

| A段 | 001~028 | 平台卡/新时代单位（FOE_PLATFORM 源ID） | vis_enemy/player_NNN |
| B段 | 030~035 | 精英掉落卡（FOE_SPECIAL，029预留） | vis_enemy/player_NNN |
| C段 | 036~071 | 固定敌人（含Boss，36张） | vis_enemy/player_NNN |
| D段 | 专属命名 | 补充池卡（29张，用 card_id.png） | enemy/player/card_id.png |
| E段 | 072~081 | 堡垒类别（10张） | vis_enemy/player_NNN |
| **F段** | **082~087** | **平台卡变种（6张，无源ID映射）** | vis_enemy/player_NNN |
| 预留 | 088~109 | 待分配 | — |
| **G段** | **110~114** | **守护者成就卡（5张，终极Boss奖励）** | vis_enemy/player_NNN |

**图源约定**：
- `vis_enemy_NNN.png` = 敌方原图（朝左，512×512 RGBA 透明底）
- `vis_player_NNN.png` = 我方翻转图（vis_enemy 水平翻转生成）
- D段用 `card_id.png`（如 `ww1_inf_enfield.png`）而非编号

## 二、命名规则（统一三段式）

```
<era>_<role>_<specific>[_tier]
```

| 字段 | 取值 | 说明 |
|---|---|---|
| **era** | `ww1` / `ww2` / `cold` / `mod` / `fut` | 时代 |
| **role** | `inf` / `arm` / `arty` / `sup` / `air` / `fort` / `boss` | 战斗定位 |
| **specific** | 型号代号 | 小写下划线，真实名或音译 |
| **tier**（可选）| `_e` | 仅精英强化版 |

**特殊前缀**：
- `platform_<era>_<role>` — 平台卡（敌方部署模板）
- `guardian_<era>_<name>` — 守护者成就卡（玩家终极奖励）
- `drop_<name>` — 特色掉落卡（击败精英/Boss获得）

## 六、掉落体系（v7.x 修复）

### 掉落链路

```
击杀敌人 → battle_damage_system.roll_blueprint_drops(unit)
  → EnemyArchetypes.get_drop_definitions(archetype_id)  # 读 _manifest_merged.drops
  → CardDropGrants.grant_enemy_style_card(card_id)
  → DefaultCards.get_card_by_id 查到 → DropManager.grant_dropped_cards_by_id 发放
```

### 每个敌人的运行时 drops 组成

`apply_capture_drops_to_archetypes`（v7.x 修复：从覆盖改追加）后，每个敌人 drops =：

```
[特色卡(若有), captured_<archetype>, bp_平台蓝图(自动)]
```

- **特色卡**（drop_*）：JSON 配置的精英/Boss 专属掉落
- **captured_***：基础缴获卡（8% 普通 / 22% 精英 / 55% Boss）
- **bp_***：自动平台蓝图掉落（air-only 单位除外）

### Boss 掉率修复（v7.x）

`_tag_tier_from_id` 从 `begins_with("boss_")` 改为 `contains("boss")`，修复 `cold_boss_mig`/`mod_boss_command`/`fut_boss_nexus` 掉率 8%→55%。
