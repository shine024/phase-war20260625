◆ v1.4 核心改动：底部操作台 + 右单位面板（融合方案）

  • 布局：三栏 左单位名册 220px / 中改造库+底部台 1fr / 右单位面板 280px。继承 v1.3 视线垂直向下的优势，同时恢复 v1.1 的右栏单位面板。
  • 中栏精简：删除顶部 unit-strip（与右栏单位面板重复）。中栏直接从改造库列头开始，列头 ch-count 只保留改造库自身的统计（可用 6 · 总持有 14），不再重复单位名/槽位（右栏已有）。改造库获得更多垂直空间。
  • 职责清晰分工：右栏承载单位面板（战力大字/基础属性/已装改造列表），底部台只承载模块的"决策→执行"（核心属性+要求+安装按钮）。两者无信息重复。
  • 底部台瘦身：因右栏已承载战力档位进度条，底部台省去战力档位 chip 行，只保留单行紧凑要求（强化≥3 ✓ · 纳米64 ✓ · 图纸1 ✓）。高度从 v1.3 的 ~140px 压到 ~80px，改造库获得更多垂直空间。
  • 视线流：选中改造库模块 → 视线下移看底部台核心属性（+42%）+ 安装按钮 → 点安装。右栏单位面板恒定显示，余光可瞥战力/属性变化。
  • 取舍：v1.4 是 v1.3（视线流最优）和 v1.1（单位面板完整）的融合。代价是改造库列宽被右栏挤掉 ~280px（原 v1.3 单屏 7-8 行 → v1.4 约 6-7 行），但仍优于 v1.1。
