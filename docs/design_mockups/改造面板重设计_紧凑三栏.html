◆ 紧凑三栏方案 · 核心改动对照（临时修改.txt）

  • 问题①·右侧栏"双重身份" → 中栏 9 槽位从 3×3 大方块缩为 横向窄条（高度从 ~150px → ~60px），让出中栏垂直空间给「当前单位基础面板」。
  • 问题②·焦点不统一 → 右栏只在「中栏 Hover/选中模块」时刷新；左栏选中单位用 左侧 3px cyan 边框（不再是大块深色框），仅做锚定不打架。
  • 问题③·顶部 9 槽位占地过大 → 槽位高度 30px 横排一行，释放的纵向空间用于展示 HP / 三维攻防 / 战力档位，解决"右栏列表很长时左中栏闲置"的痛点。
  • 右栏瘦身：战力档位从「大灰条阶梯」压缩成 单行 chip + 状态点；解锁要求 + 材料纳米 + 图纸合并成 3 行小字；核心属性（+42%）独立成发光块紧贴安装按钮，视线垂直向下。
  • 对比度代替文字说明：「档位不足」「冲突」两类不可装模块整行 35% 透明；「可安装」绿色 chip / 「已装」cyan chip，玩家一眼定位可操作项。
  • 视线流：左栏点单位 → 中栏 Hover 模块 → 右栏看核心属性 → 点安装。焦点集中在中-右区，左栏只做锚定。
  • 真实数据：单位=虚空领主#4（OVERLORD 1248 战力），改造=致命精通（epic +42% 暴伤），均来自项目真实数据。
