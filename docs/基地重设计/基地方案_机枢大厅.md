# 基地方案 · 机枢大厅（The Machine Hall）★ 用户定调版

> 2026-09-03 定稿③。用户拍板：**D1 场景感 + H1 面板运营并存，不要 NPC**。
> 形态 = 一间房 + 残破机器可修可升级 + 运营面板随进度进化（**白板 → 显示器 → 投影**）。
> 定位：前作《基地替代方案10选.md》方案十（指挥舱）×《塔科夫龙崖系》H1（总览面板）的合体升级版。
> 一句话：**场景给地方感（机器一间间亮），面板给运营感（工具一代代换），基地自己是主角。**

---

## 一、为什么这个合成成立（评估）

| 痛点 | 解法 | 来源 |
|---|---|---|
| 带入感不强 | 不靠 NPC 靠"物"：残骸变新机、房间越来越亮、指挥工具从白板进化到全息——**进度本身可见可感** | 机器状态 × 面板皮肤 |
| 繁琐 | 单房间零寻路，点机器即开面板，列表内一键修复/升级 | H1 |
| 不清晰 | 机器大件化（120-220px）+ 面板全状态一屏（状态/耗时/成本/队列） | 场景 + H1 |

成本对比：比 D1 全营地便宜一个量级（1 张房间底图 + ~9 台机器精灵 + 3 套面板皮肤框），
比裸 H1 多了"地方感"。**风险最低的完整解。**

## 二、场景：机枢大厅

一间废弃车间改的指挥机枢（TWoM 手绘粗粝风延续，相位青点缀）。**1280×720 单屏，无卷动，无角色走路**。

```
┌──────────────────────────────────────────────────────────┐
│ 后墙：管线/铁架/30灯纪念灯阵(装饰)     [封死的终局门]🚪     │
│ ┌────┐ ┌──────┐ ┌───┐ ┌────┐ ┌──────┐ ┌───┐             │
│ │发电机│ │沙盘台 │ │实验台│ │分析仪│ │电台  │ │灯阵│  ← 后排高台 │
│ └────┘ └──────┘ └───┘ └────┘ └──────┘ └───┘             │
│    ┌────┐  ┌─────┐  ┌────┐  ┌─────┐                      │
│    │充能舱│  │工作台│  │炊事机│  │打印机│        ← 前排地板   │
│    └────┘  └─────┘  └────┘  └─────┘                      │
│ （地面：油渍/线缆/地漏——点击机器即交互，无走路）              │
└──────────────────────────────────────────────────────────┘
```

- **机器 = 站点**（9 台，对应功能合并表）：发电机(反应堆·电力门槛)、沙盘台(出击+战区地图)、
  实验台(技能树+相位仪)、分析仪(情报+英雄档案)、电台(商店/势力/排行)、纪念灯阵(符文+成就+30灯·装饰化)、
  充能舱(睡觉推进天数+存档+背包)、工作台(改造/制造/成长)、炊事机(配给+治疗)、打印机(卡墙+战利品打印)。
- **尺寸分级防均质**（吸取胶囊网格教训）：重要机器大（发电机/沙盘 200px+），次要小（120px），
  高低两排错落，不排字。
- **机器三态**：`残骸`（蒙布/锈壳/断电）→ `运转`（亮灯+待机动画）→ `升级`（外挂件：加装的模块、
  多出的机械臂、叠上去的附件——**用外挂件精灵叠加，不重烘底图**，复用 v26.8 upg 图层思路）。
- **每台机器一段待机动画 + 环境音 loop**（发电机低频、打印机步进电机、电台杂音）——没有 NPC，
  机器的"活着"就是人气。
- **封死的终局门**：后墙一扇门（观星台终局保留仪式位，条件达成后开门，不做机器）。
- **灯光叙事**：修复一台，房间主光源亮一档（全屏环境光渐变），从"手电筒车间"到"满堂机枢"。

## 三、面板：运营总览的三个时代

**面板内容恒定 = H1（分组列表/状态/耗时"还差N场"/成本/生产队列/今日目标链），只有"容器皮肤"进化：**

| 档 | 容器 | 视觉 | 解锁条件（系统推导，免存档） |
|---|------|------|------------------------------|
| T1 | **白板** | 手绘白板+磁贴便签+马克笔字，成本像手写的，日报是贴上去的纸 | 默认 |
| T2 | **显示器** | CRT/三联屏机柜，站点卡片=屏幕窗口，扫描线 shader，计时数字跳动 | 6 站运转 或 发电机上线 |
| T3 | **投影** | 全息投影台，悬浮基地模型+粒子，数据流发光 | 9 站全运转 + 发电机 Lv2 |

- 晨报（H4）随皮肤换形态：T1 贴在白板上的手写日报 → T2 终端日志流 → T3 全息语音播报。
- **进化瞬间做成演出**：白板被摘下、CRT 吊装机柜、投影仪第一次亮起扇形光——每次换肤都是一次"基地升级了"的高光时刻，这是本方案的带入感核心。
- 面板与场景互导：点面板列表项 → 场景相机轻推+该机器高亮描边；点机器 → 面板切到该站详情。一键切换"场景为主/面板为主"布局。

## 四、交互流（铁律复查）

- 点机器（或面板行）→ **立刻**弹该站面板（修复中则显示进度/加速选项）→ 操作完成。
- 出击：沙盘台机器 或 顶栏常显"出击"按钮 → 战区地图。**基地→开战 ≤2 击 ✓**
- 收取：机器顶气泡（复用 `bunker_reward_bubble`）+ 面板"一键收取"。
- 天数：点充能舱睡觉 → 日结算+存档（现有 DayClock/晨报链不动）。

## 七、分期落地

- **P1（可玩）**：大厅底图 + 9 机器两态 + T1 白板面板 + 点击直开面板 + 气泡收取。
- **P2（进化）**：T2/T3 皮肤 + 换肤演出 + 升级外挂件 + 机器待机动画/环境音。
- **P3（终局）**：终局门开启演出（投影仪最终形态投出相位月/星图——观星台叙事并入投影，可选）。

## 八、残余风险与对策

1. **单房间仍可能显空/冷**（无 NPC 无角色）→ 对策：机器待机动画+声音密度要足；灯光随进度明显变亮；换肤演出撑高光时刻。
2. **面板皮肤三档工作量**→ 对策：T1/T2/T3 先用同一列表控件，只换外框材质与字体（半天的 Theme 工作），美术后补。
3. **机器摆放又排字**→ 对策：尺寸分级+两排错落+1-2 台斜置（发电机/沙盘可不与墙平行）。
