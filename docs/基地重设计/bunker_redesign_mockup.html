一 · 房间三态特写（以维修工坊为例）

沿用现有状态机语义：STATE_LOCKED(0) 废弃 → STATE_REPAIRING(1) 修复中 → STATE_ACTIVE(2) 可用。视觉重定义：锁定 = 未开挖岩腔（虚线勘察轮廓 + 镐 + 成本），修复中 = 脚手架 + 火花 + 进度（按战斗场数推进），点亮 = 暖灯内景 + 家具 + 青色状态灯呼吸。

① 锁定 · 未开挖岩腔

岩石填充腔体，青色虚线为勘察轮廓；中央镐图标 + 修复成本。整块区域在画面上"还不存在"，只属于岩层。

② 修复中 · 脚手架与火花

家具半亮（灰调 60%），脚手架网格覆盖，橙色火花循环下落；底部进度条显示"还差 N 场战斗"——修复进度由出击推进。

③ 点亮 · 可用

暖灯池亮起、家具全彩、右上青灯呼吸。点亮瞬间播"灯管启动"闪烁（两闪→稳定 0.6s，见动效清单）。
