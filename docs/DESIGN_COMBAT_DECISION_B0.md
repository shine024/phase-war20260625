# 战内决策点扩充设计（B0 草案 — 待批）

> v26.12 起草（2026-09-03）。目标：改善"战斗可看可跳过"——挂机零损失的设计底座不动
> （ultimate_cast_controller 自述原则），手动是纯增益 opt-in，本设计只扩大"想介入"的空间。

## 一、现状

- 战内决策点：①能量节奏下部署（含 1-9 快捷键）②手动大招白名单 **4 个**
  （核子轰炸 + 战术核武/护盾投射/电子屏蔽）
- 深度集中在战前构筑（组合技/搭档协同/光环/改造），战中是"演出观赏期"
- 挂机链完整（AFK 循环 + 自动部署），这是产品定位，不动

## 二、设计原则（铁律）

1. **挂机零损失不回退**：任何手动介入的期望收益 ≥ 0，失误收益 ≤ 自动行为
2. **冷却/资源约束**：手动收益来自"时机"而非"额外数值"——同一能力手动路径不改数值表
3. **可发现性**：每个新决策点在战前摘要有一行说明（复用 world_map 战前摘要链）

## 三、扩充项（3 个，按性价比排序）

### D-1 手动大招白名单扩充（1-2 天，纯数据 + 少量 UI）

现白名单机制已完备（MANUAL_ABILITY_IDS / MANUAL_MECHANISM_IDS + armed FIFO）。
候选从现有自动大招池挑（不动数值）：

| 候选 | 手动化收益 | 理由 |
|---|---|---|
| 轨道炮击（precision strike 类） | 高——点名时机决定收益 | 延迟落点天然适合预判 |
| 医疗无人机群 | 中——残血时机团血差 | 时机敏感、误用损耗低 |
| 电子干扰（敌方侧全屏） | 中——对抗 boss 大招窗口 | 与现有 18s 屏蔽同语义 |

验收：手动模式下按钮带出现新按钮；自动模式下行为与现状逐帧一致（回归锁）。

### D-2 部署定向指令（3-4 天，新机制）

部署后的单位长按（或按住数字键）弹出 3 向指令轮盘：
- **集火**：标记一个目标，该单位索敌优先级 +∞（复用 target_selection 的优先级通道）
- **守住**：锁定当前位置不再追击（复用现有 attack_range 判定，只是禁移动）
- **自由**：默认行为

约束：单次战斗同时生效的指令 ≤ 2 个（防微操过载）；挂机模式下不出现轮盘；
指令在单位死亡后消失。UI 走现有卡牌拖拽/槽位长按链路。

### D-3 战场暂停情报浮层（1 天，纯 UI）

暂停菜单（v26.11 已有）追加"战场情报"页：当前波次/下一波构成、敌方相位师血量与
大招充能状态、环境效果四维读数。信息全部来自现有 collector 数据，只补展示位。
价值：把"暂停"从逃逸键变成决策点（看一眼再决定手动大招/部署顺序）。

## 四、明确不做（本轮）

- 直接操控单位移动/攻击（改产品形态，不是决策点问题）
- 主动技能按钮堆砌（每个技能=一个冷却管理负担，与挂机定位冲突）
- 敌方侧手动化（保持对称简单）

## 五、实现顺序与验证

D-1（先做，收益/成本比最高）→ D-3（独立 UI，随时可插）→ D-2（新交互，需原型实机试）。

每项验收：自动模式回归（行为零漂移）+ 手动模式实机体感 + ui-review 检查单走查。
