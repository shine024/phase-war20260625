# 统一化手术设计（治"拼凑感"）

> 日期：2026-09-08
> 背景：四个维度（视觉/系统/叙事/节奏）拼凑感全中，诊断结论：**病根一个——游戏缺"统一锚"**，无一份所有内容都服从的宪法。UI 层有 DesignTokens 纪律但只覆盖壳，内容资产层（卡图/背景/漫画/基地图）与文案层（65+ 面板/202 改造/131 卡）无宪法约束，多批次生长致漂移。
> 方案：用户选定 **C：分批全治**。收编深度=**重（全量文案）**；视觉锚=**外部参考重定**。

## 总纲

四批顺序执行，**顺序不可倒**：宪法不定，文案收编（②）与资产重生成（④）都会再漂移——这正是本次拼凑感的成因。每批独立验收。

```
① 双宪法（定锚） → ② 全量文案收编 → ③ 节奏缝合 → ④ 资产重生成
```

## 批次①：双宪法（定锚，约 1 周）

### 1. 风格宪法 `docs/统一化/STYLE_BIBLE.md`

- **第一步（外部参考征集）**：出 3-4 个美术方向候选（军事写实向 / 末世工业向 / 油画历史战争向 / 科幻霓虹强化向），用户挑定后收集参考图做 mood board。
  决策注（2026-09-08）：mood board 以文字参考系替代（Frostpunk/TWOM/FTL 三款，直接写入 STYLE_BIBLE header），不另行收集参考图；批次④首批出图若风格跑偏再补建。
- 内容：色板、光线规则、笔触媒介规范、构图规则。
- 按资产类别（卡图 / 战场背景 / 序章漫画 / 相位仪徽章 / UI）的 **agnes/Flow prompt 锚模板**——对接 `tools/_agnes_image_api.md` 行为实测（正面意象锁死有效、负面词反激活）与 FLOW 工作流（prompt ≤900 字、--ref 强内容锚）。
- 资产分档标准：合规 / 调色可救 / 需重生成。

### 2. 语言宪法 `docs/统一化/LANGUAGE_BIBLE.md`

- **权威词汇表**：生灵 / 黑门 / 深航计划 / 相位仪 / 同伴 / 迷失者 / 时代坐标……每词定义 + 用法规则。
- **系统→叙事映射表**：65+ 面板名、4 资源名、202 改造、131 卡的旧名→新名。
- **安全边界（铁律）**：只改显示层（display_name / description / 面板标题 / 按钮文本），**id / 存档 key / 效果键 / 信号名一律不动**——旧档兼容零风险。
- 禁用词清单（已退役系统词如"科研点"）+ 语气规则（称谓、句式）。

## 批次②：全量文案收编（最重，2-4 周）

400+ 条文案全部重写进世界观：131 卡描述 + 202 改造词条 + 面板标题/按钮 + 教程 + 任务 + 结算 + 资源名。

- **工程化流程**（量大控险）：映射表驱动 → 模板化生成 → 人工抽查 → 分批落地，每批可回滚。
- **数值内核原则**：卡面描述的数值说明功能必须保留——叙事包壳 + 数值内核，包装不伤可读性。
- 敌方配装 identity 文案（`enemy_fixed_loadouts.gd` 生成区）同步收编，改生成器模板而非手写区（防下次生成覆盖）。

## 批次③：节奏缝合（1-2 周）

- **基地车=唯一枢纽**：系统入口全面房间化（收尾 EMBEDDED_PANELS 未竟部分）。
- **出征过场**：世界地图→战场加出兵演出；**结算叙事化**——战报包装成"找回同伴 / 回收力量"（迷失同伴=相位师 boss 主线已有数据基础）。
- **系统渐进曝光**：并入现有 `docs/FTUE_AUDIT_2026-08-27.md` 执行——首日不暴露全部面板，统一感的隐形来源。

## 批次④：资产重生成（持续批次）

按风格宪法分档处理：

1. **先调色救**（批量统一调色 / LUT，最便宜，覆盖最大）。
2. **后重生成**（按违和度排序分批，agnes/Flow 管线已就绪，边际成本低）。

每批生成后必跑 `python tools/generate_card_foot_anchors.py`；换图后对 `player/` 重做 FLIP_LEFT_RIGHT；**美术备份铁律**——新增/换图后在权威目录 `F:\godot fair duet\_art_backup\` 按日期惯例重打包全量基线。

## 主要风险

| 风险 | 对策 |
|------|------|
| ④视觉大换血=存量资产部分沉没 | 生图管线边际成本低；先调色救可保留大部分 |
| ②量大（400+ 条） | 映射表驱动 + 模板化 + 分批可回滚 |
| 文案包装伤数值可读性 | 数值内核原则：模板化"叙事壳+数值核" |
| 改动漂移（重蹈覆辙） | 两份宪法为唯一权威源，后续任何生图/改文案先查宪法 |
