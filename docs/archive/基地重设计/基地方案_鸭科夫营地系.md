# 基地方案 · 鸭科夫营地系（可走动俯视版）

> 2026-09-03 追加②。用户指认参照游戏为《逃离鸭科夫》（Escape from Duckov，俯视角 PvE 搜打撤）。
> 与《基地方案_塔科夫龙崖系.md》（H1-H5，菜单/面板族）互补：**鸭科夫的藏身处是能走的场景**，
> 所以本族不是"面板化"，而是"把可走基地做好"——治带入感/繁琐/清晰的另一条路。
> 结论先行：**鸭科夫营地 = 布局俯视化（10选·方案五）+ H 系交互改造（直开面板/零等待）+ 30 逝者 NPC 化**。

## 〇、鸭科夫的藏身处做对了什么（拆解）

| # | 鸭科夫做法 | 对应我们的病灶 |
|---|-----------|---------------|
| 1 | **俯视角**，场景一眼扫完，站点=大件建筑/设备，方向感极强 | 不清晰（侧视剖面黑挤） |
| 2 | **站点少而重**（防具店/武器店/工作台/健身房/技术中心/厨房/传送器 ≈ 8 个），每个都直接给战斗力或经济收益，升级顺序本身是策略 | 繁琐（15 格小房间找功能） |
| 3 | **角色在场**：鸭子会走、有动作表情，"这是我在的地方" | 带入感（12px 光点没有身份） |
| 4 | **NPC 商人+任务**：有性格的鸭子们驻场，基地有人气 | 带入感（现版刻意无 NPC，冷清） |
| 5 | **交互零等待**：走到即交互，不排队不绕路 | 繁琐（光点两段 Tween） |
| 6 | **搜打撤↔基地强耦合**：升级材料只在突袭里掉，"为修基地而出击，为出击而修基地" | 出击与基地互相给意义（现版已有，但感知弱） |

## 〇.5、本项目已有的同构底子（好消息）

Phase War 的核心循环本来就是搜打撤族：**关卡(突袭) → 掉落(战利品) → 回基地 → 修复/升级(材料消耗) → 更强出击**。
`BunkerManager` 按场推进 = 鸭科夫的建造计时；修复成本(纳米/合金/晶体/能量块) = 突袭组件；
`QuestManager` 委托 = 商人任务；食堂 AFK/挂机收益 = 厨房/比特币矿机。**缺的不是系统，是呈现。**

## 方案 D1 · 鸦科夫营地（俯视走动版）★正牌翻译

**形态：俯视 45° 营地单屏（1280×720），陈末小人在场，9 个大站点，NPC 残影驻场。**

```
┌────────────────────────────────────────────────┐
│  ⛺帐篷(宿舍)   🚚卡车(仓库+打印)   🗼天线(通讯+商店) │
│                                                │
│         🔥篝火(中枢·晨报·一键收取)                  │
│      🛠工坊(改造/制造)   📡雷达(档案+分析仪)          │
│                                                │
│  ⚗️实验室(技能树/相位仪) 🍳炊事车(食堂+医疗)           │
│  ⚡发电机(反应堆)   ⚔️沙盘(出击) ⇦ 大门/吊桥=出击口    │
│         · 陈末（可见小人，点击移动）                  │
│         · 逝者残影（半透明，在站点间游弋）             │
└────────────────────────────────────────────────┘
```

- **布局**：俯视单屏不卷动（后续可扩展为可卷动营地）；站点 = 帐篷/卡车/天线/发电机等**大件**（每件 150-260px，图标级可读——侧视 232×130 胶囊的 2 倍面积）。
- **角色**：陈末从 12px 光点升级为**可见小人**（32-48px 手绘/像素，2-4 帧走路摆动即可）；点击即交互（面板立刻弹，小人事后走到——**先响应后演出**，零等待）。
- **NPC = 30 逝者残影**：半透明相位色剪影（3-4 个基底剪影 × 时代染色 × 微差异，成本可控），
  驻在对应站点给委托（"帮我打一场 X 关，了却生前遗愿"→ `QuestManager` 委托）、在商店当掌柜、
  随叙事阶段增多。**纪念墙系统升级成活的 NPC 网**——带入感的最大增量，且不违背"逝者"设定（他们是残影）。
- **篝火中枢**：中央篝火 = 晨报（H4）/一键收取/当日目标链（H5）的聚合点，也是夜景光源。
- **出击**：营地大门/吊桥，或沙盘站点；满足"基地→开战 ≤2 击"铁律。
- **升级链策略感**（鸭科夫第 2 条）：9 站各自的升级档位给明确战斗力/经济收益，
  推荐序=发电机→工坊→沙盘→实验室→通讯→炊事→仓库→雷达→篝火（数值可调，重点是"顺序有意义"）。
- 治：带入感（角色+NPC+篝火夜景）/繁琐（俯视直达+零等待）/清晰（大件+图标双识别）。
- 代价：**美术新管线**（俯视营地 1 张 + 站点大件 9 张 + 小人 + 残影剪影）；`bunker_main` 场景重写；侧视胶囊资产退役（详情大图仍可复用）。
- 代码：`BunkerManager`/房间表/存档不动；`bunker_player_dot` → 小人控制器；交互半径+直开面板。

## 方案 D2 · 鸦科夫 Lite（现版侧视场景改造版）★性价比

**形态：保留现版岩层要塞外观，但内部逻辑全部鸭科夫化。**

- **站点合并 15→9**（合并表见塔科夫文末公共修复），锁定房间从画面上**收拢**为"暗轮廓+大图标"，不再逼玩家辨认小胶囊。
- **光点 → 小人**：给陈末一个可见小人形象（哪怕仍是发光体，加身体轮廓/影子/落地涟漪），走路动画提速 2 倍，或直接"点击即达"。
- **点击即开面板**：不等走到（H2 的核心）。
- **残影 NPC 先行**：在不换场景的前提下，先把 30 逝者做成**在现有房间里出现的半透明残影**（站在食堂长桌旁、坐医疗室床边），点击给委托/遗言——现版资产零改动，带入感立刻+1。
- 治：繁琐/带入感（部分）；清晰改善有限（侧视黑挤仍在）。
- 代价：小（1 周内量级）；不解决 P1/P2 根因。
- 适合：**先做 D2 验证体验增量，再决定是否上 D1**。

## 方案 D3 · 混合：俯视营地 + 面板总览双入口

- D1 营地 + H1 藏身处总览**并存**：场景给"地方感"，总览面板给"运营感"，一个按钮互切（龙崖风）。
- 适合既想要人气场景、又重度依赖批量运营操作的后后期；首版不必做。

## 鸭科夫化专项清单（无论 D1/D2 都做）

1. **30 逝者 → 残影 NPC**：3-4 基底剪影 × 时代染色；驻点给委托（复用 `QuestManager`）、遗言一句（档案文案已有源：`enemy_phase_masters*.gd`）。
2. **陈末可见化**：小人 32-48px，走路 2-4 帧；精神值联动现有光圈逻辑保留。
3. **先响应后演出**：点击站点立刻弹面板，小人在后台走——杜绝等待。
4. **升级顺序策略化**：9 站升级收益表重排，让"先修谁"成为决策（发电机=电力门槛已有雏形）。
5. **材料感知**：修复/升级成本中挑 1-2 种材料设为"战斗专属掉落"，出击↔基地互相给意义（掉落表 `DropTables` 加条目即可）。
