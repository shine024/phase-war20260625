# 基地方案 · 塔科夫藏身处 / 龙崖系（面板驱动族）

> 2026-09-03 追加。用户反馈现版三大痛点：**带入感不强 / 繁琐 / 不清晰**。
> 参照系：塔科夫《逃离塔科夫》藏身处（Hideout）与《龙崖》（Dragon Cliff，放置 RPG）。
> 本族方案与前文《基地替代方案10选.md》的场景系互补——那 10 个换"基地长什么样"，
> 本族换"基地怎么操作"：**砍掉空间导航，代入感改由系统运转供给**。

---

## 〇、两款参照游戏到底做对了什么

| 游戏 | 核心模式 | 带入感来源 | 对我们的启示 |
|---|---|---|---|
| 塔科夫·藏身处 | 全模块**一屏总览列表**：每站等级/状态/升级成本/计时器/前置依赖一目了然；发电机会烧燃料、工位有**生产队列**（放入材料→计时→取成品）；被动加成常驻 | "我的藏身处在替我干活"——计时器在走、燃料在烧、加成常在，**运营感即代入感** | 状态全量可见 = 清晰；零导航 = 不繁琐；生产/被动收益 = 基地是"活的" |
| 龙崖 | 放置 RPG：功能全部**面板直达**（≤2-3 击），村景仅作装饰；离线/放置收益一键收取；**每个界面都显示下一步**（下一级/下一解锁/倒计时），永远有事可做 | "处处有下一格"的目标流 + 零阻力操作 | 功能入口常显、不藏景里；进度链推着走；收取批量化 |

现版病灶对照：

| 痛点 | 现版成因 | 本族解法 |
|---|---|---|
| 繁琐 | 点房间→等光点走两段 Tween→才开面板；15 房找功能 | 删掉走路，点击即达（≤2 击） |
| 不清晰 | 黑暗胶囊里藏功能；修复/升级状态要逐房悬停看 | 总览列表一屏全状态 + 计时/成本前置 |
| 带入感不强 | 基地是"布景"，玩家与它唯一的交互是走和点 | 生产队列/被动加成/总加成条/环境音——**系统在运转** |

## 方案 H1 · 藏身处总览（塔科夫直译版）

**形态：全屏面板，无场景导航。**

```
┌─ 顶栏：第12天 ▾ | 精神 64 | 纳米 820 合金 310 晶体 90 能量 45 | ✦基地加成：制造-10% 情报+10% 精神回复+30% ─┐
├──────────────────┬───────────────────────────────────────────┤
│ 站点总览（分组）    │  选中站点详情                               │
│ 【生活】           │  ┌─────────────────────┐                  │
│ ●宿舍    Lv2 ◐收  │  │  （房间内景大图        │  ← cap_* 原图    │
│ ●食堂    Lv1 ⏳2场 │  │   放大展示，细节终于    │    终于看得清！   │
│ ●医疗    🔒纳米150 │  │   看得清，附灯光呼吸）  │                  │
│ 【作战】           │  └─────────────────────┘                  │
│ ●兵棋室  Lv1 ▸出击 │  功能：[制造中心] [分析仪 ▸1场后出结果]      │
│ ●工坊    Lv2 ⏳升级 │  ─────────────────────                    │
│ 【科技】           │  升级：Lv2 校准工装（纳米380·能量75·1场）     │
│ ●实验室  Lv1       │       [▶ 开始升级]                         │
│ ●档案室  🔒        │  下一档：Lv3 自动校准（每日1次免费洗点）      │
│ 【深层】           │  前置：无 · 供电：✓                         │
│ ●反应堆  ⏳3场 冻结?│                                           │
│  ⚡需反应堆：通讯   │                                           │
│ ●通讯    🔒❄       │                                           │
│ ●荣誉圣所 🔒❄      │                                           │
└──────────────────┴───────────────────────────────────────────┘
```

- **左侧列表**（四组，站点合并 15→9 见文末）：每行 = 图标+名称+等级豆+状态（暗=未修带成本 / 进度环"⏳还差2场" / 亮=运转）+ 收取气泡 + 一键按钮（修复/升级直接在列表行内点，不进二级页——塔科夫式）。
- **右侧详情**：选中站点显示——① 房间内景**大图**（直接复用 `cap_*.jpeg`，治"232×130 细节看不清"）；② 功能按钮直达现有面板（制造中心/分析仪/商店/技能树…原样复用）；③ 升级路线（Lv2/Lv3 效果+成本+耗时）；④ 生产队列（打印台"还剩 1 场"、分析仪"2 场后出结果"）。
- **顶栏总加成条**：当前基地提供的全部被动加成汇总常显——"基地在给我打工"的直观化。
- **沉浸感供给**：每站一段环境音 loop（反应堆低频/食堂碗筷/电台杂音）+ 详情图灯光呼吸 + 生产倒计时 + 前置依赖用小型科技树呈现（塔科夫 prerequisites）。
- **计时单位换算**：现实时间计时器 → 本项目"场"（修复/升级仍按战斗场次推进，列表显示"N 场后完工"）——节奏不变，呈现变清晰。
- 代价：失去空间仪式感（30 灯纪念墙冲击力下降）→ 荣誉圣所详情页做全屏演出补偿。
- 代码量：中。新建总览面板场景；`BunkerManager`/`BunkerRoomDefs`/存档全不动；`bunker_reward_bubble` 逻辑迁移为列表气泡。

## 方案 H2 · 龙崖式功能抽屉 + 装饰化场景（最小改动）

**形态：现版场景降级为"活体橱窗"，操作全部面板化。**

```
┌──────────────────────────────────────────┐
│   （现版 bunker 场景：无光点、镜头固定，     │
│    修复完成的房间亮灯+粒子；锁定房间暗）      │
│    房间直接点击 = 立即开对应面板（零走路）    │
├──────────────────────────────────────────┤
│ 一键收取✦ |背包|制造|改造|情报|商店|势力|     │
│ 技能树|符文|任务|出击|设置        ← 常显抽屉 │
└──────────────────────────────────────────┘
```

- **删走路**：`bunker_player_dot` 退役（或降级为氛围幽灵，只在演出时出现）；点击房间→Tween 相机轻推+直接弹面板。
- **常显功能抽屉**：照抄战斗 UI `bottom_function_bar` 的模式，一排大按钮直达所有功能面板；未解锁的灰显+悬停显示解锁条件（龙崖"处处可见下一步"）——**功能不再藏在黑房间里找**。
- **收取批量化**：房间气泡保留（`bunker_reward_bubble` 已有）+ 顶栏"一键收取"。
- 代价：场景仍是黑挤的背景板（P1/P2 不根治，但不再构成障碍）；"点亮基地"演出保留。
- 代码量：**最小**。删光点、加抽屉条、点击直开面板。

## 方案 H3 · 指挥中枢（列表 + 运镜，H1×H2 融合）★推荐

**形态：左列表右场景，选中即运镜。**

```
┌────────────┬─────────────────────────────┐
│ 站点列表     │   场景视口（现版 bunker 场景， │
│ （H1 的     │   相机可平移/缩放，无角色）    │
│  紧凑版，    │        ↓ 选中"工坊"          │
│  含状态/    │   相机 tween 推近该房间，      │
│  计时/按钮） │   高亮描边 + 面板弹出          │
└────────────┴─────────────────────────────┘
```

- 左 30%：紧凑站点列表（状态灯+计时+行内按钮，同 H1）；右 70%：活体立体模型（diorama）。
- 点列表 = 相机运镜到房间 + 高亮 + 弹面板；点场景房间 = 反向选中列表项。
- 场景全自动演出（灯、蒸汽、尘埃、电台闪烁），**是"读屏"也是仪式**：修复完成时整层连亮的点亮演出保留在这里。
- 兼得：列表保证零阻力清晰，场景保留空间记忆与情感演出。
- 代码量：中。相机系统 + 列表 UI；美术全复用。

## 方案 H4 · 晨报制（批量决策层，可叠加任意方案）

- 睡觉 → 次日弹《**晨报**》：各站点逐条汇报——配给到账 / 分析仪完成 / 打印完成 / 天气预报 / 预录来电 / 异常事件（"仓库进水，修理需纳米50"）；每条一键领取或处理，底部"全部领取"。
- 需要决策的事（修哪间/升哪级）在晨报内直接给按钮，不必去场景里找。
- 把碎片化的日常微操作**批处理**成一日一次——直击"繁琐"。
- 沉浸感加成：叙事包装强（末日指挥官的每日晨报），电台配音/文字流。
- 代码：`bunker_day_summary.gd` 已存在，是现成的种子，扩成晨报流。

## 方案 H5 · 常进度链（龙崖式"永远有下一格"，可叠加）

- 总览页常驻一条"**今日目标链**"：`修复食堂(纳米200·1场) → 升级兵棋室 → 收取打印 → 解锁符文圣所`，自动从基地状态推导（有资源可修→推修复；修完→推升级；有产出→推收取）。
- 每个功能面板页脚显示下一解锁（"分析仪还差 1 场上线"）。
- 治"不清晰 + 带入感"：目标永远明确，玩家被系统推着走，不会站在黑基地里茫然。
- 代码：纯 UI 层，一个小型推导函数 + 链条控件。

## 推荐组合

**H3（列表+运镜）为骨架 + H4（晨报）+ H5（进度链）**，并做公共修复（15 站合并为 9，见下）。

理由：
- 繁琐 → 列表/抽屉 ≤2 击直达，走路全删；
- 不清晰 → 全状态一屏 + 计时/成本前置 + 目标链常驻；
- 带入感 → 三层供给：**运营层**（生产队列/总加成条/计时器——塔科夫）、**目标层**（进度链——龙崖）、**氛围层**（场景演出+环境音+点亮仪式——保住现版最大的资产）。

## 公共修复（本族同样适用）

1. **15 房 → 9 站**（列表化的前提）：
   - 起居组：宿舍（+背包）｜食堂·医疗 合并为"生活站"｜入口（设置+布告）
   - 作战组：兵棋（出击+沙盘）｜工坊（改造+制造+成长）｜仓库（卡墙+打印）
   - 科技组：实验室（技能树+相位仪）｜档案（情报+分析仪+英雄档案）
   - 深层组：反应堆（电力）｜通讯（商店+势力+排行）｜荣誉（符文+成就+30灯）
   - 气象站并入档案组天气预报；纪念碑并入荣誉组。
2. **战斗 = 计时器**：所有"场"计时在列表/晨报可见，塔科夫味的核心。
3. **总加成条常显**：基地被动收益汇总，永远回答"基地给了我什么"。

## 落地顺序建议（若采纳 H3+H4+H5）

1. H2 先行（1 天量级）：删光点 + 直开面板 + 功能抽屉——立刻解决繁琐/不清晰，风险最低；
2. H3 相机与列表（2-3 天量级）；
3. H4 晨报（在现有 day_summary 上扩）；
4. H5 进度链（纯 UI）；
5. 房间合并与 `BunkerRoomDefs` 收缩放最后（牵动存档兼容，单独一批做）。
