## 方案一 · 相位尖塔（The Spire）

- **概念**：把"向下挖"倒转为"向上修"——一座断顶的相位灯塔，逐层点亮向上爬，塔顶即观星台。背景从岩层换成天空。
- **布局**：垂直卷动（视口 720，世界高 ~2000）。塔身 6-7 层 × 每层 2-3 室，中央螺旋梯井替代电梯井（x=640 竖井逻辑直接复用）。窗外景随高度变化：废土雾海 → 云海 → 星带。
- **功能安置**：底层动力/机库（反应堆+工坊）→ 中层生活（宿舍/食堂/医疗）→ 上层作战（兵棋/通讯/实验室）→ 塔顶观星台终局。纪念碑 = 塔基环形铭文墙。
- **进度隐喻**：修复 = 点灯；亮灯段自下而上生长，**整塔剪影随进度变化**（直治 P3）。
- **优势**：上进感/希望弧光替代现版的下坠压抑；亮色天空占比大（治 P2）；垂直卷动带回探索感。
- **代价**：相机要改卷动；每档窗外景多张背景；美术量中。
- **存活代码**：GRID rect 换纵向 + via 门连锁/梯井寻路全保留；烘焙管线不变。

## 方案二 · 铁幕列车（Armored Train）

- **概念**：基地 = 一列永不停歇的废土装甲列车，5 节时代车厢对应 5 个时代；车窗外风景就是当前时代的战场；出击 = 靠站下车。
- **布局**：水平卷动，车厢首尾相接（每节 ~640px，总长 ~3200）。车头 = 驾驶室+兵棋（出击 = 拉汽笛）；车尾 = 纪念车厢（30 灯）。机车头随章节换代：蒸汽 → 内燃 → 磁轨。
- **功能安置**：每节车厢打包 2-3 功能——餐车（食堂+配给）、货卡（仓库+打印）、守车（通讯+商店）、客车（宿舍+医疗）、工务车（工坊+实验室）、档案车（情报+分析仪）。
- **进度隐喻**：修复 = 把挂着废车厢一节节接通，从残破几节到完整军列；通关里程表/线路图贴在车厢内壁。
- **优势**："时代前进"具象化，与 5 era 结构完美同构；基地在动 = 活的（治 P3）；出击叙事顺滑（到站打仗）；车厢侧视是 AI 生图最友好形态之一。
- **代价**：视差背景 ×5 时代；布局横向长条 → 寻路退化成 1D（反而简单）；换章节要换车头图。
- **存活代码**：全部。via 门连锁天然成立，竖井 → 车厢连通走廊。

## 方案三 · 爬行都市（陆行舰 Crawler）

- **概念**：一台四足/履带巨型陆行舰碾过废土；房间 = 焊在舰体上的外挂舱段（腿舱、甲板炮座、舷侧集装箱）。每一步低频震动 = 氛围音。
- **布局**：单屏全景侧视（舰体 ~1100×500）+ 局部放大。舰桥 = 终局。功能合并为 8-9 个舱段（直接治 P1 拥挤）。
- **进度隐喻**：修复 = 起重机吊装新舱段，舰体轮廓肉眼可见地变完整。
- **优势**：剪影成长感最强的军事浪漫；"家会走路"新奇感高。
- **代价**：美术量最大（整舰多阶段重绘或模块化拼接）；单屏塞功能仍需合并房间。
- **存活代码**：状态机保留；布局仍走 GRID rect。

## 方案四 · 轨道相位环（Orbital Ring）

- **概念**：环绕破碎地球的环形轨道站，房间 = 环上舱段；站体缓慢自转，相位月与地球永在背景。与"相位"主题同根同源。
- **布局**：横向卷动首尾相接 = **环形世界**（技术上是个惊喜）；失重光点沿环漂移。
- **进度隐喻**：修复 = 环上一段段亮起，从断环到整环点亮的夜景图极其优雅（治 P3 最美解）。
- **终局**：对位望远镜舱指向地球裂隙。
- **优势**：主题契合度最高（相位/月/星本来就是游戏 DNA——代码画相位月、观星台）；环形卷动独一份。
- **代价**：与"废土手绘"基调断裂最大，需定调是否接受基地科幻化；失重世界观要补设定。
- **存活代码**：状态机保留；导航 = 1D 环。

## 方案五 · 篝火营地（Campfire Camp · 俯视）

- **概念**：彻底换视角——俯视 45° 山谷营地，中央篝火永燃，帐篷/卡车/天线环绕（DD2 / 篝火之地风）。夜幕降临灯一盏盏亮。
- **布局**：俯视单屏或微卷；12-14 个功能点 = 帐篷/棚屋/车辆/残骸改造物；30 灯纪念 = 篝火外圈石阵。
- **进度隐喻**：修复 = 搭帐篷立灯柱；全营灯光半径 = 进度。
- **优势**：信息可读性最好（俯视无遮挡，建筑+图标双识别）；彻底告别横剖面拥挤（治 P1/P4）。
- **代价**：导航/点击区全重写；俯视是新美术管线；与现有胶囊资产零复用；"建筑成长剪影"弱。
- **存活代码**：仅状态机与 manager。

## 方案六 · 故居残楼（The Old Apartment）★叙事最强

- **概念**：把入口大厅那张"老旧两居室的客厅照片"变成基地本体——陈末住回去的废弃住宅塔楼，逐层逐户点亮。**他修的不是军事基地，是他住过的家。**
- **布局**：侧视残楼剖面，与现版完全同构（岩层换混凝土楼板）：5-6 层 × 每层 2-3 户；天台 = 观星台终局；楼道 = 寻路竖井。
- **功能安置（军转民转译）**：反应堆 → 锅炉房/配电室；兵棋室 → 少年宫沙盘房；通讯室 → 传达室；荣誉室 → 楼道荣誉墙；纪念碑 → 大堂邻居名录。
- **进度隐喻**：修复 = 亮窗；另做一张楼体外立面图作过场——整楼从一扇窗亮到满楼（治 P3 的便宜解）。
- **优势**：情感独一档，与陈末四阶段独白、30 逝者叙事严丝合缝；TWoM 内景件美术可大量复用；**改动量最小**。
- **代价**：军事功能的民用转译费文案功夫；布局仍可能挤（建议合并房间）。
- **存活代码**：最高——GRID/导航/烘焙管线全不动，换贴图与文案。

## 方案七 · 相位口袋 · 群岛（Memory Archipelago）

- **概念**：基地 = 相位裂隙里的口袋空间：漂浮岛群由光桥相连，每座岛 = 一位（或一组）逝者的记忆残片，岛的环境 = 其生前时代（一战战壕岛 / 冷战雷达岛 / 近未来霓虹岛）。
- **布局**：自由 2D 散布小图，岛 = 房间，光桥 = 寻路边；中央主岛 = 宿舍/篝火。
- **进度隐喻**：修复 = 点亮一座岛 + 架一座桥；**30 master 纪念与基地结构合一**——纪念不再是单面墙，整个基地就是纪念。
- **终局**：全岛点亮，口袋中心升起观星台。
- **优势**：叙事×系统耦合最深；相位美学自由发挥；每岛一风格 = 时代巡礼。
- **代价**：美术量最大（每岛一张+桥件）；自由布局 = 寻路新写；风格统一难。
- **存活代码**：状态机保留。

## 方案八 · 深潜母舰（Silent Fleet）

- **概念**：洪水淹没的世界，基地 = 一艘深潜补给母舰；现版"潜艇胶囊"审美转正为完整潜舰内舱。下潜深度 = 进度门槛（浅层生活舱 → 深层反应堆）。
- **布局**：侧视舰体剖面，水平 3 节 × 上下 2 层；舷窗 = 外部水景（发光生物/沉城剪影）；上浮出水 = 天台观星终局。
- **进度隐喻**：修复 = 舱段排水，**水线下降**动画独一无二（治 P3 的奇观解）。
- **优势**：胶囊资产部分复用、审美无缝延续；水下沉默感与孤独叙事最合。
- **代价**：要补"为什么是水世界"的设定（与相位月/废土调和）；舷窗背景多张。
- **存活代码**：高——剖面布局同构，换壳。

## 方案九 · 相位晶树（The Phase Tree）

- **概念**：巨坑中央一棵相位晶化巨树；房间 = 树洞/树瘤/枝上巢屋；修复房间时**树本身在长高长密——基地是活的**。
- **布局**：侧视单屏巨树剪影（树冠 ~800 高），主干 3 圈 × 左右枝 = 12-15 洞。
- **进度隐喻**：不是点亮而是**生长**——每修复一间，树多出一簇晶枝/一盏果灯，剪影变化最戏剧化（治 P3 最强解）；30 盏果灯 = 纪念天然位。
- **终局**：树冠顶端观星巢，晶花全开。
- **优势**：成长隐喻独一份；自然形态彻底打破网格感（治 P1）；有机形态与"废土中一点生机"情感合。
- **代价**："生长"需多阶段树图或模块化枝条拼接，美术管线挑战最大；树洞内景可视性差（治 P4 反而恶化）。
- **存活代码**：状态机保留。

## 方案十 · 指挥舱（One Room Deep）★最省

- **概念**：反其道行之——不再造建筑，基地 = 一间指挥舱（FTL / 60 Seconds 式）。所有功能 = 舱内一面墙的设备位：吊床、电台、沙盘投影台、分析仪柜、符文龛、潜望镜……相机在工位间平移推拉。
- **布局**：单房间 ~1920 宽全景图，视口 1280 平移；12-15 个可点设备每个 100-200px 宽，**细节终于看得清**（直接治 P4）；设备是独立精灵，**改布局不重烘焙**（治 P6）。
- **进度隐喻**：设备逐台从蒙布/断电到点亮；潜望镜 = 天气与世界；揭布演出补"点亮"的情感弧光。
- **优势**：美术量最小（1 大图+设备件）；零寻路、零走路等待（治 P5）；信息密度与可读性最高。
- **代价**：空间探索感/建筑成长感归零；与"避难所建设"的品类预期相悖；房间只剩"设备"granularity，叙事要靠文案撑。
- **存活代码**：状态机全保留；寻路整段删除最省。

## 短名单建议（按诉求）

- **改动最小、情感最大** → 方案六 故居残楼：管线全不动，把"照片里的家"变成基地，文案转译即可。
- **主题一统 + 进度奇观** → 方案四 轨道相位环（整环点亮）或 方案一 尖塔（塔身亮起）。
- **AI 生图最友好 + 时代前进感** → 方案二 铁幕列车。
- **最省钱省事、快速验证"基地值不值得重做"** → 方案十 指挥舱。

## 无论选哪个都建议做的公共修复

1. **15 房 → 9-10 站点**：合并弱功能房（气象+入口、医疗+食堂相邻互通等），单间宽度 ≥300px，治 P1/P4 根因。
2. **点哪 instantly 响应**：光点移动改为"点击即开面板，光点后台走"，治 P5。
3. **剪影进度层**：无论什么形态，都做一张"基地整体随进度变化"的外景图/轮廓变化，治 P3。
