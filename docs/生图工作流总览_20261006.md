# 生图工作流总览——方式划分导出（2026-10-06）

> **定位**：本文是全部 AI 生图方式的**总索引与划分表**——回答「这件事该用哪条生图路线、
> 哪个工具、哪个 API 通道、产物落哪、受哪部规则书约束」。各路线的细节、批次记录、
> 执行标准在各自专属文档里，本文只做划分与指路，不复制细节。
> 读法：先查 §二总表定位路线 → 顺着引用读专属文档 → 公共工序（§四）所有路线共用。

## 一、API 通道层（所有生图共用的底座）

| 通道 | 模型 | 域 | Key | 说明 |
|---|---|---|---|---|
| 图像生图 | `agnes-image-2.5-flash`（批产现役）/ `agnes-image-2.1-flash` | **`apihub.agnes-ai.cn`**（图像专用域） | `tools/_agnes_image_api.md`（本地留存，不入 git） | 文生图 + 图生图（转换/重绘/风格化） |
| 视频生图 | `agnes-video-2.5-flash` | **`apihub.agnes-ai.com`**（视频专用域） | `tools/_api_key.txt`（与图像 key 两套独立） | 视频/动效素材 |

通道纪律（实测沉淀，违者翻车）：
- **key×realm 严格分离**：视频走 com、图像走 cn，key 不混用；
- **urllib 必须换 curl**（`--http1.1` 稳定）；503 = 队满，退避等槽不要硬冲；
- **cn 域 curl 必加 `--ssl-no-revoke`**（10-06 实测：Windows schannel 吊销检查离线报
  `CRYPT_E_REVOCATION_OFFLINE` 拒握手；com 域曾整段 TCP 超时不可达，图像一律走 cn）；
- 负面词基本无效且反激活（「不要大象」效应）——不满意时**改写正向提示词**，负面栏只留
  结构性排除（text / perspective view / frame）；
- 单张 30~60s；3 key 轮换未见限流；并发 payload 必须隔离（MK12 批并发互踩 = 身份漂移真因）。

## 三、路线选择判据（什么单位走什么路）

1. **出卡/换卡** → 一律 A1/A2（卡图是身份唯一真身，STYLE_BIBLE §四+§6.1.3 是宪法）；
2. **载具/部件分明/辅助单位非弹道开火** → B5 codeanim（零生图额度、md5 可复现、facing 一行参数）；
3. **士兵肢体形变动画**（弯腰/跳跃/装填）→ B1/B3/B4 生图主路（cutout 会露馅）；
4. **武器整体刚性旋转** → B5 的 cutoutR 模式（仅限武器层整体旋转）；
5. **火光固执症/贴图不净** → C2 程序兜底，别反复掷生图。

## 四、公共工序（所有 B 类路线共用）

| 工序 | 工具/函数 | 要点 |
|---|---|---|
| 锚定提取（卡图→锚定） | `fam43_card_anchors.py` / `img25_anchor_from_card` | 反预乘+品红场；air=居中 / ground=底缘 normalize 反变换 |
| 键控+去粉 | `detect_bg_color` / `chroma_key` / `depink` / `_pink_scrub`（codeanim_gen 内） | 封闭粉区补刀必须在 depink 之前；`scrub_radius` 默认 100、暗底皮肤 40-55 档 |
| **品红 AA 边晕清除**（2026-10-06 新增） | `load_anchor` 边圈回填 | 边带品红签名像素 RGB 就近回填「实色非品红」源；近透明环 RGB 整体回填防 LANCZOS 渗色。`keep_fringe:true` 为冻结复现逃生口 |
| **部署版边晕手术**（2026-10-06 追加） | `tools/followup_fringe_surgery.py` | 已部署 sheet（route_apply/早批/img25 等异配方）不重生成（锚定时效门），直接逐帧选择性重染：线段拟合 ∨ 投影双门 + 对自身实色投影豁免（涂装 AA 保命）；描边环视作透明；备份 `_old/` + md5 + remap ctex 验证 |
| 部署烘焙 | `deploy_unit_anims.py`（`bake_outline_on_sheet` 等） | attack=staged 10 帧×256 横条+描边暗烘；描边只落纯透明区；悬浮 VFX 不烘 |
| **五件套门禁** | 导入通过→dump 指向→覆盖门→foot_frac→贴边扫描 | **PNG 直写盘不 `--import` = 游戏回退宿主/显旧图**（必踩） |
| 客观像素审计 | `tools/fam43_deploy_check.py` | 尺寸契约/空帧/品红残留/地线/描边/anim.json 六项 |

## 五、产物目录契约

| 层 | 路径 | 纪律 |
|---|---|---|
| 卡图部署 | `assets/card_icons/player|enemy/<unit>.png` | 512 RGBA 角透明；专属副本+override 指行，不覆盖共享 vis_* |
| 动画部署 | `assets/effects/unit_anims/<key>/sheet_attack.png + sheet_idle.png + anim.json` | attack 10 帧×256；idle 4/8 帧；anim.json 带 outline/foot_frac |
| staged 中间产物 | `.godot/unit_review/codeanim/`、`img25_staging/`、`img25_approved/`、`fam43_anchor_from_card/` | 绝不直写 assets；部署一律走立档脚本（fam43 无档内联教训） |
| 审查/验收页 | `.godot/unit_review/*.html`（fam43_review / 决策台 / 质量检查） | 拍板结论落 JSON 台账，不散落会话 |
| 备份 | `.godot/unit_review/fam43_deploy_v2/_old/`、`art_backup_*` | **PNG 不入 git，删=永久**；备份优先幂等 |
