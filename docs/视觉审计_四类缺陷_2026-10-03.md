# 视觉审计：卡图/动画四类缺陷（2026-10-03）

> 审计动机：用户令"全面检查有多少与原图不一样的、忽大忽小的、边缘截断的、变形的"，
> 随后授权"你自己检查好后就改"。本文为审计结论 + 修复台账。
> 本文所有修复**未提交**，回滚路径见 §九。

## 一、范围与方法

- 对象：全量 233 单位动画（fam/ind/drop/plat 四段）+ 敌我卡图。
- 机械层（`tools/_vision_audit_sheets.py`）：
  - 镜像一致性：敌图水平翻转 vs 我图逐像素抽样比对，>2% 判断裂；
  - `_card_anim_asset_probe` 四类疑似（diff/size/bg/face）并集标注。
- 视觉层：204 行 × [敌图|我图|idle首帧|idle中帧|攻击首帧] 图版
  （`_anim_review/vision_sheets/sheet_00..20.png`），45 个疑似行再出 360px 全分辨率复核版
  （`_anim_review/vision_verify/verify_00..10.png`）逐行定性。
- 修复后逐案 256px 攻击帧抽查 + 机械边缘扫描（橙色火光像素贴边零容忍）。

## 六、系统性坑与修复（重建过程发现）

1. **火光切画布边（15/22 案）**：初版 `gun_x-10` 使地面单位火光星心落在 x≈-4，
   目验 PASS 而机械扫描抓出 15 案 col0 切边。修：`cx = max(gun_x-2, r+4)`，
   曳光/余焰椭圆钳制下限 4（512 尺度，保证 256 缩放后离边 2px）。
   教训：**缩略图目验不可靠，机械扫描（numpy 贴边色域检测）必须作为门禁**。
2. **火光脱靶枪口**：整体实心中位把火光打在车体中部。修：枪口高度=最左 24px 带
   （最左伸出即炮管尖）实心行中位。
3. **带中位仍失效的形态**（D 组 3 案）：车体前脸比炮管更凸出时（皮卡保险杠、
   首下装甲角），中位打在车体上。修：CASES 第 7 元素目视定点枪口 (gx,gy) 覆盖
   （皮卡 222,263=货厢机枪口；prism 40,212；abrams_mk2 20,303=炮管尖端，坐标由
   逐行最左伸出 run 探针实测）。
4. 以上修完后 3 案攻击雪碧图机械贴边扫描 **CLEAN**。
