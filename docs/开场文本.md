## 故事主线（深航计划版）

失眠做同一个梦 → 异族入侵 → 人类无力 → 执念化成"生灵" → 人与生灵并肩，
但力量觉醒太迟 → 黑门全球大量降临，无力回天 → 大陆种族会议决议启动**深航计划**：
打开传送门，一千名相位师组成车队回溯到黑门初立之时关闭黑门 → 传送途中暗能量
撕碎车队，多数同伴失忆迷失 → 你在冰雪大陆醒来，身边是基地车，天边是黑门 →
找同伴：还记得自己的并肩同行，迷失的战胜后带其力量同行。
