## 故事主线（深航计划版）

理所当然的和平旧日 → 地球滑入暗能星域（正反空间只能存续一个） → 天空裂开，异族入侵 → 人类无力 →
暗能入侵精神，不屈的精神驯服暗能具现成"生灵" → 人与生灵并肩有了希望 → 科技把驾驭封入卡牌
（人类最后的凭仗） → 但力量觉醒太晚，黑门全球成百上千降临，抵抗只是延缓结局 → 大陆种族会议
决议启动**深航计划**：打开传送门，一千名相位师组成车队回溯到黑门初立之时关闭黑门 → 传送途中
暗能量不断撕碎记忆与精神，多数同伴迷失（战士们的理智逐渐消散，详见 docs/暗能卡牌世界观.md）→
你在冰雪大陆醒来，身边是基地车，天边是黑门 → 找同伴：还记得自己的并肩同行，迷失的战胜后带其
力量同行（力量残留即符文）。
