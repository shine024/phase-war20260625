# 攻击分帧设置规范(草案,2026-10-15)

各卡攻击动画 = 四拍 2048² 四联卷,每拍 1024²。单拍 i2i 生成,参考图 = 卡图本体。
**标杆:060·三角洲部队_开火4格.png(人类卡已定稿,其他类型照此思路推)。**

---

## 一、通用四拍定义

| 格 | 拍 | 内容 |
|---|---|---|
| TL | ready | 与卡图完全同姿态,站定/原地待命,无任何变化 |
| TR | firing | 姿态不动,**开火点**出现攻击效果(火光/能量球) |

**火光位置铁律(2026-10-15 用户拍板:开火点火光要在炮口,不要在炮管或主体上)**
- 火光=「一小团圆球浮在炮口/枪口**开口端**」,prompt 写 `a small round burst floating just at the front opening of the barrel`
- 必带否定:`NOT smeared along the barrel, NOT on the weapon body, NOT on the hull`;载具另加 `the cab and headlights stay dark`(059 实测:整捆管口全糊火+车头灯点亮)
- 多管簇(火箭巢/防空炮):只**一个管口**闪,`ALL other tube mouths stay cold and dark`
- 炮口到图缘之间的品红空底保持干净:`the magenta air between the muzzle and the frame edge stays clean and empty`(057 实测:光带 streak 复现)

**人形动作铁律(同日拍板:人形不要做太夸张动作)**
- firing 拍带 `minimal motion, stance unchanged`;recoil 用冻结句+`torso and head unchanged, no leg raised`
- 禁行军/迈步/高抬腿(039 实测:TL/TR 行军射态+BL 腿抬到胸口)
| BL | recoil | 后坐:身体重心微沉 / 炮管后缩,其余不变 |
| BR | settling | 回到 ready 姿态,开火点留一缕残烟,无火光 |

核心原则:**除开火点效果和一处后坐外,四拍与卡图逐像素一致**。禁步态漂移、禁冲锋大动作、禁结构增减。

## 二、开火点定义(各类型)

攻击效果只出现在「开火点」,即卡上打出伤害的那个位置:

| 类型 | 开火点 | 效果 |
|---|---|---|
| 人形持枪(步枪/冲锋枪/卡宾) | 枪口端点 | 星爆火光 + 可选短弹头 |
| 架设机枪(维克斯/MG42/机枪巢) | 枪管前端 | 星爆火光 + 弹壳抛弧可选 |
| 坦克/反坦克炮(直射) | 炮管端点 | 大号星爆火光 + 炮口烟圈 |
| 迫击炮/榴弹(曲射) | 炮口上缘 | 火光 + 烟团向上 |
| 火箭巢/导弹车 | 发射管口 | 管口火光 + 尾烟 |
| 激光/能量炮(HEL-30 等) | 发射器透镜端点 | 能量球/电光爆闪(替代火光) |
| 水晶/风暴核心 | 晶体核心点 | 电光弧 + 能量球 |
| 无枪卡(碉堡枪眼/要塞窗/三足兽眼) | 枪眼/窗口/眼 | 圆形光球贴孔,**绝不造枪** |
| 无人机群 | 领队机头/各机腹 | 小型爆闪 |
| 喷火/毒气类 | 喷口 | 喷射焰团(向左短喷,不触边) |

## 三、各类分帧细节

### 3.0 recoil 拍变化对照表(各类型「变什么」)

统一原则:**变化 = 一处小位移或一档明暗变化**。有炮管→炮管缩;有悬架→车体沉;无机械→明暗变。
幅度:**炮管/枪后缩幅度要小(2026-10-15 用户拍板:炮管不要变化太大)**,prompt 写 "a very short distance"/"slightly",禁 "kicked back hard" 类重词。
几像素到一小段(96px 战场缩放后可辨即可),禁夸大、禁位移、禁结构增减。

| 类型 | recoil 拍变化 | 本质 |
|---|---|---|
| 人形持枪 | ①重心微沉 ②躯干微后倾 ③整枪沿瞄准线后移一小段(首选,最清晰) ④枪口上跳几度 ⑤肩被枪托顶得微缩——5 选 1-2,别全堆 | 后坐力 |
| 坦克直射炮 | 炮管沿轴线后缩一小段(缩进炮盾),悬架微压车体下沉几像素 | 机械后坐 |
| 皮卡/架设机枪 | 枪身沿座后移一小段,悬架/轮微沉 | 机械后坐 |
| 火箭巢/导弹车 | 无炮管可缩 → 管口余焰渐熄 + 微烟,pod 仰角微颤 | 发射余波 |
| 激光/能量炮 | 透镜亮度熄一档,冷却鳍微亮(散热感) | 能量型后坐=散热 |
| 水晶/风暴核心 | 电光弧熄灭,晶体微暗一瞬再回亮 | 明暗变化 |
| 碉堡/要塞枪眼 | 孔内光球熄灭,孔微暗一档 | 明暗变化 |
| 无人机群 | 无后坐 → 机头光熄,队形纹丝不动 | 明暗变化 |

**人形后坐力禁区**(实测翻车):高抬腿卸力(recoil 句里 "absorbing it" 一词就诱导抬腿)、上步、位置移动。双脚原地钉死,用冻结句压。

### 3.1 人形持枪(标杆 060)
- **ready**:与卡图同(提枪上肩瞄准,站定)
- **firing**:姿态不变,枪口紧凑星爆火光;可选「小弹丸刚离枪口 + 极短拖痕」(060 此版有,拖痕必须短、不触左缘)
- **recoil**:重心微沉、躯干微收,**双脚原地不动**(禁高抬腿、禁上步)
- **settling**:回到瞄准姿,枪口一缕细烟

### 3.2 坦克/载具炮
- **firing**:炮口大号紧凑星爆 + 一圈短烟环;车身不位移
- **recoil**:炮管沿支架后缩一小段(短!),车体/履带/炮塔朝向全不变
- **settling**:炮管回位,炮口残烟
- 禁:扬尘盖底、车身整体后仰跳动、炮塔转向

### 3.3 火箭巢 / 导弹车
- **firing**:一个发射管口出火光 + 短尾烟;已升起的发射 pod 保持原仰角
- **recoil**:无机械后坐 → 用「管口余焰 + 微烟」代替;车体不动
- **settling**:残烟散尽回 ready

### 3.4 能量武器 / 水晶 / 电光类
- **firing**:开火点出现**能量球或电光爆闪**(球体优先,电光弧必须短、贴源,禁长束触边)
- **recoil**:能量熄灭,源体微缩/微暗
- **settling**:回 ready
- 句式沿用爆闪型:「compact round energy burst」,**禁 beam/bolt/streak/pulse toward** 类词(实测必翻成光束拖尾)

### 3.5 无枪卡(碉堡 / 要塞 / 眼 / 塔)
- **firing**:枪眼/窗口/眼贴一个圆形光球(90% 贴孔),如相机闪光
- prompt 全程零 weapon/muzzle/barrel/gun 字眼;「gate」→「window」,「firing」→「peak」
- 正面句:`identical to the reference with nothing added, nothing attached and nothing held`
- **recoil**:光球熄灭,孔微暗;**settling**:回 ready

### 3.6 无人机群 / 悬浮单位
- 四拍队形保持不变,仅领队机头 firing 拍出小爆闪;禁俯冲/散开/队形变换

## 四、prompt 模板句(实测有效,直接抄)

### firing 通用爆闪句(人形/枪)
```
The star-shaped muzzle flash is one small round compact burst pressed flat
against the muzzle tip, like a camera flash going off, a small bullet just
leaving the muzzle with a very short trace that stops well before the frame
edge. Its glow fades out within a short distance of the muzzle.
NO long spikes, NO tracer streaks, NO rays extend from the burst toward any edge.
```

### 坦克炮口版
```
A large compact star-shaped muzzle flash pressed flat against the muzzle tip
of the long barrel, like a camera flash going off, one short smoke ring
around the muzzle. NO tracer, NO beam, no rays reaching the frame edge.
```

### 能量球版
```
A compact round glowing energy sphere bursting at the <开火点>, like a camera
flash going off, its glow fading within a short distance. NO beam, NO bolts,
NO streaks toward any edge.
```

### recoil 冻结句(人形,防抬腿/上步)
```
frozen in exactly the same stance as the ready pose, both boots flat on the
ground, only the rifle shifting back slightly in his grip, no body movement,
no step, no leg raised
```

### recoil 版(坦克)
```
the barrel recoiled a short distance back along its mount, the chassis, tracks
and turret otherwise identical to the ready pose, no dust, no debris
```

### settling 残烟句
```
back in exactly the same stance as the ready pose, a thin wisp of white smoke
rising from the <开火点>, no flash, no fire
```

### 通用防漂移底座(四拍都带)
```
standing braced, both feet planted, identical to the reference with nothing
added, nothing attached and nothing held
```

## 五、生成流程

1. 删该卡旧拍(raw/poses/NNN*_*.png)+ 旧卷(raw/NNN*_开火4格.png),**双删缺一不可**
2. 单拍 i2i:参考=卡图本体,逐拍生成(TL ready 只用卡图直出即可)
3. 拼 2048² 四联(TL/TR/BL/BR),写入 raw/
4. 目验判定:
   - settling 拍有爆闪 = 违规必重掷
   - ready 拍枪口白烟 = 记账可接受
   - 烟团大但离体 = 记账
   - 96px 战场尺寸不可辨的小物件漂移(挎包/沙袋变形)= 记账
   - 结构漂移(机枪跳位/部件消失/高抬腿/车体翻转)= 重掷
5. 重掷两次仍翻同类问题 → 止损:改 prompt 措辞再掷,或接受最不差一版;
   生成层彻底无解时改 **PIL 程序合成兜底**(110 三案例:卡图直贴/生成拍擦杂质/TL 派生调暗,
   零漂移保证)
6. **触边扫描 + 羽化收边**(2026-10-16 用户令:烟火到边禁裁剪):
   每拍四边 12px 带 lum>150 亮像素 ≥30 = 触边报警 → 缘条目验定烟火/本体
   → 烟火跑 v2 羽化收边(`tools/_tmp_edge_feather_20261016.py`,色距掩膜+软边向品红底渐隐)
   → 删卷重拼(拍在自动复用)。本体亮部(舰体/炮管/炮尾)贴缘 = 不动

### 8.1 转换管线终态(`tools/_tmp_conv_attk_sheet_20261016.py`)

卷 2048² → 四帧 256×256 sheet_attack.png,五道工序:

1. **五步键控**(§11.2 既有)+ 帧域品红族补杀:
   `(α>60)&(r>g+40)&(b>g+15)&(r>55)&(b>35)` —— 暗品红接触影/粉斑(060 脚底粉椭圆、
