## 军事网游 UI 的补充说明（2026-11 二轮）

- Steam 商店截图 API（appdetails）对战争雷霆/坦克世界返回的**全是载具宣传渲染图**，无机库数据面板；战舰世界有 1 张实战 HUD（已收 13 号）。
- 战争雷霆机库数据面板（火力/装甲/机动条+弹药栏+乘员）是军事单位详情 UI 的天花板，但需**玩家实机截图**：Bilibili 专栏（hdslb.com 直连可抓）、官网 wiki、thunderskill 数据卡。给到具体页面 URL 即可抓取。
- 坦克世界模块/乘员面板同理：需要 17173/多玩等攻略站的具体页面。
- 大战略（Daisenryaku）系列：Steam 无国际版、悟饭图床失效、百度百科反爬，本轮未获有效图。

## 通用结论（对照当前 tscn 的可改进点）

1. **数值可视化**：当前面板大量“标签: 数值”文本行 → 至少战力/HP/能量改为 条+数字（FFT/ITB 式）。
2. **角标化**：能量、时代、稀有度、部署次数 → 悬浮角标/徽章（炉石/Wildfrost 式），省出纵向空间。
3. **槽位化**：武器与改造 → tile 格子（ITB 式），点击格子弹 detail，而不是长词条堆叠。
4. **分区节奏**：标题小写灰 + 细分隔线 + 双列错位（DD 式），控制 540 宽度内的信息密度。
5. **战场模式差异**：战场版顶部加“敌方意图/行动预告”摘要条（ITB 式），养成版顶部保留稀有度/成长。

## 来源可达性备忘（2026-11 更新，代理 127.0.0.1:10808 开启后）

- **curl 需显式挂代理**：`curl.exe --proxy http://127.0.0.1:10808 --ssl-no-revoke`（curl 不读系统代理）
- 直连可用（不需代理）：ali213、wildfrostwiki、art.hearthstonejson.com（**必须 .png 后缀**）、github.com 网页
- 代理后可用：store.steampowered.com（全尺寸截图 `ss_xxx.1920x1080.jpg`）、fandom **api.php**（网页 403 但 api 通，用 imageinfo 拿 static.wikia 直链，文件多为 **webp**）、img.ui.cn（需 `-k` 跳过被污染的证书）、cdn.dribbble.com 直链
- Dribbble 技巧：页面 curl 只回 202，用 agent-browser 打开后 `eval` 提取 `document.images` 里的 `userupload` 原图直链，再 curl 下载
- 仍不通：www.gameuidatabase.com（403 反爬）、raw.githubusercontent.com
- 脚本：`design/ui-refs/fetch_refs*.ps1`、`fetch_refs4_proxy.ps1`（自动探测代理协议）
