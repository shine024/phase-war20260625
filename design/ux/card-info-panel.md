# card_info_panel 情报卡改版实施计划

> 依据：`design/ui-refs/intel-card/card_info_panel_设计稿.html`（B 版打底）+ `情报卡_简洁版.html`（收敛结构）
> 参考：战争雷霆 15 / 大战略 16 / 钢铁雄心 17 / 战舰世界 13 / 装甲军团 12
> 本计划供外部软件（Figma/PS/直接 Godot）实施，**不改动现有场景文件**。

---

## 1. 目标与范围

- 改造对象：`scenes/ui/card_info_panel.tscn`（540×680，背包/相位仪/战场三模式共用）
- 一期只做**背包态**版式（下述全部内容）；战场态（敌我对比 HUD）与改造态（模块槽）列为二期，不进本次。
- 视觉方向：延续现有深蓝底 + 青色边框语言，吸收两个参考点——
  1. 大战略的**克制命中率交叉表**（对轻甲/对重甲/对建筑/对步兵，"--"表不可攻击）
  2. 战争雷霆的**纯"标签: 数值"两列排版**与**斜杠数值组**（`30 / 30 / 15`），去掉现有词条区的边框线，靠留白分层

## 2. 画布规格

| 项 | 值 |
|---|---|
| 面板尺寸 | 540 × 680 px |
| 左右安全边距 | 20 px（内容宽 500） |
| 分区间距 | 块间距 14 px；行内边距 4 px |
| 圆角 | 面板 6 px；内部块 0（直角，军事感） |

## 3. 分区规格（自上而下）

| # | 分区 | 高度 | 内容 |
|---|---|---|---|
| 1 | 标题行 | ~56 px | 单位名（26px 白）+ 稀有度★（14px 金 #f0b429）+ 类型徽章（12px 青绿描边胶囊，右对齐） |
| 2 | 立绘区 | 200 px | 1px 描边 #24444f，底为深蓝渐变占位；无装饰 |
| 3 | 核心属性 | ~90 px | 左：战力大格（flex 1.4，数值 40px 金 Consolas）；右：三小格纵排（移动力/视野/弹药，数值 19px） |
| 4 | 克制矩阵 | ~66 px | 四等分格：对轻甲/对重甲/对建筑/对步兵；标签 12px 灰青，数值 22px 等宽；不可攻击显示 `--` |
| 5 | 词条区 | flex 撑满 | 每条一行：`◆ 词条名（金）+ 效果描述`，最多显示 3 条，超出滚动或折叠 |
| 6 | 底行 | ~40 px | 时代 / 权重 / 地形修正 三段左中右分布，12px 次级灰 |

## 5. 字体与字号

| 用途 | 字体 | 字号 |
|---|---|---|
| 单位名 | 微软雅黑 Bold | 26 |
| 数值（战力） | Consolas / 等宽 | 40 |
| 数值（格内） | Consolas / 等宽 | 19–22 |
| 标签/徽章 | 微软雅黑 | 12 |
| 词条 | 微软雅黑 | 13.5，行高 1.9 |

原则：**所有数值用等宽字体**，保证多位数对齐。

## 6. 字段映射（游戏数据 → UI 位置）

| 游戏字段 | 位置 |
|---|---|
| 名称、稀有度、兵种 | 标题行 |
| 战力 | 核心属性大格 |
| 移动力、视野、弹药 | 核心属性三小格 |
| 对轻甲 / 对重甲 / 对建筑（或对步兵，按实际字段） | 克制矩阵四列 |
| 技能/特性词条 | 词条区 |
| 时代、权重、地形修正 | 底行 |
| 轻攻/重攻/装甲（若需展示） | 合并为一行斜杠组 `30 / 30 / 15`，插在词条区上方（战争雷霆式） |

## 7. 交互态（一期）

- 三模式共用此版式；战场模式仅追加：进入战场时底行替换为"回合/控制区/增援"动态信息。
- 禁用/灰卡状态：整卡透明度 0.5 + 边框换 #33505e。
- 悬停（网页稿演示用）：格子 hover 时描边转 #2ba7c9。

## 8. 实施步骤

1. 按 §3–§5 出高清视觉稿（2x 导出）
2. 切图：立绘占位框、徽章描边可纯 StyleBox 实现，无需切图
3. Godot：PanelContainer + VBoxContainer 自上而下 6 块；矩阵用 HBoxContainer 均分四格
4. 数据绑定：`card_info_panel.gd` 按 §6 映射；数值格式化（等宽字体+千分位）
5. 三模式回归：背包打开 / 相位仪点选 / 战场点选各验证一次

## 9. 验收标准

- [ ] 540×680 下无滚动、无截断（词条区内部滚动除外）
- [ ] 所有数值等宽对齐；`--` 灰色、弱值红色可一眼区分
- [ ] 克制矩阵四列与设计稿逐像素一致（±2px）
- [ ] 词条区无边框线，靠留白分层（对比旧版）
- [ ] 三模式打开不报错、字段无空引用
